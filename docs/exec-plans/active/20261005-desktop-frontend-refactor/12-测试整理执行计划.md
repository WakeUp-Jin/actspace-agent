## 决策记录

| 日期 | 决定 | 原因 |
| --- | --- | --- |
| 2026-10-05 | 放弃「完整类名串」这类正向快照，例如 `SESSION_ROW_ACTIVE_CLASS` 的完整字符串、`focus-visible:ring-focus-ring/30` 必须存在 | 它们守的是写法而不是行为；颜色走 token 由脚本保证，焦点环由 `focus-ring-legacy` 禁用规则保证不退回原生色 |
| 2026-10-05 | CSS 块规则只迁禁用项，不迁「必须包含某个值」 | 正向值是视觉快照，改一次视觉就要改一次测试；例外是 `.file-diff-content`，它守的是「有界滚动」这个行为 |
| 2026-10-05 | `display: none` 的断言删除 | jsdom 测不了它，而且它是动效降级的实现细节 |

## 风险

| 风险 | 缓解 |
| --- | --- |
| T2 新规则命中大量存量代码 | 先跑一次看命中数量。超过 20 处时，规则先只扫 `components/settings/**` 和 `components/Sidebar.tsx`，扩大范围另起任务，并记进执行过程文档 |
