# 自定义模型推理能力

状态：实施中；用户已确认方案并要求开始。

## 范围与契约

复用 ModelDefinition 与 models:update，新增模型级 reasoningConfig：自动匹配或手动覆盖、支持/不支持/未知、允许的强度、默认自动或指定强度、允许关闭。新建连接可配置默认模型，已有模型在模型设置单独编辑，不改变连接身份或 API model。

自动匹配精确 API ID 或显式参考目录模型，不按前缀猜测。目录只声明支持推理而未声明强度时不生成档位；人工覆盖持久化，不被目录刷新或连接重命名覆盖。能力来源不是中转实测证明。

## 步骤与验证

1. shared 增加配置、纯匹配/校验函数；SettingsService 创建、ModelStore 更新并投影能力。测试未知、冲突、手动覆盖、重启和不同模型隔离。
2. 设置页增加共用推理表单与单模型入口；Composer 读取默认强度与允许档位。测试新建、编辑、取消、非法默认与自动。
3. Desktop adapter 区分连接协议与供应商品牌；自定义 Chat 使用标准字段，Responses 使用 reasoning.effort，Anthropic 仅使用明确支持的协议映射。自动不强行设 high。离线捕获直连/代理请求验证。
4. 运行 shared/LLM/Desktop 相关测试、依赖构建、类型与前端构建，浏览器浅深主题验证。使用现有授权中转做极短参数验证，HTTP 成功只记录接收，不宣称内部推理生效。
5. 同步设计、history、学习文档、执行摘要；不提交、不替换安装包，不覆盖并行工作。

## 回退与风险

新增配置可忽略；旧模型缺省标记未知，不批量改写历史会话。目录不可用使用内置快照与手动输入。回退本次代码即可；不改密钥、自动刷新第三方目录或执行迁移。
