# Markdown 编辑与渲染（文档面板 CM6 实时预览 + 聊天区 Markdown）

## 目标

本计划包含两部分，在同一个分支上完成：

- **文档面板**（T1–T16）：换成 CM6 实时预览编辑器。
- **聊天区**（T17–T28）：改造 Markdown 渲染。

两部分共用路径识别、提示框定义和 KaTeX。

### 文档面板

「文档」面板的正文换成 CodeMirror 6 + Lezer 实时预览编辑器，达到以下状态：

- **两种模式都能编辑**：预览和源码共用同一份文档，切换时保留光标、撤销历史和滚动位置。
- **预览**：按 D1–D12 隐藏和露出语法标记，渲染以下内容：复选框、圆点、伪表格、代码块头、Mermaid、KaTeX、本地图片、属性卡、提示框。
- **文中的路径和本地链接**：单击就在 ActSpace 里打开，带行号的跳到对应行。
- **排版**：照搬 Codex，默认强调色是信息蓝，只作用于文档正文。
- **删除**：旧的 `react-markdown` 预览和 textarea 源码编辑器全部删除。

设计见 [Markdown 编辑与渲染规范](../../design-docs/frontend/front-Markdown编辑与渲染规范.md)，视觉见 [md-render-demo](../../design-docs/frontend/md-render-demo/README.md)。

### 聊天区

`MarkdownProse` 在原位改造，三处使用方统一生效：助手回复、子 Agent 记录弹窗、子 Agent 面板。

- **改进 1–10**：路径可点、提示框、公式、原始 HTML 白名单、表格、任务列表、不自动识别语言、长代码块折叠、本地图片和远程图片不加载、脚注不再整条退回一块。
- **排版**：「A 书页」，西文衬线 + 中文苹方，16.5px，行高 1.78。
- **单个换行**：保留成换行。
- **流式**：
  - 新块淡入；
  - 末尾三层渐显；
  - 呼吸圆点光标；
  - 平滑输出；
  - 代码块内高度零回缩。

设计见 [聊天区 Markdown 渲染规范](../../design-docs/frontend/front-聊天区Markdown渲染规范.md)，视觉见 [chat-md-demo](../../design-docs/frontend/chat-md-demo/README.md) 的「A 书页」。

## 风险

**风险 1：实时预览的光标和选区行为出现边界问题。** 例如：

- 方向键越过 widget；
- 输入法组字时装饰跳动；
- 选区跨过隐藏的标记。

缓解方式：

- widget 都设为原子范围；
- 组字期间（`view.composing`）不重算装饰；
- 测试覆盖跨标记选区和方向键；
- Electron 验收时用中文输入法实测。

**风险 2：大文件卡顿。**

缓解方式：

- 行内装饰只算可见区域；
- 块级装饰按露出集合重算；
- 1MB 样本测量打开和输入耗时，不达标就先修再继续；
- 截断文件只读。

**风险 3：草稿和编辑器互相回写，形成循环，或者丢掉输入。**

缓解方式：

- 只在“外部替换”时写入编辑器（规范 §4）；
- 编辑器到草稿每帧最多同步一次；
- 组件测试覆盖连续输入、保存、重新加载、换文档。

**风险 4：打包后体积增加。**

缓解方式：

- 编辑器、语言包、KaTeX 各自分 chunk；
- 记录构建前后主包和 chunk 的大小，写进执行摘要；
- 主包不得增加超过 5KB（gzip）。

**风险 5：删除旧组件时漏掉引用方。**

缓解方式：

- 删除前用 grep 列出全部引用方；
- `typecheck` 和全量测试兜底。
- `MarkdownRenderView` 引用了 `MarkdownProse` 导出的 `codeText`、`fenceLanguage`。T12 删除它之后，确认这两个导出是否还有别的引用方，没有就一起删。

**风险 6：聊天区流式又出现一跳一跳。**

demo 里实测过：光标落在结尾换行后面、流式代码块封顶、写完自动收起，任何一个都会让高度每帧来回跳。

缓解方式：

- 规范 §7.2 的五条写成单测；
- T27 在浏览器 mock 里逐帧测量，代码块内回缩必须是 0，不达标不往下走。

**风险 7：批注定位失效。**

改动会影响批注依赖的可见文本：

- KaTeX 输出了重复的文字（MathML 和 HTML 各一份）；
- 原始 HTML 渲染后，文字也会和原来不同。

缓解方式：

- KaTeX 加 `data-annotation-exclude`；
- 现有批注测试全部要过；
- 在含公式、原始 HTML、提示框、路径的回复上补批注测试；
- 旧回复上的批注可能无法定位，执行摘要里写明影响范围。

**风险 8：聊天区让主包变大。**

缓解方式：

- 数学插件、原始 HTML 插件按需加载；
- KaTeX 和文档面板共用 chunk；
- 主包增加 ≤ 10KB（gzip）；
- 与文档面板的数字分开记录。

**风险 9：整页历史回复跟着重渲染。**

如果新加的 context 值、插件数组、`components` 不是稳定引用，平滑输出每一帧都会让所有历史回复重渲染。

缓解方式：

- 这些都放在模块级或用 `useMemo`；
- 组件测试断言：流式时非最后一块不重渲染，历史回复也不重渲染。
