| | 原版 | 改进版（修复前） | 改进版（修复后） |
| --- | --- | --- | --- |
| 正文高度回缩次数 | 2 | 36 | 9–16 |
| 其中在代码块里的 | 0 | 23 | 0–2 |

修复后剩下的回缩每次 7–14px（最后一帧约 50px）。原因是 `` `xxx` `` 这类行内语法在闭合符号到达前显示原文、到达后变格式，那一行会重新折行，属 Markdown 固有行为。

## 测试与验收清单

- 单元：路径识别与解析正反例（与文档面板共用用例）；提示框五种类型；公式（`$5 和 $10`、`\$`、未闭合、块公式、写错）；原始 HTML（`<details>` 跨块合并，`<script>`、`onerror`、`javascript:`、`style` 属性被去掉，远程 `<img>` 不加载）；脚注与引用式定义（不退回一块、编号按全文顺序、只有一个脚注区、定义晚到只重渲染引用块）；`rehypeStreamTail`（光标不落结尾换行后、代码块无光标、公式内不渐显、层数与字数）；`snapCut`（反引号、`**`、链接、表格行、围栏行，后文到达/没到）；代码块（挂载时已闭合且超 22 行才折叠、`title=` 解析、复制不含围栏、无语言不高亮）。
- 组件：流式中最后一块有渐显和光标、结束后消失；内容变短直接显示全部；路径点击带行号、无宿主不可点；批注现有测试全过、公式被排除在可批注文本外。
- 稳定性：浏览器 mock 流式逐帧记录高度，代码块内回缩次数必须为 0。
- 浏览器 mock：覆盖全部元素的回复，浅色、深色、窄窗截图。
- Electron 实机：长回复流式代码块不跳、末尾渐显和光标；点击路径、带行号路径、本地链接、外链；公式、`<details>`、本地图片、远程图片占位；右侧子 Agent 面板；深色与强调色切换；选中文字批注。

## Mermaid 决策记录（2026-09-28）

- 接受 Codex App Mermaid 图表为视觉与交互参考，不以 ActSpace UI token 重染图表；独立 Mermaid 主题偏好，固定 Codex 浅色。
- 开放项结论：固定 Codex 浅色、不跟随应用主题、外观页暂不放只有一项的选择器（代码保留 `AppearancePrefs.mermaidTheme` 与主题注册表）；不提供自定义颜色；Mermaid 全部图类型按需加载，只对 sequence / flowchart / state 做视觉承诺；放大预览只做缩放 / 平移，源码走块工具栏；聊天列即 `--conversation-content-width`，图表不越出列宽，过宽最多缩到 72%，再宽则块内横向滚动；默认禁用 `click` / 外链 / HTML labels；`mermaidTheme` 并入 `actspace.appearance.v1`，旧记录回落 `codex`。
