## 目标

- **会话定位**：`host:` 会话 key 的编解码只保留一份，放在 shared，非法 key 一律抛错。
- **运行目标抽象**：renderer 用 `RunTarget`、能力表 `capabilities` 和 `readiness` 描述「在哪里运行、能做什么、能不能发送」，代替散落各处的 `remote?.hostId` 判断。
- **Host 订阅**：Host 列表和事件只订阅一次，由 `HostDirectory` 分发，describe 失败时能看到原因。
- **审批**：审批对象带 `hostId`，renderer 不再解析审批 id。
- **main 侧收口**：远端分流下沉到 `M/session-gateway.ts`；git 子进程调用统一走 `run-git`。

## 类型草案

```ts
// R/target/run-target.ts
type RunTarget =
  | { kind: "local"; workspaceRoot?: string; branch?: string; worktree?: SessionWorktreeContext }
  | { kind: "remote"; hostId: string; hostName: string; workspaceId?: string; workspaceName?: string };
type Capability = { enabled: boolean; reason?: string };
type RunTargetCapabilities = {
  newWorktree: Capability; branchSwitch: Capability; localFileOpen: Capability;
  terminal: Capability; review: Capability; attachments: { images: boolean; files: boolean };
};
function capabilitiesOf(target: RunTarget, env: { gitReady: boolean }): RunTargetCapabilities;
function resolveReadiness(target: RunTarget, directory: HostDirectorySnapshot, model?: string): RunTargetReadiness;
```

实际字段以替换现有分支时的需要为准。每个字段都要能对上某个被替换的 `remote?.hostId` 分支，不预先设计用不到的能力。
