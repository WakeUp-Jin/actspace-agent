# 多个搜索引擎的分数为什么不能直接排序

一个引擎给页面打2.4分，另一个给0.98分，并不说明前者更相关：它们的量纲、模型和校准都不同。直接比较会让分值范围最大的引擎长期占据前排。

RRF（Reciprocal Rank Fusion）只使用来源内部的名次。每个来源对页面贡献 `1 / (k + rank)`，跨来源相加；本项目取k=60，rank从1开始。例如两个来源都把同一页排第2，该页得2/62；只在单一路排第1的页面得1/61。多来源共同认可的页面因此靠前。k越大，排名相邻的差别越小，重复命中的影响越明显。

使用时先规范化URL、保证同一个来源对同一页只贡献一次，再累计分数，最后截取总数。如果先分组截取后直接拼接，会超出总结果限制；如果把所有来源重复行都计入，会被单一来源重复结果抬高排名。规范化也不能过度：保留查询参数，不把所有尾斜杠之外的路径差异或http/https强行合并。

这是一种无需额外模型调用的融合方法，并不证明最终相关性一定优于单一引擎。高度相关的来源可能重复强化同一偏差，真实质量仍需用代表性查询评估。
