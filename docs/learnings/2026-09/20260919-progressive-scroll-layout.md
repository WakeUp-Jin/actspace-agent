# 滚动展示应建立在可读文档上

图文联动有三种独立状态：文档内容、当前视口、当前焦点。把三者直接绑定为“只有活动项存在”，会让无脚本、键盘导航和窗口缩放都变得脆弱。

先让 HTML 自带每段文字和对应图片，再在宽屏且脚本可用时启用 sticky 展示。脚本只改变当前强调项；窄屏与无脚本仍使用普通文档流。减少动效偏好关闭过渡，不删除内容。

复制图片到 sticky 舞台后，要管理重复内容的可访问性。原位置隐藏时设为 inert；舞台只有活动项可以获得焦点，其余项设置 aria-hidden 和 inert。仅改 opacity 不会阻止键盘进入透明的链接。

断点变化还必须同步交互状态。例如移动端关闭 details 后，桌面 CSS 隐藏 summary，并不会自动打开 details；必须监听断点，让桌面恢复展开。单独截图每个宽度发现不了这个问题，应该在同一个页面里从窄屏切回宽屏。

验收除了正常滚动，还应覆盖脚本关闭、键盘链接、减少动效、跨断点缩放。动画截屏应等到过渡稳定，否则中间帧的半透明重叠可能被误认为布局缺陷。
