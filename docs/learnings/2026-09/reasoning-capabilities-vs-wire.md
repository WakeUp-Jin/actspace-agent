# 推理能力和推理参数是两个契约

“模型支持推理”不等于“支持所有推理强度”。模型目录常常只给一个布尔值；将它扩展为全部档位，会把推断伪装成事实。用未知状态、精确匹配与显式手动覆盖，可以保留可用性而不制造虚假能力。

API 协议也不等于供应商品牌。中转采用 OpenAI Chat 格式，并不表示它接受 OpenRouter 的 reasoning 对象。模型 ID、连接身份和参数编码需要分开建模，最后在请求边界组合。

Auto 必须有可检验的语义：这里表示不指定 effort。仅让界面不传值并不够，Host 或 SDK 可能随后补 high；回归测试需要捕获最终 payload，并刻意向 SDK 回调提供已有默认值，确认最终真正移除它们。

HTTP 200 只能证明服务接受请求。中转可能忽略字段；非法值探测也可能超时。没有服务端证据时，应保留“接受但未证实生效”的结论。
