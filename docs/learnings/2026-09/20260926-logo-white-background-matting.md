# 给白底 Logo 去背景：为什么不能“按亮度算透明度”

> 来源：[官网首页改版 history](../../histories/2026-09/20260926-0840-site-homepage-redesign.md)（T2 Logo 透明化）。

## 问题

ActSpace 的 Logo PNG 没有透明通道，放在近白画布 `#fafaf9` 上会露出一圈白框。最直觉的修法是“越亮越透明”：`alpha = 1 - 亮度`，再反预乘恢复颜色。

这对**浅色品牌色**是个陷阱。Logo 身体是浅紫 `#b4a2e3`，亮度约 0.68，按亮度算只剩约 30% 不透明——紫色团子会变成半透明，放到深色背景上发灰发暗。

## 正确的想法：把每个边缘像素看成“前景色和白色的混合”

抗锯齿边缘像素本质上是 `pixel = α · 前景色 + (1 − α) · 背景白`。只要知道前景色，就能反解 α：

```text
α = ((W − pixel) · (W − F)) / |W − F|²      // 投影到 W→F 这条线上
color = (pixel − (1 − α) · W) / α          // 反预乘，得到纯前景色
```

Logo 只有两种前景色（深色圆环、浅紫身体），对每个边缘像素分别套两种前景色，取残差最小的那个。

## 两个关键保护

1. **只处理和外部背景相连的区域**：从图片四边做 flood fill，找到“接近白色且连到边框”的背景，再向内扩 3px 作为边缘带。只有这条带里的像素才重新计算 α，其余一律完全不透明。否则紫色和深色圆环交界处的混合像素也会被误算成半透明。
2. **用“离白色多远”而不是“多亮”判断背景**：`d = max(255 − r, 254 − g, 251 − b)`。浅紫的蓝通道离白很近，但红、绿通道差 70–90，`d` 很大，不会被当成背景。

## 核心要点

- 亮度 ≠ 是否属于背景；浅色品牌色会被亮度法误伤。
- 抗锯齿边缘 = 前景与背景的线性混合，已知前景色就能反解 α。
- 限定处理范围（连到边框的背景 + 窄边缘带），比调阈值更稳。
- 验收要在深色背景上放大看：白晕、发灰都会在深底上暴露。
