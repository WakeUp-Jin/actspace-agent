# 文件引用不等于图片：把存储与模型输入分开

`artifact` 回答“内容存在哪里、归谁所有”，MIME 回答“它是什么”。把这两个问题合并成 `artifact → image`，会让一份日志因为离开内联文本、变成文件，就突然被识别成图片。

可以用三步检查这类系统：

1. 历史是否保留足够的类型与引用信息？ID、MIME、所有权和摘要让恢复可验证，原始二进制不需要进入日志。
2. 模型是否知道如何使用这个引用？普通文件需要可调用的回读路径。只有 ID、没有工具能解析它，仍然是断开的功能。
3. 实际请求是否遵守供应商协议？工具产生图片不意味着所有协议都接受 tool 消息里的图片；一批并行工具的结果也必须先配齐，再加入视觉观察。

“输出有界”和“信息丢失”不是同一回事。长输出只返回头部可以是正确设计，前提是完整文件可恢复、分页读取有界、权限与生命周期一致。把阈值调大不会修复断开的回读路径。

测试也应跨越边界：让真实工具生成长输出，保存文件，检查下一次模型输入，再用其中的路径读取末尾内容。仅断言“工具返回了 artifact”无法发现模型随后把它当成图片的问题。
