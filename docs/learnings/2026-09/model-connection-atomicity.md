# 模型连接配置要作为一个整体解析

模型 ID、协议、地址、密钥、代理和定价倍率共同描述一次调用。分别为每个字段做“有值优先”的 fallback，看似增强兼容性，却可能把 A 服务的模型名和 B 服务的地址、密钥拼成一个从未配置过的连接。

应先确定稳定的连接身份，再从同一次解析结果生成完整请求。未知或已删除的连接必须明确失败，不能偷偷退回默认供应商。显示名称只是标签，重命名不该改变身份。

测试也要经过实际凭据入口。只用空凭据调用适配器的测试，会掩盖上游默认凭据污染；至少覆盖默认服务未配置、默认服务使用不同 Key/代理、自定义连接切换和删除等情况。

生产依赖存在类似陷阱：开发环境能导入并不代表打包后能导入。动态 import 尤其容易绕过静态检查，必须从独立部署目录运行初始化检查，避免依赖开发目录的偶然可见性。
