# 官网预览的文档、博客与更新日志统一

## 用户诉求

文档、博客和更新日志与首页割裂；先在预览内阅读，文档参考 Cursor 三栏，更新日志参考 Cursor 连续发布布局。方案确认后实施。

## 改动

- 仅调整 `docs/design-docs/website-xai-preview.html` 和相邻说明，保留首页 Logo、实拍图和现有主题。
- 文档、博客、上手入口改为预览内 hash 导航；9 篇公开文档、7 篇博客全文来自现有公开 Markdown 的静态快照。
- 文档使用分类侧栏、正文、页内目录，标题搜索可筛选目录，手机目录折叠。
- 博客使用主推文章、编辑式列表和全文阅读页。
- 更新日志按日期倒序展示 8 条公开记录，日期在左、全文在右；移除旧详情目录和本地视频上传演示，没有伪造录屏或版本号。
- 正式 `apps/site`、发布数据及其他已有设计修改未改动。

## 验证

- Playwright 真实 Chromium：1440、375、320px × Light/Dark × 首页、文档、博客、博客全文、更新日志，未发现横向溢出、可见缺图或脚本异常。
- 全部 16 个内容路由可读，逐页手机宽度检查通过。
- 验证文档标题搜索、浏览器返回、手机目录展开和桌面恢复、System 随系统切换、主题持久化、图片放大与 Escape、8 条更新连续展示。
- HTML ID 无重复，内部锚点无缺失，内联脚本语法检查通过。
- 渲染截图复核了文档三栏、博客主推列表及更新日志移动排版。

## 边界

此轮交付为独立设计预览，没有部署。历史发布记录和公开文章保留来源时间，不代表当前主线的功能承诺。后续录屏需要真实素材。属于既有布局模式的应用，未命中两条学习文档条件。
