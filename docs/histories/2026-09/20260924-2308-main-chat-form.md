# 主 Agent Chat 形态

## 用户诉求

增加与权限模式分离的主 Agent Chat 形态。Chat 只提供网络搜索和生图工具，支持用户主动上传图片、TXT、Markdown、JSON、CSV；PDF 与 Office 首版不做。沿用现有上下文压缩，只增加 Chat 压缩阈值设置，并把破坏 Prompt Cache 的动态运行事实移到上下文末尾。

## 本次改动

- 新增 `actspace.main` / `actspace.chat` 静态主 preset，以 Session Header 持久化形态；旧 Session 缺 preset 时恢复为 Agent，未知 preset fail closed，fork 继承父 preset。
- Chat 使用独立 Prompt 组装，不注入 workspace 指令、workspace facts、Skill catalog 或 selected Skill；模型工具严格为 `web`、`generate_image`。
- 新增 `web(action=search|open)` 门面，复用现有搜索 provider、抓取、SSRF、重定向和限额实现；Agent 继续使用 `web_search` / `web_fetch`。
- Prompt Contributor 拆分 `model-fact` 与 `request-fact`，request snapshot 升级为 schema v2；动态 run/invocation identity 不再进入 system prompt。
- Agent 的 Plan/Agent 单轮模式作为隐藏 `runtime-context` 持久化在用户消息末尾；renderer、标题、transcript 与 Compaction 摘要隐藏该块。
- Chat 附件白名单收口为 PNG/JPEG/WEBP/GIF、TXT、Markdown、JSON、CSV；文本严格 UTF-8、单文件 1 MiB、单消息 256,000 字符，校验失败不写消息并回滚已暂存 Artifact。
- Settings v4 增加 `chatCompactionTriggerRatio`，默认 80%、范围 50%～95%、步进 5%；Host resolver 使新值无需重启即可影响下一次 Chat 自动压缩判断。
- Sidebar 顶部和 workspace 新建入口均提供 Agent/Chat；Chat Composer 固定显示 Chat，隐藏 Plan/Agent、Skills 与 workspace 控制，保留模型、Thinking、Context 和附件。

## 设计动机

Chat 是 Session 级产品形态，不是逐轮权限开关。用 preset 固定 Prompt、工具和 UI 边界，可以避免 renderer 状态漂移或 Prompt 自律造成能力泄漏。动态事实与稳定 system prefix 分层后，缓存前缀不再被每轮 ID 打断，同时 Journal 仍保留完整审计事实。
