# 图片加载骨架预览页

## 用户诉求

官网图片加载很快，无法直观看到博客封面和产品截图的加载骨架，希望增加一个可以直接打开的预览页面。

## 本次改动

- 新增 `apps/site/src/pages/preview/image-skeleton.astro`。
- 展示博客封面 `3:2` 骨架和产品截图原图比例骨架。
- 每个示例加载时固定保持约 2.2 秒，支持“重新播放”重复查看。
- 复用现有 `media.css` 的主题变量、占位背景、呼吸动画和加载完成状态。

## 预览地址

`/actspace-agent/preview/image-skeleton/`

## 验证

使用站点 check、测试和生产构建确认新页面可生成；浏览器中打开预览地址检查桌面和移动布局。
