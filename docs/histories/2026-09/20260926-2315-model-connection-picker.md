# 模型选择器按连接分组

## 用户诉求

OpenRouter 只配置一个模型，但任务输入框显示了多个来自其他自定义连接的模型；模型设置页还把推理配置入口集中显示在列表顶部。

## 变更

- `UsableModelView` 和模型目录服务现在携带自定义连接 ID 与显示名称。
- Composer 按实际连接名称分组模型，默认连接仍显示为服务商名称。
- 模型设置页移除顶部的推理配置按钮，并把入口放到对应模型行或多选下拉项旁边。
- 增加 Composer 自定义连接分组回归测试，并更新推理配置交互测试。

## 设计动机

模型的 `provider` 表示传输服务商，自定义连接则决定实际使用的地址和凭据。只按 provider 分组会把多个连接混成一个 OpenRouter 列表，导致用户误判模型来源。显示连接身份可以保持选择器与运行时解析使用同一条边界。

## 验证

- Desktop renderer 相关测试：95/95 通过。
- Desktop typecheck 未通过，失败来自工作区已有的 usage 统计字段变更，与本次模型选择器改动无关。
