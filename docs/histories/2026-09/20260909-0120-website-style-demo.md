# 官网三方向 HTML Demo

## 用户诉求

用户认为官网整体不协调，希望参考 Claude 博客的阅读气质，保留更新日志的时间轴交互并增加动画。先制作多个不同风格的 HTML Demo，选择后再更新正式网站。

## 完成内容

- `docs/design-docs/website-style-demo.html`：单文件、素材内嵌的交互原型，约 0.98 MB，无外部运行依赖。
- 三个视觉方向：A 纸面编辑、B 精密工作台、C 空间画廊。每版包含首页、博客列表、文章阅读、更新日志。
- 可操作的方向与深浅主题切换、产品标签、文章搜索与分类、文章返回、时间轴跳转与滚动日期同步、阅读进度。
- 原生 CSS 语义变量；中文自然字距；键盘操作不播放动画；提供 reduced-motion 样式。
- `website-style-demo.md` 记录方向、素材、边界和后续选择方式；从官网长期设计文档增加导航入口。

## 内容与范围

博客复用公开内容的标题、日期、封面。Context 文章全文，其他文章以明确标注的节选展示。更新页采用 2026 年 8 月四条历史记录，其中 8 月 1 日节选新功能。产品截图使用现有历史素材并注明，Context 图裁切为系统提示区域，避免复制无关本地路径。

本次只交付视觉评审原型。`apps/site` 无变更，没有修改依赖、发布、部署、Markdown 内容源。未提交或推送。

## 验证

- `node --check` 检查从 HTML 提取的运行脚本，通过。
- 在真实 Codex 浏览器检查 1280px 桌面、375px 与 320px 手机代表性状态。三方向、深浅主题、四类页面均有渲染检查；不将代表性覆盖视为完整跨浏览器矩阵。
- 已实际操作：三方向切换、浅深主题切换、博客分类 7 → 2、搜索 2 → 1、无结果与重置、进入文章与返回、产品 Usage 标签、日期跳转与活动指示、键盘阅读。
- DOM 检查：受检页面横向溢出为 0；桌面首页失效图片为 0；移动文章标题与正文同为 x=22px，阅读列 331px。
- 最终浏览器错误与警告日志为空。
- 发现并修正：深色云景文字对比不足、375px 标题末尾孤行、时间轴跳转重复叠加顶部留白；对应状态已复验。
- 系统 reduced-motion 分支做了源码检查，未切换操作系统辅助功能设置。正式 Astro、Electron 和线上部署未运行，本轮未涉及它们。
