# 自定义模型推理配置

## 用户诉求

自定义中转模型缺少推理强度；用户确认自动匹配加手动覆盖，要求开始实现。

## 修改

- 模型级 reasoningConfig，自动精确匹配或显式参考、手动支持状态/档位/默认/关闭配置。
- 新建连接默认模型和已有单模型共用表单，Host 校验并持久化，保留连接身份。
- Composer 支持自定义默认与 Auto，剔除过期档位。
- generic 中转参数按协议生成，清除 SDK 自动强度；已知官方端点保留原适配。
- 新增 shared、Host、UI 和直连/代理回归与离线主题预览。

## 验证

进行中，结果见同名执行摘要。其他工作区变更保留；未提交、未替换安装包，未更改用户现有模型配置。
