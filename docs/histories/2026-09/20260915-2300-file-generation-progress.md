# 文件生成进度改为低频字符量

## 用户诉求

运行中 Write 长时间显示 +0 -0；保持单行、不自动展开，生成阶段最多每秒更新字符量，完成后显示真实增删行数。方案经用户批准后实施。

## 变更与原因

原适配器忽略首次之后的参数增量，工具 body 只在写盘前后报告统计，无法反映模型生成内容的等待过程。

- Main 新增常量空间扫描器，只统计顶层 content / new_string 解码后的 Unicode 码点，支持分片转义和代理对，不保留正文。
- 按调用独立一秒尾随更新，生命周期结束时清理定时器；无增量不模拟数字。
- Shared 临时 generationProgress 经 App 和 selector 传到 FileDiffBlock；生成、准备保存、保存、终态分别展示。已有设置控制字符量与完成态统计。
- 同步工具预览、流式渲染、中间消息区文档。工具原子写入行为不变。

## 验证

- 相关 4 个测试文件 52 项通过（scanner、adapter、preview、FileDiffBlock）。
- 临时恢复忽略参数增量的旧行为，新增节流回归测试失败；恢复后通过。
- Shared 与 Desktop App 依赖构建、Desktop renderer/main 类型检查、Renderer 和 Electron 构建通过。首次类型检查发现 Desktop App 旧 dist 缺少已有导出，重建后解决。
- 扩展 App suite：20 项失败 / 9 项通过，主要为找不到发送消息按钮；移除本次 App 字段透传后，发送消息单项仍出现同样失败，确认该失败不由本次字段透传引起；其余失败未逐项归因。
- 浏览器显式临时组件页确认浅深主题下生成、字符量、保存及完成态。真实 Electron 应用身份无法由 Computer Use 解析，真实 Provider 流式写入仍需人工验收。
