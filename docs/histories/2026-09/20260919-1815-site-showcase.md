# 首页图文联动、文档配图占位与浅紫引用

## 用户诉求

按已确认的 SHOWCASE_PLAN 修改页面，真实图片先占位；用户随后按清单手动截图并交给 Agent 整理。

## 改动

- 首页从两组功能扩展为上下文、工具执行、Review、Skills、只读子 Agent、会话轨迹六组，补充八项能力链接。
- 桌面 1100px 起左文右图，图片 sticky 随段落渐变；窄屏和无脚本顺序展示。减少动效、焦点优先、非活动图片 inert 均已处理。
- 新增统一 Screenshot 组件与截图文件名目录；首页旧产品图片改为明确占位，等待同名原始素材。
- 24 篇文档接入截图位，覆盖清单全部 35 个独立文件名；按页面复用共 40 处。补充自定义模型推理、后台会话与轨迹入口的实际操作说明。
- 文档和博客普通引用共用浅紫语义 token、3px 左边线与紧凑段落间距；截图占位使用中性虚线，独立于引用。
- 真实正文图片支持键盘打开、Escape 关闭与焦点返回。修复文档目录从窄屏切回桌面后保持关闭的问题。
- 清理首页本轮替换后不再使用的 feature、principles、image-button 样式；保留其他既有工作区改动。

## 验证

- Site check 无错误、警告或提示；既有 23 项测试通过；静态构建 44 页通过。
- 临时 Playwright 验收覆盖六段滚动切换、sticky 边界、键盘焦点、reduced-motion、1000px / 390px 布局、无脚本六张图可见、引用、占位、图片放大及 Escape；无 pageerror。
- 1440px 首页、390px 首页和1440px引用区已目视检查；跨断点的目录恢复检查通过。
- 35 个文件名与清单及文档占位集合完全一致；无旧 blockquote 截图占位。
- 只截取本地网站验收画面，未代拍桌面产品素材。后续真实图片裁切与呈现仍待用户交图后检查。
