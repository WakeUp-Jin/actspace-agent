# 更新 8 月功能发布记录

## 用户诉求

根据当前 `main` 与近期 histories，先更新 release 文案；Site 首页和产品截图留待后续单独调整。

## 主要改动

- 扩展 2026-08-01 发布条目，并将标题调整为“本地 Agent CLI、分析观测与更快的桌面工作台”。
- 将 CLI 介绍压缩为两条用户结果，避免实现细节占据主要篇幅。
- 汇总分析观测、图片输入与分析、全局快捷唤起、本地分支、Review、Artifacts 和运行反馈等近期用户可见能力。
- 补充图片预览、Review 滚动与状态同步、文件产物和分析会话索引相关问题修复。
- 不修改 Site 首页结构、文案或截图资源。

## 设计动机

Release 应按用户可感知能力归并，而不是逐条复制 commit 或 history。首页承担长期产品定位，更新日志承担近期功能完整性，因此本轮先收口 release，避免在没有当前产品截图时提前重做首页展示。
