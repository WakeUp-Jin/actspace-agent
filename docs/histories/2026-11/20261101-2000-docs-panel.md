### 📥 User Query

> 执行功能减法 P4：右侧「文档」面板取代工作区文件树，只列 Markdown，支持预览 / 源码编辑 / 保存、绿点与「本会话改过」筛选、按文件名搜索、新鲜度提示；把「文件」标签改名「文档」、「Review」改名「改动」。

### 🛠 Changes Overview

**Scope:** `@actspace/shared`、`@actspace/desktop`（main + renderer）、`apps/site`、`docs/`

**Key Actions:**

- **新增两个 IPC**: `workspaces.listMarkdownFiles`（git 仓库走 `git ls-files`，否则有上限的遍历，最多 5000 篇）和 `workspaces.writeMarkdownFile`（只写已存在的 Markdown，realpath 包含校验，临时文件加 rename）。契约、guard、handler、服务和单测齐全。
- **新增文档面板**: `components/right-panel/docs/` 下的面板外壳、正文区、目录树、大纲浮层、源码编辑器（原生 textarea，Tab 缩进、⌘S 保存）、离开确认对话框，以及树模型和两个 hook（清单、草稿 / 保存 / 新鲜度）。状态放进 `RightPanelContext`，Tab 类型 `markdown` 换成唯一的 `docs`。
- **渲染**: `MarkdownRenderView` 只留 `MarkdownPreviewBody`，块级 memo 分块、闭合 mermaid 围栏复用聊天区组件、宽表格横向滚动、网格列 `minmax(0, 1fr)`。
- **入口收敛**: 交付卡和聊天里的 Markdown 链接经 `open-workspace-path.ts` 打开文档面板并选中、展开到文件。
- **展开面板**: `SplitView.rightExpanded` 让右栏盖住聊天区（主区折成 0 宽但保持挂载）；文档 Tab 有自己的默认宽度 720px。
- **删除**: `WorkspaceFileTree.tsx` 和 `listDir` 整条链（契约、guard、handler、服务、mock、测试）。
- **改名**: 「文件」→「文档」，「Review」→「改动」（菜单、启动页、标签、测试断言、站点文档）。
- **脚本与基线**: 原生按钮基线加 `DocsTree.tsx: 2`、`WorkspaceOperationBar.tsx` 降到 1、删 `WorkspaceFileTree.tsx`。
- **文档**: 规范改「已实施」并补实施位置；右侧面板与布局规范、站点 `file-preview.md`、`review.md`、更新日志同步。

### 🧠 Design Intent (Why)

文件树要同时服务代码、日志、CSV，但这些文件已经交给系统默认应用，应用内真正需要阅读和修改的只剩 Markdown（人和 Agent 共用的语言）。把入口收成一个只做 Markdown 的面板，目录树只列 Markdown，既省掉通用树的目录列举、缓存和多种渲染，又让「读、改、保存」在同一个地方完成。属于「架构优化」第一步功能减法（`docs/design-docs/架构优化/01-功能减法设计.md` 第 3 节），规范见 `docs/design-docs/frontend/front-文档面板规范.md`。
