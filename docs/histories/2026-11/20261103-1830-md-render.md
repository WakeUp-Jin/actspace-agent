### 🛠 Changes Overview

**Scope:** `apps/desktop/src/renderer`（`markdown-editor/`、`markdown-common/`、`messages/markdown/`、`right-panel/docs/`、样式、mock、测试）、`docs/`

**Key Actions:**

- **文档面板**:
  - 预览和源码换成同一个 CodeMirror 6 实时预览编辑器：光标所在元素露出 Markdown 标记，可直接编辑；
  - 两种模式共享撤销栈；
  - 支持 ⌘S、未保存圆点、磁盘变化提示条、行号跳转、大纲。
- **聊天区**:
  - `MarkdownProse` 重做为 remark/rehype 管线：「A 书页」排版、五种提示框、公式、全局脚注、原始 HTML 白名单、远程图片不加载、路径带行号可点；
  - 流式平滑输出，末尾渐显；代码块不回缩，流式写过的长代码落盘后不折叠。
- **共享**: `markdown-common/` 的路径识别、提示框定义和 KaTeX 加载，两边共用。
- **层叠桥接**:
  - CodeMirror 运行时主题不在 CSS layer 里，压过 `layer(components)` 里的编辑器样式；
  - `core/layer-bridge.ts` 用 `revert-layer` 把冲突属性交回样式文件。
- **删除旧实现**: `MarkdownRenderView`、`MarkdownSourceEditor`、`.markdown-doc`。
- **验收**:
  - desktop 2663 项测试与前端检查通过；
  - 1MB 文档打开 ≤ 43ms、按键 p95 ≤ 12.5ms；30KB 回复流式每次提交中位 1.7ms（原版 20ms）；
  - Codex 原生 CUA Electron 验收 15 通过 / 0 失败 / 2 局部未覆盖。

### 🧠 Design Intent (Why)

- 文档面板要做到“看到的就是能编辑的”，所以预览本身可编辑，不另做一套渲染器。
- 聊天区重做是为了解决几个问题：流式输出时代码块跳动和回缩，路径点不开，GFM 提示框、公式、脚注显示不对。
- 两边的路径和提示框规则放在同一处，避免各写一套后出现差异。
