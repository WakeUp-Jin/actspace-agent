### 🛠 Changes Overview

**Scope:** `@actspace/shared`、`@actspace/client`、`@actspace/prompt`、`@actspace/session-jsonl`、`@actspace/desktop`

**Key Actions:**

- **空思考块**: 新增 `hasVisibleText`（去掉空白和 U+200B–U+200D、U+2060、U+FEFF），会话投影、流式块、`ThinkingBlock` 都用它判断思考内容是否可见。
- **mermaid 提示词**: 输出选择和 Chat 身份里说明聊天回复的 mermaid 围栏会渲染成图，不要为画图生成 HTML/图片文件。
- **流式跳动**: 贴底状态只由用户向上滚动（scroll 方向 + 向上滚轮）改写；ResizeObserver 只建一次；流式这一轮里 mermaid 保持代码块、表格固定列宽；assistant / thinking 新块只做透明度动画；消息区 `overflow-anchor: none`。
- **内存**: `SessionInspection` 不再携带 `rawBytes`，改为 `contentDigest`（SHA-256）；repair 重读文件比对摘要；删除无调用方的 `exportCanonicalJsonl`。

### 🧠 Design Intent (Why)

- `"​".trim()` 不为空，中转站发来的占位内容绕过了三处判断。
- 程序写 scrollTop 后内容可能又涨了，离底部的距离不能反推出用户离开底部；块高度突变（mermaid 变图、表格列宽重排）会放大跳动。
- inspection 是读完整个 journal 的临时对象，只需要摘要，没必要让几十 MB 的 Buffer 跟着它存活。
