### 🛠 Changes Overview

**Scope:** `packages/agent-core`, `docs`

**Key Actions:**

- **[Bash Definition]**: 新增 Bash 工具 definition，明确 Bash 的适用范围和 Read/Search/Edit 的负面指引。
- **[Permission Check]**: 新增单文件 `permissions.ts`，支持空命令、控制字符、Unicode 空白、危险删除、eval-like 调用、cwd 边界和 timeout 清洗。
- **[Executor]**: 新增非交互式 Bash executor，捕获 stdout、stderr、exitCode、duration、timeout 和截断状态。
- **[Render Result]**: 新增 Bash 结果渲染，供 LLM 上下文读取命令、cwd、退出码和输出。
- **[Registration]**: 将 Bash 注册到 `createToolManager()`，并导出工具、权限和结果类型。
- **[Tests]**: 覆盖 allow、deny、ask、cwd 拒绝、成功执行、非零退出、超时、渲染和注册。

### 🧠 Design Intent (Why)

Bash 是高风险但关键的开发工具。首版把权限检查、执行和结果结构化放在后端工具层，同时复用已有 ToolScheduler 的 `allow/deny/ask` 三态。审核 UI 与进程恢复暂不接入，避免把工具本体和前端审批流程耦合在一起。
