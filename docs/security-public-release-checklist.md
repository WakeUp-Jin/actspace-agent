# 公共发布前安全清单

这份清单用于仓库准备公开到 GitHub 之前的最后一轮安全检查。目标不是做一次性扫描，而是把“什么能进仓库、什么绝不能进仓库”固定成可重复执行的检查项。

## 必查项

### 1. 密钥与环境变量

- 确认没有真实 `.env`、`.env.local` 或其他本地覆盖文件被 Git 跟踪。
- 确认 `.env.example` 只包含示例值、默认值和说明，不包含真实密钥。
- 确认仓库文本里没有直接粘贴 API key、token、私钥或认证头。
- 确认运行时配置只通过集中入口读取，不在业务代码里散落直接访问敏感环境变量。

### 2. 忽略规则

- 确认 `.gitignore` 覆盖本地环境文件、日志、缓存、构建产物、依赖目录和临时文件。
- 确认任何平台生成文件都不会默认被纳入版本控制。
- 确认工作区里已有的未跟踪敏感文件不会因为路径变体绕过忽略规则。

### 3. 日志与运行产物

- 确认 `logs/`、调试日志、turn 运行日志和临时输出都不会提交。
- 确认运行时日志不会默认打印密钥、鉴权头、完整外部请求体或完整敏感上下文。
- 确认构建产物目录不会被提交。

### 4. 历史与文档

- 确认 `docs/histories/`、`docs/releases/`、README 和安全文档里没有真实密钥、真实账号、真实内部域名或本地绝对路径泄露。
- 确认示例和截图不会意外暴露个人数据、会话内容或调试信息。

### 5. 运行时边界

- 确认 renderer 不直接接触敏感环境变量或文件系统。
- 确认 shell / tool 执行不会把整套环境无脑扩散到不需要它的子进程。
- 确认外部 provider 的错误信息只保留必要诊断，不把敏感请求内容回显到界面、session 或日志。

## 快速检查命令

```sh
git status --short
git ls-files | rg '^\.env|(^|/)\.env(\.|$)|(^|/)logs/|(^|/)dist/|(^|/)dist-electron/|(^|/)node_modules/'
git grep -n -I -E '(sk-[A-Za-z0-9_-]{20,}|AKIA[0-9A-Z]{16}|ghp_[0-9A-Za-z]{36}|github_pat_[0-9A-Za-z_]{40,}|BEGIN (RSA |OPENSSH |EC |DSA |PRIVATE )?PRIVATE KEY)'
git check-ignore -v .env .env.local .env.development.local logs/latest-dev.log
```

## 发布前结论

- 只要 `.env` 没有被跟踪，且没有真实密钥落在文档、日志、快照或测试里，就可以继续公开。
- 只要日志目录和构建产物目录都被忽略，仓库本身就适合公开维护。
- 如果检查时发现一次性写入了真实密钥或本地路径，先清理再公开，不要靠“后面提醒大家别看”。
