- 本地非空src图片均完成且naturalWidth>0。各页唯一空src img来自MediaViewer的未打开dialog占位（组件源码已核对），不作为破图；对话框放大/关闭交互尚需另验。线上相同空src现象，已加载的非空src图片同样无失败。
