# BUG-029：工作树来源提示的键盘可达性

> 当前授权（2026-10-23）：全部 Bug 可直接修复，无需逐项审批。以下原始建议中的暂缓限制已失效；实施与复验状态以 [Bug 索引](../bugs/README.md)和[修复执行记录](../../20261022-acceptance-bugfix/execution-summary.md)为准。

- 问题：工作树状态行来源标签是不可 Tab 聚焦的普通 `span`，键盘用户无法触发规范要求的来源提示。
- 证据：真实 Electron 中从 Composer 按 Tab 32 次跳过该标签；DOM `tabIndex=-1`。Hover 的 `title` 显示“原工作区：committed · 基于 feature-fixture”。完整事实与证据见[Bug 记录](../bugs/BUG-029.md)。
- 涉及模块：Composer 状态行、共享 tooltip/焦点呈现约定、对应 frontend workspace/worktree 规范。
- 当前推荐：让只读标签可被键盘聚焦，并以现有共享 Tooltip 在 focus/hover 时显示相同来源；保留非按钮语义，添加主题感知的焦点样式。避免仅增加 `tabIndex` 但仍依赖原生 `title` 的修改。
- 理由：符合已写明的 hover/focus 行为，也保持该标签不代表可执行操作。
- 风险与回归：Composer 焦点顺序变化、窄窗布局、主题可见性及辅助技术名称。需实测 Tab/Shift+Tab、hover/focus一致性、非按钮语义、浅深主题和窄窗。
- 状态：建议尚未实施；验收期间只记录，全部验收和汇总结束后再讨论。
