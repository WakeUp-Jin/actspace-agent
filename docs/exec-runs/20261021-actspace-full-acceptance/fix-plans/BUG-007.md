# BUG-007 建议：显式恢复异步模型获取入口的焦点

状态：[x] 已实施并于2026-10-23复验关闭；下列为原建议，实际实现与原生证据见[Bug记录](../bugs/BUG-007.md)。当前全部Bug均可直接修复，无再次审核要求。

- 证据：[Bug 记录](../bugs/BUG-007.md)。
- 推荐方向：先核对异步获取前后 activeElement 及 Dialog 的 opener 捕获值。若确为触发器等待期间失焦，优先在模型模块持有触发按钮 ref，复用 DialogContent 已有 returnFocus，不修改所有 Dialog 的默认行为。
- 涉及模块：ConnectionDetailPage / FetchModelsDialog，复用共享 Dialog 的现有能力；若证据显示共享恢复生命周期存在问题，再评估更广范围。
- 理由与备选：显式目标更符合异步弹窗的发起入口；新建连接自动弹窗、原按钮卸载或路由改变时需有可用退路。若复核推翻该原因，重新定位，不能把 ref 补丁当已证实修法。
- 风险与回归：恢复到已卸载/禁用节点、焦点穿透或自动弹窗目标不合理；复验鼠标/键盘、Esc/取消/成功添加、慢网络、窄窗及其他共享 Dialog 代表用法。
