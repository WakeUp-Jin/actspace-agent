## 2026-10-23 修复与最终复验

- 根因：Go 在叶节点滚动前累计祖先 iframe 偏移；叶节点 `scrollIntoView` 会带动祖先滚动，使缓存偏移过期。原固定视口诊断中祖先滚动改变47px，旧坐标点击未命中，重新测量坐标可命中。
- 修复：保存 frame 路径及执行上下文，叶动作准备完成后再读取各层当前位置；最终 `frame_offset` 使用 `scrollIntoView:false`，禁止测量再次改变布局。覆盖普通 point 与 set_checked，失败关闭、不修改调用参数。Injected runtime 升级6，生成哈希 `66b25c69fb70`。
- 回归：Go 的单/双层 frame × point/set_checked 共4个新增场景修前失败、修后通过；runtime 的最终测量不滚动断言修前失败。修后 Go 全包及 `pnpm check:browser` 通过。
- 真实扩展链路：独立 Chrome155/profile、官方 acceptance fixture，经 RuntimeV2BridgeClient → Socket → Go NativeHost → 扩展执行原 `frame_path: #cross-origin-frame`、role button/name Frame action；两次独立 reload 均从 `frame-idle` 变成 `frame-clicked`，2/2通过。没有仅凭RPC成功判定，也不声称原生 Computer Use 验收。
