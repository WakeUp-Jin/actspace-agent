## 根因与修复记录

Mermaid dialog 打开时把初始焦点放到关闭按钮。`IconButton` 默认会在获得焦点时显示 Radix Tooltip；Tooltip 位于 Dialog 之上的 dismissible layer，会先消费第一次 Escape。原测试还验证了“第一次 Esc 只关闭 Tooltip、第二次才关闭 Dialog”，因此它把错误行为固定了下来。

修复只在 Mermaid 预览的初始焦点关闭按钮上设置 `tooltip={false}`，保留完整 `aria-label`，让单次 Escape 由 Dialog 关闭预览并恢复触发按钮焦点。没有增加全局键盘监听，也没有更改共享 Dialog 行为；其他工具按钮仍保留 Tooltip。
