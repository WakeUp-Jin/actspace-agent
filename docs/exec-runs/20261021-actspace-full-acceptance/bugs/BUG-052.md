1. 创建官方 DeepSeek 连接，服务余额返回 CNY 12.34，详情显示 `余额 ¥12.34`。

规范依据：`front-模型设置页面-Maka重做规范.md` 的远程余额独立加载、失败靠近受影响内容且保留重试入口。连接的“未测试”不是余额错误反馈。

## 根因、方案与影响

`ConnectionDetailPage.tsx` 的 `BalanceNote` 将 `getBalance` rejection 用 `.catch(() => undefined)` 静默吞掉；组件只有余额结果，没有失败或重试状态。服务层正确将 HTTP 500 作为异常上抛，根因在 renderer 状态缺失。

修复方案：在本地余额组件增加独立加载/失败状态及重试计数；失败就地显示安全固定文案和重试按钮，不展示远端原始错误；复用 Effect 清理，阻止卸载或连接变更后的迟到响应污染新状态。不改连接保存、Provider 协议或账户语义。

回归范围：失败反馈、同页重试成功、重试进行中防重复、离开页面后的迟到响应、原有成功/不支持余额路径；模型设置测试、Desktop 类型/构建及主题门禁；冻结新构建后由 Sol/high 真实 Electron 按正常→500→重试失败→恢复重试路线定向复验，覆盖浅深主题与键盘焦点。
