## 当前推荐方案（仅记录）

建议明确区分长期工作区选择/侧栏归组目录与当前会话有效执行目录，由工作台向 Review、文件树、文件读取和终端提供一致的当前执行目标；已打开对象的去重与缓存身份也应含真实 root/Host，避免只在某次打开函数上替换参数。优先复用已有会话 worktree 元数据，不在 renderer 再推导路径或修改持久化工作区绑定。

理由：修正一个 Review 查询不足以覆盖同屏文件树、预览及后续 Git 操作；直接把长期工作区选择状态改成 worktree 又可能影响新建页和侧栏归组。具体抽象与归属在整体验收后讨论，本轮不实施。

风险与回归：普通/工作树/远端会话往返，Review 摘要与详情相同目录，文件树/预览/刷新、对象 Tab 缓存及重复打开，终端 cwd 与 Git 写操作目标，新建页选区和正常重启。仅在专用仓库定向复验写操作，不在验收中尝试产品仓库的提交、丢弃或修复。
