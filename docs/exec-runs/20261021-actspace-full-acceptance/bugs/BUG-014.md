## 修复与关闭证据（2026-10-23）

根因是大文本为所有逻辑行挂载 DOM，切入和卸载成本随行数增长。修复采用可视区域渲染，保留完整预览文本的选择/复制语义；自动回归与实现见修复执行记录。相同 5.25MB 样本的真实 Electron 原生点击复验：旧构建冷开 3778.2ms、切回 2163–8827ms；新构建冷开 191.7ms、五次切回 141.9–163.6ms、关闭 147ms。口径为点击到 DOM 静默 100ms 再两帧，不能当作纯 React 耗时。DOM 约四万降至约五百。

[原生报告](../../../../tmp/codex-acceptance/20261022-acceptance-bugfix/cua-bc/REPORT.md)及同目录 `h014-*` 证据证明：首/中/尾真实滚动，整窗 480 CSS px 浅深主题、软换行和行号均正常；Cmd+A 和 Shift 全选复制逐字等于 2,097,104 字节的完整行预览；Unicode 全文 140117 字节、组合重音双击及跨未挂载行 Shift 扩展复制逐字正确。截断提示明确显示前 2.0MB 完整行与完整文件大小。

现有原生接口不能表达持续按住鼠标并跨屏滚动的手势，该扩展手势仍未覆盖；不将拖选后滚动加 Shift 扩展冒称同一手势。性能复合项的流式恢复采样和最终整合 T4 也继续保留未覆盖。
