## 复现与结果

1. 设置 → 模型 → 自定义验收连接，打开获取可用模型对话框。
2. 第一次按 Esc：对话框关闭，设置仍在，符合预期。
3. 第二次独立按 Esc，再读当前状态：设置仍在，焦点为 BODY；按原 16-A6 要求应退出设置并返回正确焦点。

## 原推荐方案（发现时记录）

建议在设置导航所属层定义一个明确的键盘返回动作：当更上层浮层未消费当前 Esc 时调用现有 `onBack`，回到进入设置前的会话和触发位置。关闭弹窗的同一次按键不能继续穿透退出设置；模型编辑区、Select 和未保存表单继续遵守各自取消边界。先复核应用级快捷键注册与浮层消费约定，再决定放在页面还是导航控制器，不直接给多个组件各加 document 监听器。

推荐原因：复用现有导航返回路径能保留会话选择与草稿归属，集中定义 Esc 层级可避免一次按键关闭多层。风险是影响输入取消、Select、嵌套对话框和未保存表单，需在确定交互契约后实施。

定向复验应含：从会话进入设置、两次独立 Esc、Select→Dialog→设置分层、编辑取消、鼠标返回、触发器卸载和窄窗；分别留键盘焦点与原生可访问性证据。未实施、未讨论方案。

## 2026-10-23 修复及关闭
