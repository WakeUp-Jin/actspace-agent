## 根因与修复

`packages/client/src/sessions/chat.ts` 的聊天事件投影只从 `step/end` 与 `llm/retry` 产生轮尾统计事件，遗漏独立 `llm/auxiliary-end`。现消费辅助终结事实，以 attemptId、实际 route/model 及所属 Run/Turn 产生一次用量投影。显式0保留，失败/取消已报告消耗保留；全未知或未终结尝试不伪造0。既有 Activity、全局及会话累计消费者已处理辅助事件；Web 复用同一 client，无另一份聊天用量投影。
