## 复现与根因

在隔离会话发送受控 Markdown，原生点击脚注1后定义仍在视口下方（y1807，视口865），滚动未跳至定义；回链也没有跳转。HTTPS 外链原生打开系统 Chrome 正确，Electron 保持唯一窗口和原 URL。证据：`tmp/codex-acceptance/20261021-actspace-full-acceptance/markdown-native-20261023/`，包括 `03-footnote-click.png`。

`MarkdownLink` 仅排除工作区相对文件，其余链接统一 `_blank`，因此 `#user-content-fn-*` 也进入 Electron 新窗口保护，file URL 被安全外开层拒绝。应修正文链接分类，不放松导航安全策略。
