- 预期：正式夹具可使用当前 Settings API 生成仅含合成凭据的配置并启动。
- 实际：`seed-settings.ts:2:43` 导入不存在的 `packages/shared/src/custom-model-input`，构建报告 `Could not resolve`，夹具无法到达 ready。
- 复现频率：一次实际启动失败；当前源码和缺失路径已再次只读确认。未为重复计数再启动已知失败夹具。
