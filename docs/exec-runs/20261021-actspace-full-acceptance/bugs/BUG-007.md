- 状态：[x] 已复验关闭；自动回归及真实 Electron 原生交互通过（2026-10-23）。
- 严重程度：P3，键盘焦点恢复问题，不阻止鼠标获取模型。
- 所属阶段与验收点：F1-10 获取模型；P2-D20 焦点返回。
- 方法与版本：gpt-6.1-sol 通过 Playwright 操作真实 Electron 固定 dist；主仓库 fix/settings-model-select，HEAD 00d6b763 加本轮未提交实现。独立 profile，Electron PID88356。

## 复现与结果

1. 设置 → 模型 → DeepSeek 连接详情，点击“获取可用模型”。
2. 等待真实列表弹窗出现，按 Escape。
3. 弹窗关闭；预期焦点回到“获取可用模型”触发按钮，实际 document.activeElement 为 BODY，aria-label 为 null。
- 同实例有限复核两次一致；不将整个设置页或所有 Dialog 判为失败。
