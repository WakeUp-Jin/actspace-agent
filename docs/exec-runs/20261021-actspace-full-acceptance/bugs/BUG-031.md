## 复现与结果

1. 在隔离工作区通过 UI 创建工作树 A / B 并分别发起会话。
2. 选择工作树会话并打开工作区环境信息。
3. 实际提示 `get-workspace-environment: workspaceRoot is not registered`；预期读取该本地会话的实际工作树目录，不要求把每个工作树额外加入“最近工作区”。

## 根因与修复

`fixed-renderer-ipc.ts` 的环境只读 handler 调用 `registeredWorkspaceRoot`，而工作树目录由本地会话持有，不在 registry 中。改为复用 `resolveWorkspaceAccess`，允许 registry 或本地会话 root，经 realpath 比较，继续拒绝无关目录。Git 写操作和会话准入保留原边界，不顺带扩大权限。
