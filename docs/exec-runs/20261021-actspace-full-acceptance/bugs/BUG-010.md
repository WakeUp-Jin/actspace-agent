## 2026-10-23 修复与复验

根因已确认：locator 的 label-name 计算递归纳入了被标注控件子树中的选项文本，导致 `<select>` accessible name 被扩展为“Color Red Green Blue”，exact `Color` 无法匹配。修复调整 label 文本计算，排除控件自身子树，同时保留 ARIA 命名优先级与正常嵌套标签语义。

新增永久回归覆盖显式 `for`、嵌套标签、多选项、ARIA label/labelledby 优先级、重复标签歧义、空白规范化及 open Shadow DOM；修前 Color exact 用例失败（实际 matches=0），修后通过。Browser Bridge 全包与相关检查日志：`tmp/codex-acceptance/20261022-acceptance-bugfix/g010-red.log`、`g010-browser-check.log`。

真实交互复验使用隔离 Chrome 155、当前工作树构建的 Go NativeHost 和扩展，动作经 Runtime bridge → socket → Go command engine → NativeHost → Chrome 扩展 → 真实页面。G010 逐项 10/10 通过，包括原始 Color exact、Green 选择及 Apply 副作用；CSS 对照、嵌套/多选、ARIA 优先级、重复匹配拒绝、Shadow DOM 和全量事件/状态核对。详见 `tmp/codex-acceptance/20261022-acceptance-bugfix/g010-live/report.md` 及同目录 `actions.json`、`checks.json`、`049-screenshot.jpg`。
