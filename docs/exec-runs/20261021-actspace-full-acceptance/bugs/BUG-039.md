## 证据与根因

原生录制、启停、目标保存均成功；从 Finder 注入组合键后尚未形成可证明的 OS 回调闭环，保留未覆盖。原生报告：`tmp/codex-acceptance/20261021-actspace-full-acceptance/quick-open-native-20261023/report.md`。

源码确认两个独立于系统派发的缺口：main 注册回调只有 restore/show/focus，未执行既定约640px、鼠标所在屏幕居中；renderer 消费请求后只选会话并增加聚焦计数，WorkbenchLayout 自有的 Settings/trajectory 状态没有回到 chat，输入区可能没有挂载。

## 修复方案与边界

1. 将既有窗口展示动作提取为可测试的 main helper，先保留原行为，补窗口几何回归并确认失败。随后按鼠标屏幕 workArea 收敛宽度640px、限制高度并居中；恢复最小化/最大化/全屏时序后再发送既有 IPC 意图，继续复用同一主窗口。
2. 在 WorkbenchLayout 消费已有的快捷唤起聚焦序号，将页面及当前会话主视图切回 chat，关闭紧凑覆盖层；只有新唤起才触发，普通切页不改变用户轨迹偏好。补真实 App/bridge 事件回归，覆盖同会话 Settings 和 trajectory，保证草稿不丢失、不自动发送。
3. 定向测试、类型检查、构建后由 `gpt-6.1-sol` 复验。系统按键派发、handler/IPC 测试和真实 UI 分开报告；没有真实系统证据不得关闭该子步骤。

不新增窗口、不读取剪贴板、不改变目标解析、注册协议及用户安装版。
