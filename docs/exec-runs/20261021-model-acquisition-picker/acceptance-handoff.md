# 验收交接：获取可用模型与连接详情 V3

在 Electron 里用真实 Key 逐项确认（分支 `fix/settings-model-select`，未提交）。

1. **新建官方连接**（Kimi 或 OpenRouter）：填 Key 点「连接」后进入详情页，弹出「选择要添加的模型」，一个都没勾；勾两个点「添加 2 个」，列表出现这两张卡片并闪一下。
2. **再次获取**：点「获取可用模型」，已添加的两个打勾置灰并标「已添加」；搜索、全选只影响未添加的行。
3. **中转站没有 `/models`**：新建自定义中转后出现「没拿到模型列表：…」，下面自动展开手动添加；输入 `gpt-5` 能认出并填好，添加后出现在列表。
4. **手动添加变体**：输入带日期后缀的 ID（如 `claude-haiku-4-5-20251001`），显示「按 Claude Haiku 4.5 填好了」；点「不是它」后字段清空。
5. **移除与撤销**：移除一个模型，原位出现撤销条，说明影响的用途；点「撤销」恢复；再移除一次等 8 秒，确认真正删除，「用途」里改为跟随会话默认。
6. **内置模型可移除**：移除内置连接的某个模型，再从「获取可用模型」加回来。
7. **迁移**：用旧设置（有停用模型）启动，停用的模型不见了，指向它们的用途变为跟随会话默认。
8. **连接字段**：改名称、服务地址、代理后失焦，框内出现「已保存」；粘贴新 Key 后出现「取消 / 保存」；内置连接名称不能改。
9. **深色 / 窄窗**：深色下弹窗和卡片正常；窗口缩到 600px 以下时字段变一列，删除按钮常驻。
