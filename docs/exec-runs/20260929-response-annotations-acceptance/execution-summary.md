## 2026-09-30 B01 修复复验

根因：Escape 恢复编号焦点触发 Radix 延迟打开；此外先前排队的打开回调也可能在关闭后抵达。旧测试只断言焦点返回，未断言延迟后卡片保持关闭。

修复：ResponseAnnotationPopover 记录 Escape 主动关闭，阻止旧打开请求及恢复焦点的自动打开；新的点击、指针进入或离开后重新聚焦恢复正常预览。未修改共享 HoverCard。
