## 问题

1. **CU-01（P2）压缩中无法取消。** 摘要请求保持时，停止按钮disabled，Escape无效；后端已有取消信号，前端仍沿用不可中止假设。
2. **CU-02（P2）自动压缩失败的终态没有持续提示。** 6次受控摘要HTTP400后主运行正常结束，界面没有压缩失败/重试提示。未观察提示消失过程，只确认终态缺失。

复现、源码定位和本地截图见 [问题记录](issues.md)。首次附加图片后输入文字未带附件只能列待复现；第二次直接发送图片已在UI、JSONL、正式附件和模型输入四侧确认成功。

## 已确认的主要链路

- 工具Step完成后 Context 增长；工具批次结束后触发自动压缩。摘要/Surface替换持久化后才发下一请求，该请求含新摘要；面板显示压缩后占用下降及下一Step。
- 移走**隔离目录**SQLite后，Session事实文件哈希不变；重启恢复会话目录、标题、Todo、轮步状态，并可继续执行；Context索引按需追赶（最终199条请求记录）。
- 生产存储接口创建的图片样本，重启后真实界面显示并可打开预览。UI直接上传的另一张图片提交成功，但未再重启验证它。
- 现场新增路径UI可展开活跃列表，显示完整路径和睡眠空态。验收中有其他开发者HMR更新，不能宣称为冻结版本的全面回归。
