## 已实现

- Context 当前投影、最近请求 manifest 与 SQLite 历史分开管理，面板五区块接入真实数据；Composer 使用同源当前投影。Session 仍为事实来源，SQLite 可重建，不承担 Agent 授权。
- 模型/工具输出先持久化，再更新来源与 Context；每次模型请求保留独立输入基准。当前/历史分别版本化；分类总量不因分页变化；未知上限和未知压缩回收量明确显示。
- SQLite schema 9 增加独立 Context 历史、可恢复批次水位、building/published；单 Session 查询不枚举全部 Session，无新变化不重放事件。UTC offset、reset 边界与稳定游标已修复。
- renderer 可见时合并事件与条件探测，单在途，隐藏停止，丢弃迟到结果；明细、全文有界分页。live capability 不可用时历史可继续读取，不把历史伪称为当前。
- CU 发现并修复 Composer 接线、负数进度、Usage reset 热查询、取整差异、新建等待历史列表、窄窗焦点和设置页全量会话重放。设置的快速唤起目标改用按需索引搜索。
- 大 Session 发布复制补上 rowid 区间约束，避免每256行重扫排序整个会话。原子发布仍是一个 Session 事务，事务内公平调度与中断延迟仍是验收限制。
