## 阶段 P1：外观与布局（T1–T8）

### 用户能感知到的变化

- **外框**：低对比细边加柔和阴影，聚焦时边和阴影都加深。单行时是胶囊形，多行时 18px 圆角。
- **单行 / 多行**：
  - 单行是「+ · 模式 · 输入 · 发送」，模型按钮藏起来；
  - 输入折行、按 Shift+Enter 换行、加附件 / Skill / 回复引用时变多行，模型按钮出现在下面一行；
  - **变成多行后，删字不会变回单行，只有清空才会**（之前删回一行就跳回单行）；
  - 新建页始终多行，至少两行高；窗口窄于 600px 时始终多行；输入区最高 200px，超出在里面滚动。
- **Chat 的上下文用量**：从输入框里面移回输入框下方的状态行（右侧）。
- **`+`**：28px 无底圆形，悬停和菜单打开时有底色（原来是 36px 带浅底和描边）。
- **模式 chip**：24px、13px 字；只有右边的 × 能点（提示「回到 Agent」），名称部分不再是按钮；焦点在 × 上按 Backspace 也回到 Agent；退出后焦点回到输入框。
- **发送按钮**：28px（原来 32px）；Agent 黑（跟随强调色），Plan 黄，Chat 绿；停止按钮不变色。
- **placeholder**：Agent 新建页「描述你要做的事，@ 引用文件，/ 调用命令」，对话中「继续追问…」；Plan「描述要规划的改动…」；Chat「问点什么…」；运行中「继续追问，运行中发送会进入队列…」。
- **输入法**：中文 / 日文组字时，Shift+Tab、↑↓、Esc、Enter 都交给输入法，不会切模式、翻历史、关菜单或发送。

## 阶段 P3：`+` 统一面板与模型选择（T12–T15）

### 用户能感知到的变化

- 点 `+` 打开的不再是一列菜单，而是贴在输入框上方、与输入框同宽的面板：最上面是搜索框（打开就能直接打字），下面是模式（只列当前不是的那个；已经开始的 Chat / Plan 会话不列）、附件、Skills ›、模型 ›（写着当前模型名）。
- 在搜索框里打字会同时搜模式、附件、Skills 和模型，结果按「模式 / 添加 / Skills / 模型」分组；模型结果写着所属供应商。
- 键盘：↑↓ 移动（跳过不可用的行，首尾循环）；Enter 或 Tab 选中；→ 进入 Skills 或模型列表；搜索框为空时 ← 或 Backspace 回上一级；Esc 在子页回上一级、在主页关闭。
- Skills 页可以连续勾选多个，面板不关。模型页里，可调选项的模型行尾有「编辑」（键盘移到该行或鼠标悬停时出现），进去是 Thinking 和推理强度。
- 选完、按 Esc 关闭后光标回到输入框；点面板外面关闭不抢光标。
- 工具行的模型按钮：本机和远端同一个菜单。远端时只列 Host 上的模型、没有「编辑」，Host 还没回报模型时写「等待 Host 模型」；原来的「远端模型」下拉框删了。
- 输入框上的几个浮层（`+` 面板、模型菜单、上下文用量、新建页的三个下拉）同一时间只开一个，从一个点到另一个时新的那个直接打开。

## 阶段 P4：运行位置（T16–T19）

### 用户能感知到的变化

- **新建页的运行目标行**：工作区 ⌄ ／ 分支 ⌄ ／ 运行位置 ⌄ 三个无边框文字按钮，菜单统一为应用里的通用菜单（键盘 ↑↓ / → / ← / Esc、首字母跳转）。
  - 工作区：最近使用（名称 + 第二行路径）、使用已有文件夹…、新建文件夹（在菜单里直接输入名字）。
  - 运行位置：本机 ／ 远端机器 › ／ 新建工作树。远端机器子菜单列出所有 Host（状态点 + 不在线时的状态文字），底部「连接新机器…」；Host 达到 5 台时顶部出现搜索。没有配置 Host 时这一项是「连接远端机器…」，点了打开 设置 › Agent 服务器。「云端 / 远程 SSH · 即将推出」删掉了。
  - 选远端后：分支按钮消失，工作区按钮列这台 Host 上的工作区；Host 没就绪时运行位置按钮后面有状态点和短文案（连接中 / 离线 / 读取失败…）。离线、需要重新配对的 Host 也能选中，草稿照常编辑，发送按钮禁用并在 tooltip 里说明原因。
  - 原来远端时的三个原生下拉框（运行位置、远端工作区、远端模型）全部去掉。
- **发送 / 停止**：远端不能发送时，发送按钮的 tooltip 写 readiness 的原因（如「GPU 服务器 离线。前往设置重新连接」「无法读取机器信息：socket hang up」）。运行中 Host 掉线时，停止按钮也禁用并说明原因；Host 连着但还在读取工作区时可以停止。
- **对话中的状态行**：只读，没有下拉。
  - 本机「⑂ main · 💻 本机」，工作树「⑂ 分支 · ⑂ 工作树」，远端「🖥 Host · 📁 工作区」，后面是权限控件，右侧是上下文用量。
  - 远端 Host 名悬停显示状态和工作区路径。Host 没就绪时第二段换成状态点 + 短文案，上下文用量显示「—」。
  - Chat 会话的状态行只有上下文用量。

### 需要你判断的事项

> 2026-10-07 用户拍板：第 1 项选 **A**（维持现状，本机 Chat 新建页不显示运行目标行）；第 2 项选 **A**（禁用并写原因）。两项都不改代码，规范已与现状一致。

1. **新建 Chat 会话时的运行目标行**（T18）
   - 现状：本机 Chat 不显示这一行；远端 Chat 只显示「运行位置」一个按钮。
