Kairos 通知中心 · 交互方案对比

三个方案都满足：点铃铛 → 通知列表 → 点条目查看详情并标记已读。差别在「详情呈现的容器」。全部可点击交互。

方案 A · 锚定浮层 + 行内展开

现行方案的打磨版 · 最轻

点条目在列表内原地展开详情（手风琴），同时标记已读。不离开当前页面、无层级切换。适合详情较短（1–3 段）的通知。

主从式 · 详情空间完整
