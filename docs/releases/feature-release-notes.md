# 更新日志

这份记录只保留用户能够感知的新功能、改进和问题修复。实现细节、测试数据和内部重构继续记录在 `docs/histories/` 与设计文档中；这里不等同于正式版本号、Git tag 或远程发布通道。

## 2026-07

### 2026-07-29 — 开发计划与更清晰的官网标题

#### 新功能

- 官网新增开发计划页面，可以分别查看尚未完成和已经交付的主要功能，并保留已完成功能的完成日期。

#### 改进

- 首页、文档、博客与 404 页使用更简洁的展示标题，减少长句和句末标点，让页面层级更清楚。

### 2026-07-28 — 图片生成、DuckCoding 与更清晰的模型体验

#### 新功能

- 主 Agent 可以通过独立的 OpenAI-compatible 图片服务生成一张或多张图片，并把结果保存为可恢复的会话产物。
- 新增 DuckCoding 服务商，支持多把 Key、独立倍率、模型绑定，以及 Codex 与 Grok 本地模型档案。
- Composer、默认会话、轻量任务、Explore 和 Kairos 的模型选择器按服务商分组，跨服务商同名模型可以明确区分。
- 新增 ActSpace 官网、公开文档、工程博客和更新日志，并支持 GitHub Pages 静态部署。

#### 改进

- 生成图片、Write 和 Edit 的完成结果集中显示在回复下方的产物栏，可在右侧面板预览，并支持复制、定位和使用本机应用打开。
- 图片服务设置收敛为摘要卡片和配置弹窗；已保存的 Key 不回显，低频高级设置默认折叠。
- 模型长时间没有返回可见内容时会显示低干扰的运行提示，正文、Thinking、工具或审批状态出现后立即让位。
- DuckCoding Codex 模型会按推理强度选择网关实际模型名，单 Key 用户继续保持原有的简单配置流程。

#### 问题修复

- 修复开发态无法直接预览本地生成图片的问题，图片读取会经过会话目录边界和文件类型校验。
- 修复只有加密推理状态、没有可读正文时界面出现空 Thinking 块的问题。

### 2026-07-26 — 会话分支、执行反馈与可视化恢复

#### 新功能

- 现有会话可以分叉成一个独立继续的新会话，也可以复制会话 ID 或只包含可读消息的对话文本。

#### 改进

- 多个工具连续执行时，每个工具都会按自己的完成时间立即更新，不再等到整批工具结束。
- Bash 审批、拒绝和完成状态会明确说明命令是否执行，以及实际使用的沙盒或非沙盒环境。

#### 问题修复

- 修复回复可视化偶尔显示空白面板的问题；重新生成会真正绕过缓存，并只处理当前点击的回复。
- 修复 workspace 子目录递归删除无法进入正确审批流程，以及沙盒初始化失败时可能静默降级的问题。

### 2026-07-25 — 多供应商模型、费用透明与 Ink & Emerald

#### 新功能

- 可以同时配置 DeepSeek、Kimi 和 OpenRouter，并分别为主会话、轻量任务、Explore 与 Kairos 选择实际可用的模型。
- 模型选择器支持本地搜索；支持的 OpenRouter 模型可以选择推理强度，新增模型会立即出现在 Composer 中。
- 每轮回复、每日统计和会话明细可以查看 Token 消耗与统一的美元预估费用。
- DeepSeek、Kimi 和 OpenRouter 的账户余额回到各自服务商卡片中管理，OpenRouter 模型 Key 与管理 Key 分开保存。

#### 改进

- 桌面端迁移到 Ink & Emerald 语义视觉系统，浅色、深色和跟随系统主题拥有一致的文字层级、交互状态和数据配色。
- Browser 工具改为按需加载，Agent 默认只接收浏览器入口，需要操作网页时再展开完整工具组。
- Kairos 在尚未选择模型时仍可编辑配置，模型可用后当前进程即可启用，不需要重启应用。
- 模型、Review 和右侧面板补齐更明确的悬浮、选中、禁用与键盘焦点反馈。

#### 问题修复

- 修复 Write 文件预览在流式输出时错误抢占用户滚动位置的问题。

### 2026-07-19 — 失败任务可以直接沉淀为回归用例

#### 新功能

- Agent 执行失败或效果不佳时，可以在当前会话使用 `/eval` 生成带 fixture 的回归 Candidate，并导入独立评估仓库。

### 2026-07-17 — 更稳定的 Agent Turn、Browser 定位与后台任务

#### 新功能

- Browser Use 支持通过 role、accessible name、label、placeholder、test id 等接近真实用户语义的方式定位页面元素，并覆盖 Frame 和开放 Shadow DOM。
- 右侧对象面板新增 Files、Review、Context、Kairos 和 Reply 启动入口，关闭最后一个 Tab 后会回到对象选择页。

#### 改进

- 后台 Bash 默认有最长运行时间、单会话并发上限和重复任务复用规则，新 Turn 会向 Agent 提供仍在运行的任务清单。
- Browser 操作增加严格匹配、可操作性检查、自动等待和跨 Frame 坐标回算，长浏览器任务允许更多执行轮次。

#### 问题修复

- 修复流式回复重复、停止后不能快速继续输入、中断轮次重新进入后无法恢复，以及流式内容与持久化消息交接时闪动的问题。

### 2026-07-13 — Agent 能力开始可以被系统评估

#### 新功能

- 新增黑盒 Agent CLI、Docker-first 数据集运行器、确定性评分器、可选 Judge、单用例与数据集报告，以及 baseline 对比。
- 评估模式可以保存每次模型调用前的上下文快照，普通使用不会生成这些评估文件。

### 2026-07-12 — Browser 会话安全与输入编辑体验

#### 改进

- Browser 首次使用只需按会话授权一次，不同任务的标签页所有权相互隔离，任务结束不会关闭用户自己的页面。
- Browser 返回更完整的 DOM、工具说明和批量操作结果，并通过可见光标展示即将发生的页面操作。
- 长输入、长消息和 Composer 单行/多行切换保持稳定；用户消息可以折叠查看，长内容不会挤压整个会话。
- 文件修改预览以原始结构化结果为准，上下文压缩后仍能恢复；写到工作区外时可以单独请求授权。

### 2026-07-10 — Browser Use 全链路接入

#### 新功能

- 主 Agent 可以通过标准 Browser 工具操作真实 Chrome，完成读取、导航、表单、截图、标签页、下载、剪贴板和调试等任务。
- Browser Bridge、Chrome Extension、Native Host、Locator、可见光标和 Tab Group 在主仓库中形成完整链路。

### 2026-07-09 — 模型可以直接理解图片输入

#### 新功能

- 支持图片的模型可以直接查看用户附件、读取到的图片和工具生成的截图。

#### 改进

- 模型目录明确标记文本或图片输入能力，图片会按当前模型能力路由；纯文本模型会明确说明限制，不再暗中调用另一个模型代看。

### 2026-07-06 — 更可靠的网页读取与多供应商搜索

#### 新功能

- 新增本地 `web_fetch` 网页读取工具，以及覆盖中英文来源的多供应商 `web_search`。
- 设置页新增网络搜索供应商配置，可以分别管理多组搜索服务 Key 和额度信息。

#### 改进

- 搜索供应商遇到额度或认证问题时可以自动切换可用通道，网页读取不再依赖另一个模型猜测页面内容。

### 2026-07-05 — LLM 错误恢复与更稳的消息编辑

#### 改进

- 偶发模型网关错误会自动退避重试，并在界面显示当前恢复进度。
- 长用户消息默认保持紧凑，需要时可以展开；文件 diff 和工作区外写入拥有更清楚的预览与授权反馈。

#### 问题修复

- 修复模型最终失败后留下空白回复的问题，失败轮次现在会保存为可恢复的错误状态。
- 修复 Composer 输入布局和文件修改预览在部分长内容场景下不稳定的问题。

### 2026-07-04 — Bash 沙盒与可定制的 Kairos

#### 新功能

- Kairos 新增通知中心，重要发现可以集中查看并标记已读。
- 用户可以为 Kairos 选择或编写人格，并直接在设置页维护规则和任务表。

#### 改进

- Bash 默认在 macOS 沙盒中运行，常规命令减少打扰，删除、强制重置等不可逆操作始终要求确认，越界目标会直接拒绝。

### 2026-07-03 — 后台 Bash、文件监听与更主动的 Kairos

#### 新功能

- 长时间 Bash 命令可以在超时后转入后台继续执行，Agent 能读取增量输出、终止任务，并在任务结束时收到通知。
- 新增常驻文件监听插件；Kairos 和其他 Agent 可以通过 Skill 消费目录变化，插件与 Skills 可以在设置页管理。

#### 改进

- Kairos 醒来后会主动读取数据源、按场景规则行动并留下笔记，旧的轮询巡检入口被统一收口。
- 写文件完成后可以看到增加、删除和 diff 预览；Composer 粘贴大段文本时会自动增高。

#### 问题修复

- 修复 Bash 转入后台后落盘输出停止更新，以及超时退出时无法可靠返回已捕获输出的问题。

### 2026-06-14 — Apache-2.0 开源与更完整的工具输出

#### 改进

- 长工具输出压缩后会保留原始内容前缀，关键参数和错误细节更不容易被摘要稀释。

### 2026-06-10 — 多轮会话恢复与 Kairos 缓存优化

#### 改进

- Kairos 的稳定系统提示词与动态 tick 内容分离，缓存命中更高；Thinking、短期记忆压缩和模型上下文窗口能够正确恢复。
- Review 可以直接预览工作区中的图片文件。

#### 问题修复

- 修复只有第一条消息能够正常响应的严重问题，多轮历史重建不再打乱 Thinking、正文和工具调用顺序。

### 2026-06-08 — Kimi 备用模型与联网能力

#### 新功能

- 主会话可以选择 Kimi 作为备用模型，并使用 Kimi 的联网搜索能力。
- Usage 页面可以分别查看 DeepSeek 与 Kimi 的余额。

#### 问题修复

- 修复 DeepSeek 偶尔输出裸协议标记后污染对话的问题，此类响应会进入可恢复错误流程。

### 2026-06-06 — Explore 子代理与紧凑任务过程

#### 新功能

- 小范围代码探索可以交给更便宜、上下文隔离的 Explore 子代理，设置页可以单独选择其模型。

#### 改进

- 已完成的工具过程会折叠成一行 `Worked for Xs`，长任务不再铺满消息流。
- 会话按最近活动排序，首轮完成后会自动生成简短标题。

#### 问题修复

- 修复工具折叠后的执行时长总是显示为一秒，以及 Explore 首帧反馈不稳定的问题。

### 2026-06-05 — 本地更新、请求明细与模型选择修复

#### 新功能

- 设置页新增独立的本地更新流程，可以查看构建阶段，并在新包验证失败时保留可用旧版本。
- Usage 页面新增会话请求明细、Token 构成提示和分页浏览。

#### 改进

- Agent 重复读取未变化的同一文件范围时会返回简短提示，减少上下文污染，同时保留强制重读入口。

#### 问题修复

- 修复新会话选择的模型没有真正生效、Kimi 国内连接地址不合适，以及侧栏在窄宽度下横向滚动的问题。

### 2026-06-04 — Skills、Review 与可观察的 SubAgent

#### 新功能

- Agent 可以从项目与用户目录发现 Skills，在运行时按目录优先级加载，并在设置页查看启用状态。
- Review 新增变更来源、工具栏、对象菜单和图片预览原型，用于集中检查工作区修改。

#### 改进

- SubAgent 的运行过程、工具列表和完整 transcript 可以从主会话查看，完成后仍保持紧凑摘要。
- 会话悬浮卡可以快速预览 workspace、更新时间和最近消息。

### 2026-06-03 — SubAgent 协作、Kairos 收件箱与本地启动排障

#### 新功能

- 主 Agent 可以通过 Agent 工具把局部任务交给隔离的 SubAgent，主会话只保留摘要和 transcript 引用。
- Main Agent 与 Lab Agent 可以通过文件收件箱向 Kairos 留下后续观察信号。

#### 改进

- 本地 macOS 应用补齐 ad-hoc 签名、安装版启动日志和路径修复，双击启动时更容易排查问题。

### 2026-06-02 — 手动上下文压缩与完整会话管理

#### 新功能

- 用户可以输入 `/compact` 主动压缩当前上下文，并在消息流中看到开始、进度与完成状态。
- 新增专用 Delete File 工具，删除前展示目标并请求一次性确认，不再依赖高风险 Bash 命令。
- 会话右键菜单支持 Pin、Rename 和 Archive；附件支持发送、拖拽、删除、持久化和恢复。

#### 改进

- Workspace 选择在真正发送消息时才提交，切换目录不会提前污染空会话。
- 项目中的 `AGENTS.md` 规则由运行时统一加载，真实 Turn 与 Context 检查视图使用同一份结果。
- 工具行、图标按钮提示和侧栏会话状态更容易理解。
