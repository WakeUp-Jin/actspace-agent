# 更新日志

这份记录只保留用户能够感知的新功能、改进和问题修复。实现细节、测试数据和内部重构继续记录在 `docs/histories/` 与设计文档中；这里不等同于正式版本号、Git tag 或远程发布通道。

## 2026-10

### 2026-10-18 — 上下文与执行轨迹改进、DeepSeek 搜索与官网改版

#### 新功能

- 上下文面板新增活跃路径与睡眠路径列表，可搜索、分页查看路径及披露状态。
- 执行轨迹可分别查看固定系统提示词、规则、技能与动态上下文，并对比上下文变化；父会话中可展开子 Agent 的工具记录。

- 可在「搜索与网页读取」中开启 DeepSeek 搜索，与已启用的智谱和国际通道一起聚合结果，去重排序后返回。
- DeepSeek 网页读取可单独开启，默认关闭；搜索与读取开关互不影响，并共用已配置的官方 Key。

#### 改进

- 每一步工具执行完成后检查上下文占用，达到阈值时先压缩再继续；上下文按受影响的模块更新。
- 长会话减少常驻内存中的历史正文，需要时再读取已保存的记录。

- 官网首页重新设计：首屏窗口按桌面端界面重画，演示一轮任务里读取、Skill、子 Agent、编辑、审批、测试、上下文压缩和上下文面板各自起的作用；点击周围的插件开关，任务会按新配置重跑。
- 首页新增五个真实界面功能块：改动与交付、执行轨迹、审批、上下文面板和 Space 演示，截图会依次放大到每条要点对应的区域，悬停或点按要点可停在该处。
- 首页新增三个迭代方向：上下文管理引擎、Harness 自进化、Actor 与 Space，并标明进度；开发计划页与之对齐。
- 文档、博客、更新日志和开发计划页统一为同一套纸本风格，截图和插图使用相同的相框；新增「让 Agent 新增工具」文档，补充上下文面板说明。

#### 问题修复

- 修复重开会话后初始系统提示词为空、工具 Schema 丢失，以及误报系统提示词更新的问题。
- 修复查看子 Agent 状态时可能导致任务恢复冲突、父工具报持久化失败的问题。
- 修复压缩期间的停止状态与失败提示在切换会话后显示不正确的问题。

- Web 会话停止或失败后显示「队列已暂停」，可点「继续发送」恢复；刷新页面后仍可继续。
- 手机端审批按钮增大触控区域，窄屏下可换行。
- 窄窗口中的输入框统计信息按需换行，避免输入框和上下文浮层左侧被裁切。
- 通过别名路径打开工作区时，新一轮写入或修改的文件正常显示在回复下方的改动卡中。
- 重新打开历史轨迹时，已有计时记录的回复可显示首 token 时间、生成时长和输出速度。

### 2026-10-17 — Bash 完全权限修复、停止后的正文保留与会话统计修正

#### 问题修复

- 开启「完全权限」后，通过安全检查的 Bash 命令直接执行；等待审批时切换到完全权限，当前命令可继续执行。
- 修复停止 Bash 时，已取消的命令仍可能启动的问题。
- 停止回复或输出中途失败后，已生成的正文会保留，刷新和重新打开会话后仍可查看。
- 修复失败原因显示成灰色的问题，浅色和深色主题均正确显示错误颜色。
- 会话模型用时计入失败重试消耗的请求时间，不包含重试等待。
- 关闭侧栏搜索后，键盘焦点返回搜索按钮；点击其他位置时保留新的焦点。

### 2026-10-15 — 轮尾改动与交付卡片、本轮用量、新版轨迹页和会话侧栏改版

#### 新功能

- 每轮回复结束后，回复下方直接列出本轮改动的文件和增删行数；悬停可预览 diff，点开在右侧查看本轮 Review。不需要时可在设置「对话显示」中关闭。
- Agent 可以主动交付文件，回复下方以文件卡片展示，支持预览、用默认应用或其他关联应用打开，以及在访达中显示。
- 回复尾部新增「用量」胶囊，点开可查看本轮输入、缓存、输出、推理 token 和花费；预估金额会单独标注，价格未知时显示「部分未知」或「未知」。
- 输入框状态栏新增会话统计和 Token 用量入口，可查看首 token 时间、输出速度和累计用量。
- 侧栏新增视图选项：可按工作区、单列表或按时间分组，可选手动排序或最近更新，可隐藏已归档、显示全部或只看已归档，并能一键恢复默认。
- 会话和工作区都可以拖拽排序；在「最近更新」下拖动会自动切换为手动排序。
- 按时间分组时，待审批、失败和后台跑完还没查看的会话集中显示在顶部「需要处理」中。
- 已归档的会话可以在侧栏直接取消归档。

#### 改进

- 轨迹页重新设计：新的时间轴、按类型标注的记录表格和详情面板，支持 JSON 树、提示词前后对比和搜索；带思考的记录默认展开，停止按钮移到轨迹工具栏。
- 长会话在轨迹页流式输出时更流畅，不再随输出变长而卡顿。
- 工具失败等错误在回复末尾单独显示为红色状态行，不再折叠进工作过程中。
- 设置 › 模型的连接列表改为卡片样式，连接状态一眼可见；二级页面的返回按钮移到标题旁。
- 侧栏更简洁：搜索收进标题行的图标，点开后在原位展开搜索框；各分区和工作区可以折叠，折叠状态重启后保留；每个工作区先显示 5 个会话，其余可展开。
- 后台运行结束但还没查看的会话会显示未读标记，时间改为「4分钟」「昨天」这类中文相对时间。
- 默认工作区只在第一次启动、还没有任何工作区时自动创建，之后可以像普通工作区一样移除，移除后不会再自动出现。
- 没有工作区时，新建会话页会提示先选择工作区，不再把会话悄悄放进下载目录。

#### 问题修复

- 修复关闭 Thinking 后部分模型请求失败的问题。
- 修复轨迹中 Markdown 列表丢失编号和项目符号的问题。
- 修复内置能力连续升级后，任务停在队列中既不运行也不暂停的问题。
- 修复移除或归档工作区后自动生成空白会话的问题。
- 修复移除工作区后，侧栏仍残留该工作区空文件夹的问题。

### 2026-10-12 — Context 面板、Cursor 式审批卡与命令前缀授权

#### 新功能

- 右侧 Context 面板重新设计，集中展示当前上下文、会话统计、上下文明细、趋势和事件；明细默认对比上次请求，点击会话条目可跳转到轨迹中的对应记录。
- Bash 审批新增「本会话允许 <命令前缀>」，同一会话内匹配前缀的简单命令不再重复询问；切换工作区后授权自动撤销，原有的安全拦截保持不变。

#### 改进

- 所有工具审批统一为更简洁的卡片：Bash 命令带语法着色并显示执行环境，编辑和写入可在卡片内展开 diff，危险程度通过按钮颜色区分。
- 设置中的模型多选框改为固定一行的摘要，长模型目录不再把输入框撑宽；下拉面板支持「全部 / 已启用」筛选，并按厂商分组。

### 2026-10-11 — 大规模使用统计查询更快

#### 改进

- 使用统计改由本地索引承担筛选、搜索、聚合和分页，会话数据很多时查询依然快速；页面显示同步进度，支持取消和错误提示。
- 侧栏新增历史会话搜索。

### 2026-10-08 — Review 自动刷新更省资源

#### 改进

- 构建产物、依赖目录等被 Git 忽略的文件持续变化时，Review 不再反复刷新，构建期间的 CPU 占用明显下降。
- 切换到其他工作区后，原工作区的文件变化不再触发当前界面的 Review 统计刷新；连续大量改动时刷新频率也有上限，普通保存仍在约 1 秒内自动更新。

### 2026-10-07 — 会话专属工具与更顺手的输入区

#### 新功能

- 可以在 Agent 模式下要求为当前会话开发或修改简单的文本、数据处理工具；内置插件开发 Skill 提供开发指引，经过授权启用后，下一条消息即可使用新工具。
- 自定义工具只影响当前会话，正在执行的任务继续使用原版本；支持恢复会话的工具选择和回退旧版本。首版限于无外部依赖的单文件 TypeScript 工具。

#### 改进

- 输入框的「+」面板集中提供模式、附件、Skills 和模型入口，支持搜索与键盘导航；本机和远端模型使用一致的选择体验。
- 输入框在单行与多行之间切换更稳定，消息队列紧贴输入框上方，运行中补充指令统一使用「引导」入口。
- 新建 Agent 会话时，可以集中选择运行位置、工作区与分支；进入对话后显示当前运行位置，无法发送或停止时提供原因提示。

#### 问题修复

- 修复部分插件工具等待授权时没有审批按钮、任务无法继续的问题。
- 修复外部修改文件或 Git 状态后，Review 未自动刷新变更列表的问题。
- 修复断开智谱搜索后，后续搜索仍使用旧连接的问题；重新连接或更换密钥后也会使用最新配置。
- 修复新建会话选择「新建工作树」后未实际生效的问题；首次发送会在所选工作树中创建会话，创建失败时保留错误提示。

### 2026-10-06 — 长会话上下文与恢复能力改进

#### 改进

- 上下文压缩后保留任务摘要与相关文件线索，按读取情况维护活跃文件列表，较少使用的文件转入可按需查阅的索引，方便长任务继续追踪工作内容。
- 项目的 `AGENTS.md` 指令在每轮对话刷新；压缩后再次读取文件可以获得正文，会话分叉也保留各自的文件追踪信息。

#### 问题修复

- 修复长会话累计记录较大时无法继续运行的问题。
- 修复自动压缩未按实际模型容量和输出预留空间计算触发预算的问题。
- 修复进程中断后快速重启，临时写锁冲突导致会话持续无法恢复的问题。
- 修复中文系统下无法正确识别非 Git 工作区的问题。

### 2026-10-04 — 从桌面连接远端 Agent

#### 新功能

- 新增可独立运行的 Agent Host，桌面端可以配对远端机器、选择远端工作区与模型，并在统一会话列表中查看和操作远端任务。
- 支持远端任务审批、文件上传和结果下载；桌面连接断开后，远端任务可以继续运行，重连后恢复观察。
- 同一 Host 可以连接多个桌面客户端，同步查看任务与处理审批；连接设备可以撤销授权。

#### 改进

- 远端离线时保留已加载的会话信息，并明确显示连接状态；连接、工作区和会话列表的更新反馈更及时。

### 2026-10-03 — 更可靠的任务停止

#### 问题修复

- 修复主动停止任务后被误报为执行失败的问题。
- 修复延迟到达的旧任务取消操作可能影响当前任务的问题。

### 2026-10-01 — 消息排队、压缩摘要与回复批注

#### 新功能

- Agent 运行期间可以继续输入和发送消息，后续消息依次排队；支持编辑、调整顺序或引导当前任务，停止或失败后可手动继续发送。
- 上下文压缩在对话流中显示进行状态与耗时，完成后可以展开、复制摘要，同时保留此前消息供查阅。
- 通用设置新增性能监控开关，开启后可在侧栏查看应用 CPU 和内存占用。

#### 改进

- 选中回复文字后，可通过“添加到对话”在原文旁填写评论；草稿批注以高亮和编号标出，方便继续编辑。
- 输入区用批注数量胶囊集中展示引用，展开卡片即可查看、编辑、删除或清空；已发送的批注可在用户消息上方查看并定位原文。
- 优化长会话历史恢复与用量统计加载，减少重复计算和加载过程中的界面更新。

#### 问题修复

- 修复通过 OpenRouter 使用 Claude 进行 Chat 对话时，因工具参数兼容性问题返回 400、无法生成回复的问题。
- OpenRouter 请求失败时，尽可能显示上游返回的具体原因，避免只看到通用错误提示。
- 修复中文输入法组字时输入框测量引起的页面滚动跳动，以及回复流中出现空白 Thinking 区块的问题。

## 2026-09

### 2026-09-29 — 会话与工具调用稳定性修复

#### 问题修复

- 修复 Chat 拒绝不可用工具后无法继续对话的问题，已有受影响会话也可继续使用。
- 修复 Explore 和通用子 Agent 执行失败，以及部分子会话历史无法读取的问题。
- 修复新会话首次读取文件时，误提示复用其他会话读取结果、未返回正文的问题。
- 修复开发启动可能加载旧编译产物，导致模式切换失败的问题。
- 外观设置中的字体预览改为中英文字体和代码样例，移除开发说明。

### 2026-09-28 — 单一 Agent 形态与三模式

#### 改进

- Composer 在同一会话中切换 Chat、Plan、Agent；模式随会话保存和恢复，草稿与历史不因切换被清空。
- Chat 仅向模型提供网络查询与生图两个工具；Plan 和 Agent 按各自能力范围运行，已有权限设置不能扩大模式边界。
- Chat 不再主动加入工作区指令或 Skills；切回 Chat 后，当前会话的既有历史仍保留。

### 2026-09-26 — 更容易接入模型服务，更顺手的桌面与官网体验

#### 新功能

- 自定义服务改为两步向导：填写地址与密钥、测试连接，再从发现的模型中选择要启用的模型；官方 Anthropic 连接只需填写密钥并选择模型。
- 自定义 Anthropic 服务支持自动识别认证方式，并可按参考价格、仅统计 Token 或手动单价记录用量费用。

#### 改进

- 连接详情支持逐项编辑、刷新模型列表和确认删除；常见接口地址后缀会自动整理，旧连接继续沿用原有配置。
- Chat 输入区收紧布局，上下文用量靠近模型选择器；空会话可从输入框切换 Chat、Agent 或 Plan，工作区的「+」直接创建 Agent 会话。
- 桌面端统一输入框、消息、按钮和设置页的视觉细节；官网首页、导航、功能展示与更新页同步调整，产品截图更完整易读。
- 长会话一次加载更多历史内容，向上滚动时继续加载较早消息。

#### 问题修复

- 修复审批中的会话重载后审批卡或停止操作丢失，以及 Chat 会话分叉后首次发送失败的问题；带附件的分叉会话现在可以独立访问自己的文件。
- 修复点击归档后侧栏需要等待数秒才隐藏会话的问题；归档失败时会自动恢复会话显示。

#### 新功能

#### 问题修复

### 2026-09-24 — 会话级文件授权

#### 新功能

- Desktop 文件审批支持“仅本次”和“本会话允许”；会话授权可以限定为单个文件或用户明确选择的目录树，并在重新打开同一会话后恢复。
- 顶部权限入口可以查看当前会话授权的动作、范围、来源工具和签发时间，并随时撤销。

#### 改进

- 会话授权只覆盖当前 Session、当前主 Agent 和同一核心文件权限域；CLI、Bash、删除、敏感文件与子 Agent 不会继承。
- 从“完全访问”降回“默认”时，会撤销工作区外授权并使待审批请求失效。

### 2026-09-23 — 更明确的工具权限模式与一次审批

#### 新功能

- 会话支持“默认”和“完全访问”两种文件权限模式；恢复会话时会沿用已记录的模式。

#### 改进

- 文件范围、删除、Bash 和敏感配置采用统一的一次审批；“完全访问”只扩展普通文件范围，不会自动批准高风险操作。
- 审批请求在超时、取消或拒绝后都会留下完整结果，重新打开会话时不再把一次批准误当成持续授权。
- 官网截图和博客图片加载前保留占位，加载中显示骨架反馈，减少页面跳动；预览图片的加载动画也更连贯。

### 2026-09-19 — 重新整理官网、文档与博客
