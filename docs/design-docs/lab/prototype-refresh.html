让 Agent 锻造 Rust CLI

主假说

问题

Agent 经常需要重复解析日志、文件结构和命令输出，当前只能靠临时 bash 片段和聊天上下文维持。

能力缺口

缺少一个可被 bash 稳定调用、可测试、可复用的 CLI 能力，用来把高频解析动作从临时步骤变成长期工具候选。

假说

如果把高频解析逻辑封装成 Rust CLI，主 Agent 可以通过 bash 工具稳定复用，并且更容易记录证据、测试和错误边界。

检查项

  • ✓CLI 能处理 3 组样例输入
  • ✓有明确错误输出
  • ✓包含最小测试
  • ✓不默认启用，必须进入晋升评审
