# Lab UI 体验

本文档是 Lab 前端体验的总入口。具体首页、卡片、弹窗和 V0 页面删减规则见 `frontend-page-design.md`。

## 核心界面：实验矩阵

Lab 首页是实验矩阵。

```txt
+----------------+----------------+----------------+----------------+
| 假说           | 实证           | 锻造           | 晋升           |
| 3              | 1              | 1              | 0              |
+----------------+----------------+----------------+----------------+
| 实验 A 假说卡  | 实验 A 记录    | 实验 A 产物    | 实验 A 评审    |
| 实验 B 假说卡  | 空             | 空             | 空             |
| 实验 C 假说卡  | 实验 C 记录    | 实验 C 产物    | 空             |
+----------------+----------------+----------------+----------------+
```

设计重点：

- 一行是一轮实验，保持横向因果链。
- 一列是生命周期阶段，表达实验推进深度。
- 单元格卡片承载该阶段的摘要、状态和关键产物。
- 空单元格不是错误，而是表达该实验还未进入后续阶段。

## 页面区域

V0 页面结构：

```txt
+--------------------------------------------------------------------------------+
| Lab                                                [已完成实验] [新实验]          |
+----------------+----------------+----------------+------------------------------+
| 假说构建 3  +   | 实证验证 2  +   | 能力锻造 2  +   | 晋升评审 1  +                 |
| cards...        | cards...        | cards...        | cards...                     |
+----------------+----------------+----------------+------------------------------+
```

V0 不展示搜索、Agent 建议、筛选、视图切换、全局统计条、底部选中实验条或右侧详情面板。详情通过弹窗承载。

## 卡片内容

每个阶段卡片默认只展示最小信息：

- 标题或阶段摘要。
- 状态：草稿、运行中、已完成、阻塞、失败、待评审。
- 产物类型图标或短标签：skill、cli、tool、doc 等。
- 证据数量或检查数量。
- 最近更新时间。

卡片不直接展示长文本。长内容进入卡片详情弹窗。

## 弹窗

点击某张阶段卡片后打开卡片详情弹窗。

卡片详情弹窗根据阶段展示不同内容：

- 假说卡：问题、能力缺口、假说、成功标准、风险预估。
- 实证卡：验证方案、命令 / 工具调用记录、证据、观察、失败记录、结论。
- 锻造卡：产物类型、产物路径、使用契约、验证方式、已知限制。
- 晋升卡：评审结论、风险等级、检查项、证据引用、人工审批状态。

顶部 `新实验` 打开新实验弹窗；顶部 `已完成实验` 打开完成实验列表弹窗。

## 交互原则

- 允许用户手动创建实验，但也要为 Agent 创建实验预留入口。
- 允许阶段回退，回退时追加记录，不覆盖旧记录。
- 允许同一实验有多个产物，但晋升时必须逐个评审。
- 高风险动作必须明确展示权限和影响范围。
- 默认视图展示进行中的实验，已晋升、已拒绝、已废弃和已归档实验进入 `已完成实验` 弹窗。

## 视觉气质

Lab 应该像实验台，而不是项目管理软件。

方向：

- 轻量、横向、清晰。
- 列头可以有温和色块，帮助区分阶段。
- 卡片应该克制，不做厚重装饰。
- 状态色只用于表达风险和进度，不把页面染成单一色系。
- 信息密度比聊天页高，但仍要保留呼吸感。

## 待前端设计继续确认

- 四列在窄屏下是否横向滚动，还是切换为阶段 tabs。
- 行高是否统一，还是按内容自适应。
- 完整实验详情在 V0 是否需要实现，还是只实现卡片详情弹窗。
- 阶段列标题最终使用中文长名还是短标签。
