## 0. 一句话

**Space 把几个 Actor 聚在一起解决一个问题。你只和协调 Agent 说话，它把事交给合适的 Actor；每个 Actor 在中间区域开成一个标签页，右栏按状态汇总所有 Actor。**

## 1. 术语

| 概念 | 界面名 | 代码名 | 说明 |
| --- | --- | --- | --- |
| 容器 | **Space** | `Space` | 不翻译。和产品概念里的「空间」同义 |
| 主持 Space 的 | **协调 Agent** | `coordinator` | 每个 Space 一个，头像就是 Space 头像。标签栏第一个，标签名写 Space 名字 |
| 成员 | **Actor** | `actor` | 有名字、场景、能力、自己的记忆的独立个体。右栏标签叫「Actor」 |
| 所有 Actor | **Actor 名册** | `roster` | 左栏入口，卡片页，点卡片进入一对一对话 |
| Actor 在 Space 里的位置 | （不单独命名） | `SpaceMember` | Actor + 它在这个 Space 里的状态、任务、目录、对话 |
| Space 里新起的 Actor | （不单独命名） | `nascent: true` | 协调 Agent 在名册里找不到合适的时新起，只属于这个 Space |
| 用户写的规则 | **指令** | `instructions` | 每个 Actor 开工前都会读 |
| 协调 Agent 记下的事实 | **Space 记忆** | `memory` | 逐条，可忘记 |
| 文件与产出 | **库** | `library` | 磁盘上的真实目录 |
| 现有的一次性只读助手 | **子智能体** | `subagent` | 保持现状，不参与 Space |

**界面上不出现的词**：初生、工作 Agent、客串、线程、主会话、派活。Space 里新起的 Actor 不加任何文字标签，只靠小球头像和标签页头部「归属 Space」区分。

## 3. 概念模型

```
Actor 名册 ── Actor × n（名字、场景、能力、自己的记忆）
                 │  被拉进 Space（新建时选，或协调 Agent 交事时自动加入）
                 ▼
Space ─┬─ 名字、要解决的问题（一句话）、相关目录
       ├─ 指令（用户写）─────────┐
       ├─ Space 记忆（协调 Agent 写）┴─▶ Actor 开工时读
       ├─ 库：spaces/<id>/library/{artifacts,added}
       ├─ 协调 Agent × 1：只读 + 交事
       └─ 成员 × n：一个 Actor 一行
              状态 wait | fail | run | result | idle
              当前任务、待办进度、目录、工作树（可选）
              对话：按任务分段的一条连续对话
```

### 3.1 职责

| 能力 | 协调 Agent | Actor |
| --- | --- | --- |
| 和你对话 | ✓ | ✓（标签页里，或名册里一对一） |
| 交事给 Actor、新起 Actor | ✓ | ✗ |
| 读文件、搜索 | ✓ | ✓ |
| 写文件、执行命令、浏览器 | ✗ | ✓ |
| 写 Space 记忆 | ✓ | ✗，只能提议，由协调 Agent 记下 |
| 自己的记忆 | — | ✓，跟着 Actor 走，跨 Space |
| 审批请求 | 不代答 | 在自己的对话里原地弹出 |

### 3.2 成员状态

| 状态 | 界面名 | 什么时候进入 | 什么时候离开 |
| --- | --- | --- | --- |
| `wait` | 等你决定 | Actor 发出审批请求或问题 | 批准 → `run`；拒绝 → `idle`（说明写「命令被拒绝，等你给方向」） |
| `fail` | 出错 | 会话失败 | 你重试或给方向 |
| `run` | 工作中 | 收到任务 | 发出审批 → `wait`；做完 → `result` |
| `result` | 有结果 | 一个任务做完，你还没看 | 打开它的标签页 1.4 秒后 → `idle` |
| `idle` | 空闲 | 没有进行中的任务 | 收到任务 → `run` |

- 中间对话列和输入区都用现有会话的宽度（上限 880px，左右留白 32px），不另定宽度。
- 右栏在 Space、Actor、一对一对话里都可用；只有名册页不显示右栏、胶囊和托盘。
- 窗口变窄时右栏和现有会话一样盖在中间区域上面。

### 4.2 左栏

就是现有左栏，只加三处（D20）：

- **新建 Space**：在主操作组里，紧跟「新建会话」，点了打开 §4.5 的弹窗。
- **Actor 名册**：主操作组最后一行，在「扩展」下面。图标是两张角色图叠放，右侧显示名册里 Actor 的数量。
- **Space 分区**：在主操作组和「已置顶」之间。标题旁边是「演示」小标签（D18），悬停出现 `+` 新建。每个 Space 一行：Space 头像 + 名字，有「等你决定」时右侧显示琥珀色数字徽标。

一对一对话不另开分区，放在工作区的会话列表里，行首是 Actor 头像（D30）。

### 4.3 中间区域

**标签栏（44px）**

- 最左固定协调 Agent 标签：Space 头像 + Space 名字，加粗，不可关闭，不随 Actor 标签滚动。
- Actor 标签：头像（工作中带转动光环）+ 名字 + 状态点（只有等你决定、出错才有）+ 未读点 + ×（悬停或选中时出现）。
- 放不下时的行为见 D17。「全部标签」菜单：顶部「关闭其他标签」，每行勾选标记 + 头像 + 名字 + 状态点，栏里看得到的灰一点，悬停出现 ×。切到看不到的标签时自动滚进视野，不和手动滚动抢位置。
- 名册页、一对一对话时，标签栏只显示一个标签（「Actor 名册」或 Actor 头像 + 名字）。

**协调 Agent 标签页**

只有这几种内容，不加头部（D14）：

| 内容 | 形态 |
| --- | --- |
| 时间分隔线 | 「今天 09:12」 |
| 你的消息 | 右对齐卡片 |
| 协调 Agent 回复 | 正文，不带头像。Actor 名字渲染成引用胶囊（小头像 + 名字），点了打开那个 Actor 的标签页 |
| 记忆脚注 | 「✓ 记下了「…」· 撤销」。撤销后划掉并写「已撤销」，同时从 Space 记忆里删除 |
| 「留下」卡片 | 见 §5.4 |

回复先显示三个跳动的点，再逐字出现，末尾带光标。

**Actor 标签页**

- 头部：40px 头像（工作中带光环）、名字、状态胶囊、场景一句话、能力标签、元信息（目录、工作树、名册 Actor 写「自己的记忆 N 条」，新起的写「归属 Space」）。
- 对话：任务分隔线「开始 · 任务 · 时间」/「✓ 完成 · 任务 · 时间」、「协调 Agent 交来的事」灰底块、工具行（动作 + 对象 + `+增 −删`）、正文、记忆同步分隔线、审批卡。
- 没有任务时：「在这个 Space 里还没有交给 ×× 的事。」

**空 Space**：深色主题是缓慢漂移的星空，浅色主题是极淡的点阵；中间是 56px Space 头像、名字、「为「目标」而设」、成员头像（轻微浮动，可点）、一行提示「说说要做什么，协调 Agent 会交给合适的 Actor。」

**名册页**：标题「Actor 名册」+ 数量 + 搜索框；一句说明；卡片网格（最小 220px）。卡片：56px 头像、名字、场景（两行截断）、最多 3 个能力、底部「今天聊过 · 在 N 个 Space 里」。搜索按名字、场景、能力过滤。

**一对一对话**：顶部居中的自我介绍（头像、名字、场景、能力），下面是对话，不带头像。

**输入区**：托盘 → 胶囊 → 现有 `Composer`（D21）。占位符：协调 Agent「接下来做什么？」、Actor「对××说…」、一对一「和××说…」。状态行按 D31。

### 4.4 右栏

复用现有右栏（D25）：顶部是标签栏，右端是「+」对象菜单和收起按钮；没有打开任何标签时显示启动页。

**每个上下文能打开哪些标签**

| 上下文 | 可打开的标签 | 第一次进入时默认打开 |
| --- | --- | --- |
| 协调 Agent 标签页 | Actor、库、记忆、文件、终端 | Actor、库、记忆，选中 Actor |
| Actor 标签页 | 和普通会话一样：子 Agent、文件、Review、上下文、终端、可视化回复 | 有改动：Review + 终端；否则：文件 + 终端 |
| 一对一对话 | 和普通会话一样 | 文件 |

- 每个上下文各自记住打开了哪些标签、选中哪个（D28）。切回来时恢复，不会被别的上下文影响。
- 文件、终端、Review 用的目录：协调 Agent 是 Space 的相关目录；Actor 是它自己的目录或工作树。
- 「+」菜单只列当前上下文能打开的标签；已经打开的切过去，不重复开。
- 关掉最后一个标签显示启动页。

**启动页（D29）**

白底，顶部一句灰色说明，下面每行一种标签：图标 + 名字 + 一句说明，36px 一行，悬停浅灰底。不用磁贴、不换背景色，和右栏其他列表保持一致。普通会话的启动页一起改成这个样子。

| 标签 | 说明 |
| --- | --- |
| Actor | Space 里每个 Actor 在做什么 |
| 库 | Actor 产出和你放进去的文件 |
| 记忆 | 指令和 Space 记忆 |
| 文件 | 浏览工作目录 |
| 终端 | 在这个目录里开终端 |
| 子 Agent | 这次对话派出的一次性助手 |
| Review | 这次的改动 |
| 上下文 | 上下文用了多少 |
| 可视化回复 | 图表、页面形式的回复 |

**Actor 标签**

- 按 D11 的顺序分组，空分组不显示。分组条 30px 浅灰底：折叠箭头 + 状态名 + 数量，每组都可折叠。「等你决定」分组条是琥珀色，折叠后也一眼看得到。
- 每行 36px：22px 头像（工作中带光环）、名字、说明、未读点、待办进度、时间。
  - 说明：等你决定 / 出错写它在等什么；工作中写任务；有结果写「✓ 任务」；空闲写「上次：任务」或「还没有任务」（灰一点）。
  - 待办进度：只在工作中、等你决定、有结果且有 todo 时显示，小圆环 + `完成数/总数`。
  - 悬停 `title` 显示「名字 · 说明」。

**库 标签**：「N 个文件」+「添加」；「Actor 产出」「你放进去的」两组，每行文件名、来源、日期；底部虚线框说明库就是 `spaces/<id>/library/`。

**记忆 标签**：「指令」（只读展示 + 编辑）；「Space 记忆」逐条，悬停出现「忘记」，说明「只有协调 Agent 会写。Actor 自己的记忆跟着 Actor 走，在它的标签页里看。」

### 4.5 新建 Space

弹窗字段：名字、要解决的问题（一句话）、成员（从名册多选，默认选前两个）、相关目录（选填）。创建后进入这个 Space，显示空 Space。Space 头像按创建顺序自动轮换，不让用户选。

## 5. 关键交互

### 5.1 你对协调 Agent 说话

1. 你的消息出现，协调 Agent 回复先显示跳动点。
2. 回复逐字出现，写清交给了谁。规则：先找空闲的名册 Actor；名册里没有合适的，就在这个 Space 里新起一个。
3. 回复结束后，被交到事的 Actor 进入「工作中」，右栏那一行亮一下（翡翠绿底闪 1.5 秒）；新起的 Actor 那一行从下方淡入。
4. 演示里，几秒后会有一个工作中的 Actor 发出审批，用来走一遍 §5.2。

### 5.2 审批（D8）

- **源头**：审批卡在 Actor 自己的对话里，标题「想运行一条命令」、命令、理由、「拒绝」「运行」。处理后卡片收成一行「已批准，继续往下做。」/「已拒绝这条命令，等你给别的方向。」
- **提醒**：右栏移到「等你决定」分组；标签上琥珀色点；左栏 Space 行数字徽标；输入框上方琥珀色胶囊，新来时跳两下。
- **快捷处理**：点琥珀色胶囊展开托盘：头像、「××想运行一条命令」、命令（单行截断）、多个时 ‹ 1/3 ›、「查看」「拒绝」「运行」。处理完切下一个，没有了就收起。
- **不重复**：当前看的就是那个 Actor 时，胶囊数量和托盘都不算它。
- 托盘默认不自动展开，不打断输入。

### 5.3 打开、关闭、切换

- 点右栏行、引用胶囊、空 Space 成员、托盘「查看」→ 打开或切到那个 Actor 的标签页，清掉未读。
- 关标签不影响 Actor 本身。关当前标签跳到左边那个，没有就回到协调 Agent。
- 切换 Space：记住离开时的选中标签，回来时恢复；托盘收起。

### 5.4 留下新起的 Actor（D12）

- 卡片：小球头像 + 「**××** 这次做完了，要不要留下它？」+ 小字「留下后它会进入名册，以后同类的事可以直接找它。」+「不用」「留下」。
- 留下：8 个星尘粒子从四周聚拢，小球缩小淡出，角色图弹出；卡片变成「留下了。××现在在名册里，以后可以直接找它。」+「去名册」。右栏和标签上它的头像同时换成角色图并弹一下；名册里它的卡片描一圈翡翠绿边后淡去。
- 不用：卡片变成虚线框「没有留下 ××，它只留在这个 Space 里。」

### 5.5 名册与一对一对话

- 点卡片进入一对一对话，它出现在左栏工作区的会话列表里（D30）。
- 一对一里发消息，Actor 回复先跳动点再逐字出现。

### 5.6 其他

- 胶囊：等你决定（只算当前没在看的）、出错、工作中、有结果、空闲，数量为 0 的不显示；空 Space 不显示胶囊。点非琥珀胶囊打开右栏的 Actor 标签（没开就先开）。
- 「忘记」一条记忆：直接删除，提示「已忘记」。
- 演示里不展开的入口（添加库文件、预览库文件、编辑指令）点了给一条提示，不做假页面。左栏、文件、终端、Review 等现有功能照常可用（demo 里只是提示）。

## 6. 状态、颜色与头像

| 状态 | 颜色 | 出现在 |
| --- | --- | --- |
| 工作中 | 翡翠绿（`operational`），头像外转动光环 | 头像光环、胶囊点（脉冲） |
| 有结果 | 翡翠绿空心圈 | 胶囊点、状态胶囊 |
| 等你决定 | 琥珀（`warning`）+ 脉冲 | 胶囊、标签点、分组条、左栏徽标 |
| 出错 | 红（`danger`） | 胶囊、标签点 |
| 空闲 | 灰 | 胶囊点 |

- 翡翠绿只用于工作中与成功，琥珀只用于等你决定，红只用于出错。全部走主题 token，深浅两套主题各自成立。
- 头像只回答「是谁」，不表达状态；状态由分组、光环、点和文字表达。
- 头像圆角约 28%；尺寸 16（引用胶囊）/ 18（标签、左栏）/ 22（右栏、托盘）/ 40（Actor 头部、空 Space 成员）/ 56（名册卡片、空 Space、一对一）。
- 头像素材见 [assets/](assets/)：`space/`、`ball/` 是原图，`demo/` 是 256px 裁切版，`unused/` 是落选稿。名册 Actor 直接用桌面端 `apps/desktop/src/renderer/assets/subagents/companion-1..9.webp`。

## 7. 动效

| 场景 | 动效 |
| --- | --- |
| 右栏开合、标签切换 | 沿用现有右栏 |
| 协调 Agent / Actor 回复 | 跳动点 760ms，再每 26ms 出 3 个字，末尾光标闪烁 |
| Actor 状态变化 | 右栏那一行 FLIP 平移 0.3s 到新分组 |
| 交到事 | 那一行翡翠绿闪 1.5s；新行从下方 5px 淡入 0.24s |
| 分组折叠 | `grid-template-rows` 1fr ↔ 0fr 0.22s + 淡出，箭头旋转 -90° |
| 新审批 | 琥珀胶囊上下跳两次 |
| 托盘 | 高度 + 透明度 0.26s |
| 工作中 | 头像光环 2.4s 一圈 |
| 留下 Actor | 星尘聚拢 0.6s（逐个延迟 28ms）+ 小球缩小 0.45s + 角色图弹出 0.5s |
| 空 Space | 星空两层漂移 200s / 300s + 闪烁 7s；成员头像浮动 5s |
| 「全部标签」菜单、弹窗 | 下落 / 上移淡入 0.16–0.2s |
