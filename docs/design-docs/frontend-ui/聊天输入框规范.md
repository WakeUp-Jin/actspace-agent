# 聊天输入框规范

## 定位

聊天输入框是整页最重要的操作中心。

## 内容

- 多行输入区域。
- 模式按钮下拉。
- 模型按钮下拉。
- 附件入口。
- Context 圆形入口。
- 发送按钮。
- 上下文弹窗。

## 原则

- 使用弹出下拉，不使用生硬的静态选择框。
- 输入区要像桌面应用，而不是普通网页表单。
- 保留足够的打字空间。
- 不显示语音按钮。
- 发送按钮保持单一、轻量、克制。
- `model` 选择保持文字化，不加边框。

## Context 弹窗

点击输入区里的 Context 圆形按钮后弹出。

### 内容

- 上下文总占用。
- 分段占用条。
- System prompt。
- Tools。
- Rules。
- Skills。
- MCP。
- Subagents。
- Conversation。

### 原则

- 保持统计感。
- 以占用和构成为主，不做复杂编辑。
- 视觉上接近你给的那张参考图。

- 图片附件只显示图片本体。
- 文件附件只显示文件名。
- 附件位于输入区上方，简洁排列。
