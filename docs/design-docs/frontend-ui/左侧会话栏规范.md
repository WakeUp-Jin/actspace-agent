# 左侧会话栏规范

## 定位

左侧只服务聊天态下的会话切换，不做复杂控制台，也不承担完整设置导航。

它属于聊天态工作台的可调面板区域，布局尺寸和折叠边界见 `工作台布局与面板交互规范.md`。

## 内容

- `New chat` 入口。
- `Search` 入口。
- `Chats` 分区。
- `Scheduled` 分区。
- 当前选中态。
- 最近更新时间。
- 简短会话标题。
- 底部 `Settings` 入口。

## 原则

- 轻量优先。
- 首版不加过多筛选和管理功能。
- 不保留 `Project` 层，也不做多级工作台导航。
- `Chats` 和 `Scheduled` 是两个一级分区，展开后直接展示各自会话列表。
- 左侧没有 `Workspaces / Projects -> folder -> chat` 这类三级结构，分区下方直接顶格展示会话。
- 分区标题使用浅灰小字号，右侧可以放更多操作和新建操作图标。
- 会话项保持纯文本感，以标题加时间为主，不做重卡片。
- 会话项不使用左侧缩进、文件夹或层级圆点；右侧状态点只表示会话状态。
- 会话项高度保持紧凑，优先接近高密度文本导航，而不是聊天卡片。
- 让用户能快速切换到最近会话。
- 保持较高的信息密度但不过载。
- 选中态要清晰，列表层级要干净。
- 分区标题与首条列表项之间的间距应适当压缩，避免出现松散空洞感。

## 面板状态

### 展开态

- 不展示 logo 或品牌 wordmark，只展示操作入口、会话分区和底部设置入口。
- 宽度可由用户在工作台中调整。
- 宽度变化不应把会话标题改成多行卡片，超长标题仍按紧凑导航处理。

### Rail 态

- 左侧首版折叠到 icon rail，不先做完全隐藏。
- rail 只保留折叠控制、新建会话、搜索和设置等高频入口的图标表达。
- `Chats` / `Scheduled` 分区、会话标题和相对时间在 rail 态隐藏。
- rail 是 sidebar 的紧凑展示状态，不替代中间区或右侧对象区的布局规则。

## 分区说明

### Chats

- 放普通手动创建的聊天会话。
- 点击分区标题可以展开或收起整组列表。
- 列表项默认只展示会话标题和相对时间。
- 当前选中项使用很轻的浅灰底高亮，不额外增加状态浮层。
- 会话运行、等待审批等状态后续放在列表项右侧，用小状态点或轻量状态控件表达。

### Scheduled

- 放定时运行相关的会话。
- 点击分区标题可以展开或收起整组列表。
- 首版先按普通列表表达，不额外引入复杂运行面板。
- 默认也使用标题加时间的紧凑行式布局，保持和 `Session` 同一视觉语言。

## Settings 切换规则

- 底部 `Settings` 是页面级入口，不是弹窗入口。
- 点击后，应用从聊天态切换到设置态。
- 切换到设置态后，原左侧会话栏不再保留。
- 原位置替换为设置导航列表，具体规则见 `设置页规范.md`。
- 首版不显示账号卡片、登录信息卡片或 `Log out` 浮层。
