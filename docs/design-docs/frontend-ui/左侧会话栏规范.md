# 左侧会话栏规范

## 定位

左侧只服务聊天态下的会话切换，不做复杂控制台，也不承担完整设置导航。

## 内容

- `New chat` 入口。
- `Search` 入口。
- `Session` 分区。
- `Scheduled` 分区。
- 当前选中态。
- 最近更新时间。
- 简短会话标题。
- 底部 `Settings` 入口。

## 原则

- 轻量优先。
- 首版不加过多筛选和管理功能。
- 不保留 `Project` 层，也不做多级工作台导航。
- `Session` 和 `Scheduled` 是两个一级分区，展开后直接展示各自会话列表。
- 会话项保持纯文本感，以标题加时间为主，不做重卡片。
- 让用户能快速切换到最近会话。
- 保持较高的信息密度但不过载。
- 选中态要清晰，列表层级要干净。

## 分区说明

### Session

- 放普通手动创建的聊天会话。
- 点击分区标题可以展开或收起整组列表。
- 列表项默认只展示会话标题和相对时间。

### Scheduled

- 放定时运行相关的会话。
- 点击分区标题可以展开或收起整组列表。
- 首版先按普通列表表达，不额外引入复杂运行面板。

## Settings 切换规则

- 底部 `Settings` 是页面级入口，不是弹窗入口。
- 点击后，应用从聊天态切换到设置态。
- 切换到设置态后，原左侧会话栏不再保留。
- 原位置替换为设置导航列表，具体规则见 `设置页规范.md`。
