# 左侧会话栏规范

## 定位

左侧会话栏是 actspace 桌面端工作台的左侧栏，负责：

- 入口聚合：聊天态新建（New Agent）、Lab、Usage 三个一级入口和顶栏窗口控件。
- 会话导航：让用户在大量历史会话之间快速切换。
- 状态指示：把"当前选中""有运行中 turn / 待审批工具"这类二态合并显示为行首蓝点。
- 全局设置入口：底部 Settings。

它属于聊天态工作台的可调面板区域，宽度、折叠和 rail 边界见 `工作台布局与面板交互规范.md`。

## 信息架构

自上而下分四块：

1. **顶部窗口区**（红绿灯 + 折叠按钮 + 搜索按钮）。
2. **顶部主入口**：`New Agent` / `Lab` / `Usage`。
3. **分区列表**：`Pinned` → `Scheduled` → 各 Workspace。
4. **底部** `Settings`。

## 顶部窗口区

- 自左到右：macOS 红绿灯（系统）、折叠按钮（PanelLeft icon）、搜索按钮（Search icon）。
- 折叠按钮负责在 expanded / rail 之间切换。
- 搜索按钮是图标级别的"操作"按钮，不是导航项；点击触发全局会话/工作区搜索。Rail 态隐藏。
- 搜索功能本身在首版可暂未实现，但入口必须保留。

## 顶部主入口

- `New Agent`：替代原 `New chat`，承担"开启一次新的 Agent 任务"语义；展示快捷键 `⌘N`。
- `Lab`：实验台占位页（Coming soon）。未来用于 prompt 调试、工具沙盒、多模型并排。
- `Usage`：统计页占位（Coming soon），将承载 token / 成本聚合。具体设计见 `usage-statistics/设计规范.md`。
- 三个入口在 rail 态收缩为图标。
- 三个入口共用同一组 hover / active 状态语言；当前 view 视为 active。

## 分区列表

### Pinned

- 跨 Workspace 的顶层固定分区。
- 用户可手动 pin/unpin 任意会话。
- 至少有一个会话被 pin 时出现，没有则该 section 隐藏。
- 列表项保持和 Workspace 内列表项完全相同的视觉语言。

### Scheduled

- 顶层独立分区，用于定时运行相关会话。
- 首版可以只放占位条目，等真实定时任务功能落地再接通。
- 标题右侧提供"更多操作 / 新建定时任务"两个图标按钮（默认隐藏，hover 分区标题时露出）。

### Workspaces

- 按会话创建时记录的 `workspaceRoot` 自动归类，分组标题 = `path.basename(workspaceRoot)`。
- 旧会话缺 `workspaceRoot` 字段时归到 `Default workspace`。
- 每个 Workspace 是一个可折叠分组（默认展开）。
- 分组标题右侧的"更多 / 新建"图标按钮在 hover 时露出。
- 每个分组超过 **8** 条用 `See more / See less` 折叠剩余项。
- 首版只支持「按 cwd 自动归类」，**不支持**手动新建/重命名/拖拽 Workspace，这部分留给后续 plan。

## 会话行

- 高度紧凑（接近 32px），保持高密度文本导航的气质，不做卡片。
- 行内三列：`marker | title | time`。
  - `marker`：行首蓝色状态点位置；不显示时仍占同样宽度以保证标题对齐。
  - `title`：单行 ellipsis；字号 14、字重 500。
  - `time`：相对时间，使用紧凑的 `1h` / `3d` 缩写；选中态时这一格淡出，让位给 active 体验。
- Hover 时背景轻灰；当前选中态使用更深一点的浅灰底。

### 状态点

- 位置：行首左侧，标题前 8px。
- 颜色：`--color-brand`（actspace 品牌蓝）。
- 显示条件（任一满足即亮起）：
  1. 当前选中（实心点）。
  2. 该会话有运行中 turn 或待审批工具（呼吸动画的点，表示 busy）。
- 不再出现行尾状态点。

### Pin 图标

- Hover 任意 session 行时，右侧露出一个图钉图标按钮（lucide `Pin` / `PinOff`）。
- 已 pin 的会话即使 hover 退出，图钉图标也保持显示，颜色用品牌蓝。
- 点击切换 pin 状态，调用 IPC `pinSession`。Rail 态隐藏。

## Settings 切换规则

- 底部 `Settings` 是页面级入口，不是弹窗入口。
- 点击后从聊天态切换到设置态，原侧边栏被设置导航替换。
- 切换规则与设置态布局见 `设置页规范.md`。
- 不显示账号卡片、登录信息卡片或登出浮层。

## 面板状态

### 展开态

- 宽度 200–360px，由用户在工作台 SplitView 中调整。
- 不展示 logo 或品牌 wordmark。
- 宽度变化不应让会话标题变成多行卡片，超长标题仍按紧凑导航处理。

### Rail 态

- 折叠到 icon rail。
- 顶部三入口、Settings 仍以图标形式保留；搜索按钮隐藏。
- 分区标题、会话标题、Pin 按钮、相对时间在 rail 态全部隐藏。
- Rail 是 sidebar 的紧凑展示状态，不替代中间区或右侧对象区的布局规则。

## 后端契约

- `SessionMeta` 增加可选字段：
  - `workspaceRoot?: string`：创建会话时由主进程从 `BootstrapState.workspaceRoot` 注入。
  - `pinned?: boolean`：用户在前端 pin/unpin 时通过 IPC `session:pin` 更新。
- `SessionListItem` 同步透出这两个字段，让前端按 workspace 分组并标记 pinned。
- 后端 `agent-core` 在创建 session 时根据 `SessionCreateInput.workspaceRoot` 写入 meta；列出时直接透出。
- 切换 pin 走 `pinSession({ sessionId, pinned })`，主进程调用 `setSessionPinned` 重写 meta。

## 设计原则

- 轻量优先：信息密度高、视觉装饰少，不做重卡片。
- 自动归类：Workspace 概念暂不暴露管理面，对用户来说"打开 actspace 在哪个目录"就决定了 Workspace 归属。
- 状态合并：行首点首版只区分 active 和 busy，不细分未读/错误/审批，等业务上有真实区分需求再扩展。
- 操作克制：顶部不放 Marketplace / Automations 这种暂时没有功能的占位项，先放真正会演进的 Lab 和 Usage。
