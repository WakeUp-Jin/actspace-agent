# 设置页规范

## 定位

设置页是独立于聊天态的页面级视图，用于承载应用配置，不作为聊天页右侧附属面板存在。

## 切换规则

- 用户在聊天态点击左侧底部 `Settings` 后进入设置态。
- 进入设置态后，原左侧会话栏整体替换为设置导航。
- 右侧主区域同步替换为设置内容区。
- 设置态与聊天态共享同一应用外壳，但内容布局不同。
- 左上角可提供 `Back to app` 返回聊天态。

## 布局

设置页采用两栏结构：

- 左侧：设置导航列表。
- 右侧：当前设置项详情内容。

### 左侧设置导航

- 保持窄而稳定的宽度。
- 使用纯列表导航，不做聊天会话展示。
- 每项为一个设置分类，例如：
  - `General`
  - `Appearance`
  - `Model`
  - `Tools`
  - `Advanced`
- 当前选中项使用轻量高亮背景。
- 导航风格延续聊天态侧栏的克制视觉，不突然变成后台控制台。

### 右侧设置内容区

- 以表单和配置分组为主。
- 内容允许和聊天页完全不同，但版式节奏保持一致。
- 使用清晰的标题、分组标题、说明文本、开关、下拉和输入控件。
- 不追求复杂卡片感，优先保证静态可读和操作稳定。

## 视觉原则

- 保持极简、冷静、桌面应用感。
- 不使用弹窗式设置菜单。
- 不额外引入登录卡片、账号浮层或复杂账户中心。
- 让用户感受到这是同一产品的另一种主页面，而不是另一个系统。

## 首版范围

- 先验证聊天态切换到设置态的布局关系。
- 先定义导航结构和内容区信息层级。
- 具体设置项文案和功能细节后续再补。
