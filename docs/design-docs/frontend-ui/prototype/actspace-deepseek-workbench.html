DeepSeek Working Mode

让系统优先展示可控的上下文结构，而不是把复杂性藏在模型内部。

Context-first Coding Expose token shape, reuse ratio and compression thresholds during execution.
General Assistant Lower observability, lighter surface, better for casual daily work.

Runtime Controls

这些设置服务于“缓存利用降低成本”的目标，所以采用清晰、保守、可回退的表达方式。

Prefer cache reuse 优先保温可复用上下文块，减少重复输入和重复推理。
Auto compression 在 token 压力升高前主动压缩历史，保留结构而不是保留原文。
Context diff markers 显示哪些上下文是热缓存、冷缓存、临时拼接还是手动附着。

Workspace Defaults

Default model 保持文字化而不是重控件化，让主工作流不被设置感打断。
