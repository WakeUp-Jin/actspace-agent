# V3：自主能力研发

## 目标

让 Agent 能更主动地发现能力缺口，并在用户设定的边界内推进完整 Lab 实验。

## 范围

V3 做：

- Kairos 根据重复失败和重复需求建议实验。
- Main Agent 在任务中发现缺口后创建实验候选。
- Agent 自动推进低风险研究和整理。
- Agent 在沙箱中执行批准后的验证计划。
- Agent 生成候选能力和晋升报告。
- 用户在 Promotion Gate 中集中审批。

V3 不做：

- 完全无监督自我改造。
- 自动放宽权限。
- 自动把高风险产物设为默认启用。
- 绕过 evidence / review 机制。

## 成功标准

- 用户能看到 Agent 主动提出的高质量能力研发候选。
- 实验推进过程可审计。
- 通过晋升的能力能稳定改善后续 Agent 任务。
- 失败实验也能沉淀为有价值的 learning。
