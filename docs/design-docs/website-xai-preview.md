# ActSpace 官网样稿：黑白、等宽与直角

后续官网方向见 [Site DESIGN](../../apps/site/DESIGN.md)。本页描述已有样稿，不再代表下一版全部视觉决策。

状态：2026-09-19，方向已批准，首页、文档、博客与更新日志样稿待视觉评审。原型独立于 `apps/site`。

[打开双主题交互样稿](website-xai-preview.html)。HTML 内嵌字体和图片，可离线打开；通过顶部导航在首页、文档、博客、更新日志之间站内切换。

## 1. 视觉主题

以用户确认的 [xAI 风格预览](https://www.ifuryst.com/DESIGN.md/x.ai/design-md/) 为准：直角按钮、等宽英文展示字、黑白平面分区、大留白与细线。该参考是第三方设计解读，不是 xAI 官方规范。它取代此前本地参考中的胶囊按钮方向，也取代 A/B/C 原型作为下一轮官网评审入口。

受众是希望让 Agent 在本地完成实际工作的开发者与高级用户。首页保留“给模型一个真正能行动的空间”，用实际工作与产品体验叙事，Harness 内部架构留给文档和工程博客。

## 2. 色板

Light 为白底、`#1f2228` 正文；Dark 为 `#1f2228` 底、白色标题和分层灰色正文。Light / Dark / System 三态，默认跟随系统，选择存入原型专用 localStorage。字体和媒体不依赖外网。

用户明确指定焦点色 `rgb(51, 121, 92)` / `#33795c`，用于 `:focus-visible` 的 3px 轮廓及 4px 间隔。与白底对比约 5.21:1，与深底约 3.06:1。此为官网样稿已批准的例外，不修改桌面端中性焦点契约。主题颜色只在 CSS token 定义中出现。

## 3. 字体

样稿使用本机已具备的 JetBrains Mono 内嵌字体近似等宽方向；不是 Geist Mono 的像素复刻。用于品牌字标、英文短标签、日期和编号。中文使用 PingFang SC / Microsoft YaHei，正文使用无衬线字；中文大标题不套英文极端字距。正式实施时可换成有明确授权来源的 Geist Mono。

## 4. 组件

直角反色主按钮、细线次按钮、文字导航、原生主题下拉、可放大截图。图片对话框使用原生 dialog，支持 Escape、关闭按钮与焦点返回。手机菜单有展开状态并支持 Escape。页面 hash 可直达首页、文档、博客全文、更新日志及文章章节。

## 5. 布局

首页：定位 → 工作台大图 → Context / Review 两段能力 → 本地、控制、扩展三项原则 → 历史更新入口 → 上手入口。

文档：宽屏采用左分类、中正文、右页内目录，窄屏收起文档目录；标题搜索直接筛选已有 9 篇公开文档。

博客：一篇主推文章 + 编辑式文章列表，7 篇已有公开文章均可在原型内阅读全文。

更新日志：左侧日期、右侧完整更新内容，按时间倒序连续展示 8 条公开记录。取消固定章节栏与单篇返回导航，不伪造版本号。图片直接嵌入对应更新内容。

## 6. 层级和动效

原生 CSS 与语义变量作为唯一样式方案。无装饰阴影、玻璃、云海和渐变。首页标题短淡入，指针按压轻微缩放；键盘操作无按压动画，支持减少动态效果。

## 7. 内容边界

导航与页脚使用用户提供的紫色角色 Logo，裁去外围空白，保留原图颜色。原始 PNG 不带透明通道，因此当前保留白色底片，深色主题下仍可辨认黑色轨道；后续有透明原稿时可直接替换。

2026-09-19 通过 Computer Use 操作本机已安装的 ActSpace，采集浅色与深色工作台、上下文用量面板共四张实拍。工作台选用已有的代码格式测试会话；上下文面板使用同一会话的真实统计，局部裁切突出面板，未改写界面内容。图片随官网主题切换，放大时取当前可见图片。截图压缩后内嵌 HTML，应用的外观设置已恢复为原来的跟随系统。

Review 在本机已有会话中显示 `workspaceRoot is not registered`，未取得可用的当前变更截图。因此首页 Review 与历史更新详情暂时保留已有公开官网素材，首页图片替代文本与更新页图注保留历史来源说明。此问题记录为采集阻碍，不在本轮修改桌面端逻辑。正式上线前仍需补齐当前 Review 素材与对应发布内容。

当前没有配套操作录屏，因此移除面向访客的本地视频上传示例。正式发布时，在相关功能介绍中嵌入经核实的录屏、封面和原生播放控件。

文档、博客、上手和更新日志均在原型内切换；GitHub、开发计划与文章引用保留外链。正文来自现有公开 Markdown 的本次静态快照，正式站继续以原始内容为单一事实来源。
