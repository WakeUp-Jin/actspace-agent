# V0：实验矩阵

## 目标

建立 Lab 的基本产品形态：用户可以创建实验，在四阶段矩阵中记录假说、验证、锻造和评审。

## 范围

V0 做：

- Lab 页面入口。
- 实验矩阵视图。
- 创建实验。
- 编辑四阶段记录。
- 添加证据和产物引用。
- 基础状态：draft、active、blocked、candidate、promoted、rejected、abandoned。
- 手动评审结果。

V0 不做：

- 自动执行实验。
- 真沙箱。
- 自动生成 Rust CLI。
- 自动安装或启用 skill。
- Kairos 自动创建实验。
- 主 Agent 自动使用候选能力。

## 成功标准

- 用户能把一次想法完整记录为一轮实验。
- 一行实验能清楚展示四阶段推进状态。
- 产物和证据不会只停留在聊天上下文。
- 已晋升、已拒绝、已废弃实验可以通过 `已完成实验` 弹窗查看。
