# 05 界面与设置设计规范

只改造现有界面，复用现有组件和样式（`AgentRunBlock`、`BackgroundTag`、`BackgroundNoticeRow`、`SubagentsPanel`、设置的 `SettingGroup` 等），不引入新的视觉元素；实施中如果确实需要新的视觉元素，先做 HTML demo 给用户看。

## 1. 对话区

| 位置 | 变化 |
|---|---|
| `agent` / `agent_fork` / `agent_codex` / `agent_claude_code` 卡片（`AgentRunBlock`） | 单行卡片（2026-11-08 改）：头像、标题（`description`，没有时退回任务首行）、种类（通用、探索、Fork、Codex、Claude Code）、后台运行时的「后台」标签、状态。不再显示模型名和最新动态（动态在右侧「子 Agent」列表第二行）。点卡片打开右侧「子 Agent」并选中这个子智能体；规则见 [front-子Agent与后台任务规范 §2.1](../frontend/front-子Agent与后台任务规范.md#21-主会话里的子智能体) |
| `send_message` | 一行工具行：「发消息给 ‹描述›」，展开看消息原文；点目标名打开该子智能体 |
| `wait_agent` / `list_agents` / `list_subagent_models` | 一行工具行：「等待子智能体」「查看子智能体」「查看可选模型」，只有标题，不带工具结果 |
| `interrupt_agent` | 一行工具行：「停止 ‹描述›」 |
| 子智能体完成通知（收件箱 `subagent_notification`） | 不显示（2026-11-07 改）：结果看派发卡片的状态。唤醒空闲会话时仍开新的一轮，但没有开头行；规则见 [front-子Agent与后台任务规范 §2.1](../frontend/front-子Agent与后台任务规范.md#21-主会话里的子智能体) |
| 子智能体发来的消息（`agent_message`） | 来信卡片 `SubagentMessageCard`（2026-11-08 改）：头部同单行卡片（头像、标题、蓝色「来信」、发送方状态），正文直接显示，超过 6 行折叠；本轮结束后排在「Worked for」外、最终回复前 |
| Bash 后台通知 | 不变；`taskKind` 只剩 bash |
| 通知行的位置 | 显示的通知（来信、Bash）：唤醒空闲会话的通知开一轮，作为该轮第一行；主会话运行中读到的通知（含退出重开后补的 lost 通知在下一轮被读到）留在这一轮里它被读到的位置，不拆轮，该轮有工具时收在过程组里。由领取事件的 `opensTurn` 区分 |

## 2. 右侧「子 Agent」面板

- 列表按**子智能体**列（一个子会话一行），不再按调用列。分「运行中 / 其他」两组，外观见 [子 Agent 列表与详情顶部栏](../frontend/front-子Agent与后台任务规范.md)（无外框）：头像、描述、第二行（运行中是此刻在做什么，刚来信 6 秒内是来信摘要；结束后是结果第一行），右上 token，右下「状态文字 · 最近一次激活的耗时」（只写文字，不叠图标，不显示「第 N 轮」；没有结果时左侧也不重复写状态）。种类和模型不在行里，放到详情顶部栏和标题悬停提示。
- 状态文字：运行中、空闲（可续派）、已中断、失败、已结束（外部，不能续派）。
- 运行中的行有「停止」按钮，调用新 IPC `interruptSubagent(sessionId, agentId)`，效果同 `interrupt_agent`。
- 详情：
  - 通用 / 探索 / Fork：沿用对话 / 轨迹切换。Fork 只显示分出之后的部分，顶部一行「从主会话 [#N] 分出」。
  - Codex / Claude Code：只显示最终回复和原生记录路径（复制、在 Finder 中显示），不显示轨迹。
- 右侧「后台任务」面板只显示 Bash。

## 3. 设置

| 位置 | 变化 |
|---|---|
| 设置 › 模型 › 用途 | 「子 Agent 探索」一行改为「子智能体」，下拉选可用模型，第一项「跟随主智能体」（默认）。保存到 `subagentDefaultModel` |
| 设置 › 子 Agent（`SubagentSection`） | 「Explore」一组改为「子智能体」：说明两个预设（通用：和主智能体一样的工具，能改文件、跑命令，不弹审批；探索：只读）、并发上限 10，链接到模型设置 |
| 扩展 › 插件 | 新增「Codex 子智能体」「Claude Code 子智能体」两个插件，默认关闭；说明它们用本机 CLI 和 CLI 自己的权限；没装 CLI 时显示不可用原因；插件设置见 [04 §4](04-外部子智能体设计规范.md) |

## 4. 其他界面

- 轨迹（`TrajectoryView` 及 `subagents.ts`、`RecordOverview`、`DetailPanel`）：父轨迹里委派一行按新事件取种类、描述与子会话；`send_message` 续派在父轨迹里也是一行，指向同一个子会话。
- 设置 › Harness 统计 › 运行（`RuntimeTab`）：子智能体按种类 / 预设统计次数与耗时，数据来自 `subagent/activation`。
- Web 客户端（`apps/web` 的 `EventRow`）：与桌面端同样的种类文字和通知行。
- 浏览器 mock（`?mock=`）：子智能体与后台任务的 mock 数据改为新结构，覆盖：运行中、空闲多轮、fork、Codex、已中断、lost。
