# V1：辅助实验

## 目标

让 Main Agent 能辅助用户推进 Lab 实验：研究资料、梳理假说、总结证据、生成阶段记录草稿。

## 范围

V1 做：

- Main Agent 根据用户指令创建实验。
- 从当前会话总结实验草稿。
- 辅助生成假说和成功标准。
- 辅助整理验证记录。
- 辅助生成 skill / doc / learning 草稿。
- 将 Agent 生成内容标记为草稿，等待用户确认。

V1 不做：

- 自动执行高风险命令。
- 自动晋升能力。
- 自动修改主 Agent 工具集。
- Kairos 后台自主推进完整实验。

## 成功标准

- 用户可以从聊天中一键沉淀实验。
- Agent 能把零散对话整理成结构化阶段记录。
- 人类仍清楚知道哪些内容是草稿，哪些内容已确认。
