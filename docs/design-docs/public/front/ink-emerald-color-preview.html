App、Sidebar、Surface 的层级在真实屏幕上可见，同时保持长时间阅读舒适。

Selected 不依赖彩色

浅灰底 + 字重 + 单色 current glyph 共同表达；running 仍由独立绿色圆点表达。

Ink action 足够明确

发送和保存优先级最高，但不形成纯黑大块；深色主题自动反色。

Operational 足够稀缺

只出现在运行点、Toggle、连接状态和进度，不进入普通 selected、hover 或按钮。
