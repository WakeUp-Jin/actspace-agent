侧边对话：这个 Demo 想确认的交互

入口

  • 右栏 + → 「侧边对话」（右栏为空时，启动列表第一项就是它）。
  • 主输入框输入 /side 问题，回车后在右侧新开侧边对话，并直接把问题发过去。

继承

  • 新开时复制主会话截至上一轮结束的上下文，之后两边互不影响。
  • 主会话正在跑时开（顶部切「运行中」再试），进行中的那一轮不带进来，提示条会写明。
  • 面板从空白开始，不重放主会话消息；开头一条居中分隔线「继承主会话 N 轮」，跟消息一起滚走，没有按钮。
  • 上下文用量一开始就不是 0（继承来的内容算在里面）。

独立会话

  • 可以同时开多个，各自流式输出；后台跑完的 tab 会亮一个小蓝点。
  • 模型默认继承主会话（标「继承」），可以切；权限默认「只读」，可以切到「需审批 / 自动执行」。
  • 只读时让它改文件会被拦下（输入里带「改」字试试）。
  • 标题先叫「侧边对话 N」，发第一条消息后用消息内容做标题。

长期保存

  • 关 tab 只是收起，+ 菜单和启动列表里「本会话的侧边对话」可以再打开，内容都在。
  • 左侧会话栏不单独列出侧边对话，只在主会话后面显示数量。

第一版不做

  • 从某条历史消息分出、侧边对话里再分出、回流主会话 / send_message。
