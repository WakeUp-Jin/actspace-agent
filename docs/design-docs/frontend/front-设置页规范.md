# 设置页规范

设置中心是全屏页面：左侧导航加右侧内容区，从应用内任意处进入，「返回应用」或 Esc 退出。本文只写设置页自己的结构、交互与各页面规则；全局的视觉 token、文案与状态表达、通用组件规则见前端必读规范（[视觉 token](front-视觉token规范.md)、[文案与状态表达](front-文案与状态表达规范.md)、[组件与交互模式](front-组件与交互模式规范.md)），这里不重复。

代码：`apps/desktop/src/renderer/components/settings/`（`SettingsPage.tsx`、`SettingsNav.tsx`、`SettingsPrimitives.tsx`、`sections/`、`models/`）、`components/UsageStatisticsPage.tsx`、`components/harness-stats/`。设置数据按 `SettingsV4` 命名空间读写（`packages/util/shared/src/settings.ts`）。

历史方案、Maka 对照与实施分期见归档：[设置中心重构规范](../../exec-plans/completed/design-archive/frontend/front-设置中心重构规范.md)、[模型设置页面 Maka 重做规范](../../exec-plans/completed/design-archive/frontend/front-模型设置页面-Maka重做规范.md)、[使用统计刷新](../../exec-plans/completed/design-archive/frontend/front-usage-statistics-refresh.md)。

## 1. 信息架构

导航分四组，顺序固定（`SETTINGS_GROUPS`）：

| 分组 | 页面 | 作用 |
|---|---|---|
| 偏好 | 通用 | 对话显示、个人偏好、Agent 指令、生成参数、媒体、语音、快捷键 |
| 偏好 | 外观 | 主题、强调色、字体与字号 |
| 能力 | 远端 Host | 配对并管理远端 Host |
| 能力 | 模型 | 用途、模型连接、连接详情 |
| 能力 | 搜索与网页读取 | 联网搜索开关、搜索通道 Key、网页读取 |
| 能力 | 工具 | 代码库 / 终端 / 浏览器 / 多媒体 / 显示 的工具开关 |
| 能力 | 子 Agent | 子智能体入口，默认模型在「模型」里配 |
| 活动 | 使用统计 | 请求、Token、费用的明细与汇总 |
| 活动 | Harness 统计 | Harness 运行统计，见 Harness 统计相关设计 |
| 活动 | 归档会话 | 查看并恢复已归档会话 |
| 系统 | 更新 | 本地源码构建更新 |

- 一个页面只回答一个问题，设置项按主题聚到页面里，不按开发者的模块划分。
- 搜索通道的 Key 属于「搜索与网页读取」，模型服务商的 Key 属于「模型」，不混放。
- 导航宽 216px，分组标题是 `text-act-xxs text-text-faint`；当前项 `bg-selected` 加 medium 字重，图标 15px。`<= 820px` 导航收成顶部横条，分组标题隐藏。
- 导航顶部是「返回应用」。Esc 在设置壳上等同返回；行内编辑器、菜单与弹窗先消费自己的 Esc（输入法组合期间不处理）。
- 当前页面记在窗口内存里（`WorkbenchLayout` 的状态，默认「通用」），不写盘；跨页跳转（如「前往模型设置看图模型」）通过 `onNavigate` 切页。
- 设置数据加载中显示「加载设置中…」，读取失败整页居中显示错误文字。

## 2. 页面壳与基础件

所有页面共用 `SettingsPrimitives.tsx`，新页面只用这些基础件，不自己拼卡片。

### 2.1 PageShell 与 PageHeader

- `PageShell`：内容居中，默认最大宽 736px，`width="wide"` 为 928px（使用统计、Harness 统计这类表格页）；横向内边距 48px，`<= 600px` 时 16px；页头与内容间距 36px，分组之间 36px（窄屏 28px）。
- `PageHeader`：标题 `text-act-xl font-semibold`。二级页传 `onBack`：**返回箭头与标题同一行**（`IconButton`，可读名称「返回 ‹上级名›」），不在标题上方另放返回链接；`leading` 放服务商 logo 这类身份图标；`description` 只给「官方 · 已连接」这类状态串，不写说明句。
- 一级页标题由 `PageShell title` 给出；「模型」页的页头由 `ModelsPage` 自己画，因为二级路由要把返回箭头放进标题行。

### 2.2 分组与行

- `SettingGroup`：分组标题（`text-act-sm font-semibold`，下文 `headingLevel` 3 或 4）+ 容器。容器是 `bg-surface`、1px 发丝线（`border-line`）、`rounded-act-group`（10px）、行间 `divide-line/60`，即「内嵌分组」。分组右上角可放 `meta`（短计数，如「6 / 6 已启用」）或 `action`（按钮）。`plain` 分组不画容器，只给标题，用于里面是卡片列表的场景。
- **行内容不缩进**：`SettingRow` 左右内边距 16px，标题与说明左对齐于同一条竖线，子项不再嵌套缩进；子层级用 `SettingSubhead`（`surface-subtle` 底的小标题行）区分。
- **没有页面副标题和分组说明**：页头与 `SettingGroup` 不挂 `description`。说明性文字只在两种情况保留：行的 `description` 写这一行**无法从标题看出**的后果或来源（如「网址将发送至 DeepSeek · ¥0.005 / 次」），以及风险提示（MiniMax Key 的说明、子 Agent 页「通用子智能体可改文件、跑命令，不弹审批。」）。
- 行高：`min-h-[52px]`，紧凑行（`tight`）`min-h-[44px]`；控件靠右，窄屏（`<= 600px`）控件换到标题下并撑满。
- `SettingRow`：标题 + 可选说明 + 右侧控件（`Toggle`、`SettingsSelect`、`SegmentedControl`、`Stepper`、`SettingsMenuButton` 等）。
- `SettingLinkRow`：整行可点，右侧 `›`；可带 `leading`、`value`（单行截断，最宽 240px）、`trailing`（状态点或标签）；有展开语义时带 `aria-expanded` / `aria-controls`。用于跳转子页、打开弹窗、展开高级项。
- 状态点 `StatusDot`（ok / off / warn / error / neutral）与标签 `SettingTag` 是设置页里表达状态的唯一方式；风险提示用 `InlineWarning`。

### 2.3 行内编辑与保存

| 场景 | 交互 |
|---|---|
| 开关、分段、下拉 | 改动即保存，成功后底部短暂出现「已保存」；失败在出错的那一行显示原因，控件回到旧值 |
| 单个文本 / 数值字段（生成参数、连接详情字段） | 失焦或回车提交，只提交合法且与已保存值不同的值；字段内短暂显示「已保存」；不合法在字段下写原因，不提交 |
| 需要多个字段一起确认的编辑（自定义提示词、Key、快捷键等） | 行下展开 `SettingEditor`：内容 + 左侧提示或错误 + 右侧「取消 / 保存」；Esc 取消，保存中禁用取消；关闭后焦点回到触发行 |
| 高风险或不可逆（删除连接、清除 Key、断开连接） | 二次确认（再点一次或菜单项确认），文案写清后果与是否保留历史 |

- `useSingleEditor`：同一页面同一时间只展开一个行内编辑器，打开新的会先关掉旧的。
- 保存提示由 `SettingsSaveNoticeProvider`（挂在设置壳上）统一提供，`useSettingsSaveNotice()` 触发：底部居中的深色小胶囊，默认文字「已保存」，1.4 秒后消失，`role="status"`；**只有成功才提示**。
- 需要用户知道「改了什么、影响什么」的场景直接把后果写在行说明里，不用 toast 代替。

## 3. 通用

`PageShell title="通用"`，自上而下的分组：

1. **性能监控**：「显示性能面板」开关。
2. **对话显示**：「显示本轮代码改动」开关。
3. **个人偏好**：「显示名称」「回复风格」，各自一个行内编辑器。
4. **Agent 指令**：「系统提示词」，行内编辑主 Agent 的自定义系统提示词。
5. **生成参数**：温度、最大输出 Token、自动压缩阈值；各用途用哪个模型在「模型」页，这里只留生成参数。温度需在 0–2，最大输出 Token 为 1–1,000,000 的整数，留空表示用模型默认值；失焦保存。
6. **媒体**：「图片生成」（有 Key 时说明写「模型 · 服务地址」，状态点「已配置 / 未配置」，点击打开配置弹窗）、「看图模型」（跳到「模型 › 用途」）。
7. **语音播放**：MiniMax Key、语音模型、音色、语速；仅在英语学习插件本次启动已加载时挂载。
8. **快捷键**：快速唤起的快捷键录制 / 恢复默认，打开目标（自动选第一个项目 / 指定工作区 / 指定会话）与对应的默认工作区、默认会话；已移除的工作区选项标「已移除的工作区（将自动降级）」。

## 4. 外观

`PageShell title="外观"`：

- **主题**：浅色 / 深色 / 跟随系统，三列迷你窗口预览（高 84px，选中描边加粗，「跟随系统」一半浅一半深），单选组。
- **强调色**：五个色板（默认、蓝、紫、粉、橙）做成带色样的胶囊单选，方向键循环切换，Home / End 跳首尾；色样用固定预览色，不随当前主题翻转。色值规则见[视觉 token 规范](front-视觉token规范.md)。
- **字体与字号**：界面字体、界面字号（步进器）、代码字体、代码字号（步进器）四行，分组末尾一块字体预览（正文一行加代码一行）。
- 所有外观设置即时生效并写入本机 `localStorage`（`appearance/storage.ts`），不需要「应用」按钮，也没有「已保存」提示。

## 5. 模型

`ModelsPage` 在一个页面里用本地路由切换四种视图：`list → catalog → setup → detail`，以及 `list → detail`。数据来自 `modelConnections` 的整份视图，页面只保存路由和添加连接时的草稿（`ConnectionDraft`）；添加失败等错误显示在页头下的 `ModelsError`（「知道了」关闭）。

### 5.1 列表（路由 list）

页头「模型」，下面两个分组：

- **用途**（`PurposesSection`）：每类任务用哪个模型与默认思考档位。行顺序固定：会话默认、轻量任务、自动审批、子智能体、看图。除「会话默认」外都可「跟随会话默认」（子智能体写「跟随主智能体」）；「看图」只能选带图片输入能力的模型；子智能体不显示思考档位。行说明一句话写用途（「新会话一开始用的模型」等）。选择器是与输入框同款的模型选择菜单，未设置显示「未设置」；选中模型后的思考档位区，如果还没有这个模型的思考信息，写「还没有这个模型的思考信息。」加「去补充」，跳到该连接详情并展开对应模型卡片（`onGoToModel`）。
- **模型连接**（`ConnectionListSection`）：分组右上角主按钮「添加连接」。每行 `SettingLinkRow`：服务商 logo、名称（自定义中转加「中转」标签）、协议名、「N 个模型」、有缺项时「N 个待补充」（warning 色）、状态点（已连接 / 连接失败 / 未测试 / 已停用）。没有连接写「还没有连接。」。

### 5.2 添加连接（路由 catalog → setup）

1. **选服务商**（`TemplateCatalogPage`）：页头「添加连接」带返回「模型」；顶部「搜索服务商」搜索框；下面按服务商分组（`PROVIDER_TEMPLATE_GROUP_LABELS`）列行：logo、名称、默认服务地址的域名、已添加的标「已添加」。同一服务商可以再加一次（比如两把 Key），自定义中转永远可加。
2. **填 Key**（`ConnectionSetupPage`）：页头是服务商名（中转为「自定义中转」）带 logo，返回「添加连接」。一个分组：
   - 中转多两行：协议（`SegmentedControl`）、服务地址；
   - 「API Key」（密码输入，等宽）；
   - 「高级设置」折叠：服务地址（非中转）、代理；
   - 行尾右侧「连接」主按钮，同一行左侧写错误（「请输入 API Key。」「请填写服务地址。」或探测失败原因），连接中按钮写「正在连接」。
   - 点「连接」先探测（`probe`），失败留在本页显示原因；成功才创建连接，提示「连接已保存」，并带着探测结果跳到连接详情。

### 5.3 连接详情（路由 detail）

页头：服务商 logo + 连接名，返回「模型」；说明串「官方 / 自定义中转 · 状态点 · 余额（有 Key 且服务商支持时）」。自上而下：

1. **连接**分组：名称（内置连接的名称来自模板，只读）、协议、服务地址、API Key、管理 Key（仅 OpenRouter，查余额用）、代理。每个字段是输入框，失焦保存，框内短暂显示「已保存」。已保存的 Key 显示掩码并写「已保存在本机，粘贴新的 Key 可替换」，不回显明文。
2. **模型**（plain 分组）：标题旁「N 个」，右上角「获取可用模型」按钮（获取中显示「正在获取…」并禁用）。下面是模型卡片列表、「手动添加」按钮。没有模型写「还没有模型。」（虚线框）。获取失败在列表上方一条 warning 提示「没拿到模型列表：原因」，可关闭。
3. **删除**（中转为「计费与删除」）：中转连接多一行「价格倍率」（`官方价 ×` 前缀的数值框，说明「手填的价格不乘倍率」）；删除行二次确认，文案写「再点一次确认，历史会话保留」，并说明连接及其模型都会移除。

规则：

- **获取可用模型**（`FetchModelsDialog`）：弹窗列出服务商返回的模型，带「搜索模型名称或 ID」、全选 / 取消全选；底部「已选 N 个」和「添加 N 个」，没选时禁用。弹窗没有标题下的解释句。刚建好的连接从 setup 跳进来时自动带着探测结果弹出该窗口；服务商没开放列表写「这个服务没有开放模型列表。」，返回为空写「返回的模型列表是空的。」。
- **模型卡片**（`ModelCard`）：折叠态一行：模型家族标记、显示名称、与显示名称不同时的 API 模型 ID（等宽、截断）、缺项标记、右侧能力摘要（窄屏隐藏）、「移除」（悬停或聚焦才显现，窄屏常显）与展开箭头；整行可点展开。展开后是字段表单（`ModelFields`）加「显示更多」（更多字段二级展开）。没认出来的模型（目录里没有）顶部一条 warning「没认出来：填上上下文和价格，用量和费用才算得准」，目录里有近似项时给「按 X 填」，已套用时给「不按 X 填」。缺项的模型计入列表里的「N 个待补充」。
- **移除撤销**：移除模型后，原位置出现一条撤销条「已移除 X」+「撤销」，可关闭；若被移除的模型正好被用途选中，条上写明受影响的用途（「会话默认」需要重新选一个模型，其他用途改为跟随会话默认）。
- **手动添加**（`AddModelPanel`）：「模型 ID」必填、「显示名称（可选）」，保存提示「模型已添加」。
- 所有修改都走 `modelConnectionsApi`，成功后用整份视图覆盖本地视图；删除连接成功后回到列表。

### 5.4 数据与安全

- Key 与代理地址只存本机，renderer 读到的视图只带 `hasApiKey`，永不带明文。
- 价格以官方价为基准，中转的价格倍率只作用于未手填价格的模型。
- 模型能力、价格等模板数据的来源与校验见 `docs/design-docs/` 下模型连接相关设计；这里只定义界面。

## 6. 搜索与网页读取

`PageShell title="搜索与网页读取"`：

- **联网搜索**：单行「允许联网搜索」开关。
- **搜索通道**：分组右上角 meta「N / 5 已连接」。行：DeepSeek、智谱 Web Search、Tavily、TinyFish、Exa。每行有 logo、名称、状态点；已连接的行有启用开关和「管理」菜单（更换 Key / 断开连接），未连接的行点开行内编辑器填 Key；没有 Key 时启用开关禁用。
- **网页读取**：「使用 DeepSeek 抓取网页」开关；说明写明网址会发给 DeepSeek 及单次价格；没有 DeepSeek Key 时说明改为「请先连接 DeepSeek」并禁用开关。

## 7. 工具

`PageShell title="工具"`，分组与顺序固定：

| 分组 | 内容 |
|---|---|
| 代码库 | 文件读写 / 搜索等工具开关，meta「N / M 已启用」 |
| 终端 | Bash 开关；「执行前确认」开关（Bash 关闭时禁用） |
| 浏览器 | 「浏览器工具」总开关；「高级设置」展开后分「执行工具」「敏感能力」两个小标题，逐项开关；仅在浏览器插件本次启动已加载时显示 |
| 多媒体 | 图片生成等工具开关；图片生成服务未配置时行内警告「图片生成服务尚未配置，工具不会出现。」 |
| 显示 | 「显示写入变动」开关 |

工具显示名一律用中文，不露内部工具名；开关改动即保存。

## 8. 子 Agent

`PageShell title="子 Agent"`：一个分组「子智能体」，只有一行「子智能体默认模型」，点击跳到「模型 › 用途 › 子智能体」；分组说明保留一句风险提示「通用子智能体可改文件、跑命令，不弹审批。」。模型选择只在「模型」页做，这里不重复控件。

## 9. 远端 Host

页头「Agent 服务器」。页面结构：已保存的 Host 列表（名称、地址、状态、出错原因、「重新连接」等操作）和「添加服务器」表单：名称、连接方式（WSS / SSH 隧道）、服务器地址（SSH 隧道时为「SSH 配置别名」并多一项「服务器上的 Host 端口」，默认 4317）、「一次性配对码」（密码输入），按钮「配对并连接」（连接中写「正在连接…」）。失败时给可操作的原因：「服务器身份或协议不匹配，请核实服务器配置。」「连接未成功，请检查服务器地址、网络和服务器运行状态后重试。」配对码只用一次，不保存。

当前实现没有挂在 `PageShell` 上（自带 `max-w-2xl` 容器与 `h2`），标题字号和间距与其他页不一致，也不是「内嵌分组」样式；后续应收口到 `PageShell` + `SettingGroup`，不要再新增一套页面壳。

## 10. 使用统计

`UsageStatisticsPage`，`PageShell width="wide"` 加外层 `overflow-auto` 的 `main`（设置内容区在该页改为 `overflow-hidden`，由页面自己滚动）。数据来自使用活动快照（`UsageActivitySnapshot`），由 `SettingsPage` 的 `onUsageRefresh` / `onUsageRequestPageChange` 查询。

### 10.1 控件与筛选

- 顶部一行：时间范围分段（24 小时 / 7 天 / 30 天 / 全部）+ 刷新按钮（`IconButton`，可读名称「刷新使用统计」，读取中禁用）。
- 汇总四格：请求数、Token 用量（附「输入 · 输出」明细）、费用、缓存命中率（附缓存 Token）。
- 分类页签：请求日志、服务商、模型、工具（页签文字不带计数）。下面是筛选行：搜索框；请求日志页多一个「筛选状态」下拉（全部状态 / 成功 / 失败 / 已中止 / 未知）；有筛选时出现「清除筛选」；请求日志页右侧「显示明细」开关。
- 范围、状态、搜索词、页签、「显示明细」存入 `activity.usage` 命名空间（`SettingsV4UsagePreferences`）：300ms 去抖写入，范围 `24h / 7d / 30d / all` 与界面范围一一对应；旧值 `pricing` 页签回落到请求日志。
- 查询在筛选条件变化后 200ms 去抖触发，分页由后端完成（每页大小以响应为准）；读取中保留旧数据并在底部写「正在刷新…」。

### 10.2 请求日志与聚合表

- 请求日志列：时间、类型（模型 / 工具）、对象（模型 ID 去掉服务商前缀，等宽截断）、会话（标题，没有标题写「未命名会话 · ‹短 id›」）、Token、费用、耗时、状态（`StatusDot`：成功 / 失败 / 已中止 / 进行中 / 未知）。表格最小宽 800px，窄屏横向滚动；长值单行截断，悬停显示完整内容（`CellHint`），悬停卡片给 Token 与模型细节。工具行的 Token 与费用写「—」。
- 服务商、模型、工具页签是聚合表：名称（附连接信息）、调用数、Token（工具页为失败数）、费用等；工具页没有 Token 与费用。
- 空结果：有筛选写「没有符合筛选条件的记录」，否则「所选时间范围内暂无使用记录」。
- 底部分页：「a–b / 总数」加翻页。

### 10.3 口径与缺口

- 命中率与输入框会话胶囊同一算法：缓存读 ÷（未缓存输入 + 缓存读 + 缓存写），只用已知部分；没有任何已知输入依据时显示「—」。
- **缺口不当成 0**：没有任何用量的请求（失败或未完成）、模型未配置价格的请求、服务商没返回缓存字段的请求都不参与对应数值；全部请求都缺 Token 时 Token 显示「—」。有缺口时汇总下方一行小字「有 N 次请求缺少用量或定价，数值为已知部分的合计」，悬停给原因拆分（请求失败或未完成 / 模型未配置价格 / 服务商未返回缓存字段，各自次数）。
- 费用：一个已知费用都没有时写「费用未知」，不显示 $0.00；含来源未验证的历史记录时在费用格下注明。费用统一 USD、两位小数。
- 读取状态：读取中显示阶段文字（等待查询 / 检查使用记录 / 正在同步使用记录 / 正在重建统计索引 / 查询中）和取消；部分会话读不了写「有 N 个会话暂时无法读取，当前统计不包含这些会话。可刷新重试。」；索引不可用回退到会话记录时写「统计索引暂不可用，当前结果从会话记录读取。可刷新重试。」；读取失败的 IPC 技术错误折叠进「错误详情」，主文案写「使用统计读取失败，请重试。」加「重试」。

## 12. 归档会话

`PageShell title="归档会话"`，一个分组「已归档」：每行会话标题、「更新时间 · N 次运行 · 工作区名」，右侧「恢复」按钮（恢复中禁用并写「恢复中…」）。加载中写「正在加载归档会话…」，空写「暂无归档会话」，恢复失败写「恢复归档会话失败。」。恢复成功后刷新列表并通知侧栏刷新会话。没有搜索，也不在这里永久删除。

## 13. 更新

`PageShell title="更新"`：「更新来源」分组，三行：「源码目录」、「安装目标」、「构建并更新」。构建更新的进度在 `LocalUpdateProgressDialog` 里显示；有日志文件时在行内给出「日志：路径」。

## 14. 数据与存储归属

| 数据 | 归属 |
|---|---|
| 通用、工具与搜索开关、媒体、使用统计偏好 | `SettingsV4` 对应命名空间（`general`、`tools`、`media`、`activity.usage` 等），经 `updateNamespace` 写入 |
| 外观（主题、强调色、字体字号） | 本机 `localStorage`（`appearance/storage.ts`），不进 `SettingsV4` |
| 模型连接、模型、用途绑定 | `modelConnections`（`modelConnectionsApi`），不在 `SettingsV4` 里 |
| 服务商 / 搜索 / 语音 Key | 本机密钥存储，renderer 只看到 `hasApiKey` |
| 远端 Host 配对 | Host 配对存储，配对码不落盘 |
| 当前设置页、未保存的行内编辑草稿 | 窗口内存，退出设置即丢弃 |

## 15. 响应式与无障碍

- `<= 820px` 导航变顶部横条；`<= 600px` 页面横向内边距 16px，行内控件换行撑满，分段控件撑满宽度。
- 每个控件都有可读名称（`ariaLabel` 写动作而非「按钮」，如「前往模型设置看图模型」）；开关、分段、下拉可键盘操作；`SettingLinkRow` 的展开态带 `aria-expanded`。
- 导航当前项 `aria-current="page"`；保存提示 `role="status"`；错误提示 `role="alert"`。
- 减少动态效果偏好下，保存提示与展开动画不做位移过渡。

## 16. 不做

- 页面副标题、分组说明句；设置项的搜索框；设置页内的版本说明。
- 设置的导入 / 导出；在设置页永久删除会话；模型价格的在线同步入口。
- 把设置页拆成多窗口或浮层；在行内再嵌套第三层缩进。

## 17. 验收

- 每个页面：浅色、深色、`<= 820px` 与 `<= 600px` 都要看；长服务地址、长模型名、长路径单行截断且悬停可见完整内容。
- 行内编辑：打开第二个编辑器时第一个关闭；Esc 只取消最内层的编辑器，不会直接退出设置页；保存失败时错误出现在对应行，值回滚。
- 模型：添加连接全程（选服务商、填 Key、探测失败、探测成功跳详情并弹出获取窗口）；移除模型与撤销；删除连接二次确认；用途选择器与「去补齐」跳转；Key 不回显明文。
- 使用统计：24 小时 / 7 天 / 30 天 / 全部切换；筛选与翻页期间旧响应不混入新结果；有缺口时汇总下方出现提示；费用全未知时写「费用未知」。
- 浏览器 mock 的覆盖见[前端验证清单](../../FRONTEND_VERIFICATION.md)；真实 Key、真实探测、Host 配对与本地更新构建只能在 Electron 下验。
