主题

DeepSeek 新 API 的两项能力落到界面上会变的地方：深度搜索的工具行、回复里怎么标出处、文档解析、设置里的两个开关。示例内容取自 2026-11-14 用真实 Key 跑的几次调用，只用来看样式，不代表结论正确。蓝色虚线标签是 demo 的说明，不是产品界面。

1 运行时：深度搜索这一行怎么显示

一次深度搜索实测 13–23 秒：内部搜 2–7 次、读几个网页，再写一段带出处的结论交给主模型。下面四种显示方式走同一条时间线（取自 13.3 秒的那一次）；「现状」的行数和节奏是示意，没有做新旧耗时对比。播完后点 Worked for 展开过程，再点工具行看详情。

2 完成之后：行尾统计与展开内容

完成后的行是「动作、问题、计费搜索次数、引用来源数」，和其他工具行一样没有图标，箭头悬停才出现。展开内容有三种密度，展开框和现有工具详情一样最高 280px，超出在框内滚动。后面是有网页打不开、失败、中止几种状态。带箭头的行都可以点。

3 最终回复里怎么标出处

工具把「结论 + 编号来源」交给主模型，最终回复由主模型写。下面三种都是现有 Markdown 渲染器已经支持的写法（已在真实渲染器里核对，脚注区固定排在整条回复最后），不用改渲染器；选哪种只影响写给模型的提示词。

4 文档解析

打开开关并连接 DeepSeek 时，PDF、Word、PPT 和扫描件交给 DeepSeek OCR，拿回 Markdown；工具行沿用 Read，行尾是页数。实测 2 页约 3 秒、15 页约 12 秒、124 页约 16 秒。开关关闭或没有 Key 时不变，仍由模型按 pdf、office-docx 这些 Skill 写 Python 提取。

5 设置里的两个开关

深度搜索的开关放在「搜索与网页读取」页，写法照搬现有的「使用 DeepSeek 抓取网页」：说明只写外发和价格，没有 Key 时写「请先连接 DeepSeek」并置灰。文档解析的开关有两个候选位置，只留一处。开关可以点，上面可以切换 DeepSeek 的连接状态。

6 需要你确认的点

要你定的
  1. 运行时的行：A、B、C 选一个。建议 B。
  2. 展开内容：a 只列来源、b 搜索词加来源、c 全部步骤。建议 b。
  3. 回复里的出处：行内链接、脚注、文末来源。建议行内链接。
  4. 文档开关的位置：① 搜索与网页读取页新增「文档解析」组，② 工具页「多媒体」组。建议 ②：它是一个工具的开关，其他工具的开关都在那一页，服务没接上时的提示也有现成写法；「搜索与网页读取」这个页名不包含文档。
  5. 默认值：深度搜索建议默认关。现有的 DeepSeek 搜索通道和「使用 DeepSeek 抓取网页」都默认关，深度搜索一次约 ¥0.03–0.08。文档解析按你说的「有 Key 就直接走 OCR」是默认开；代价是升级后已经填过 DeepSeek Key 的人，文档会从本机提取变成发给 DeepSeek。默认开还是关由你定。
  6. Chat 模式：深度搜索建议进 Chat，做成现有 web 工具的第三种动作，Chat 仍然只有两个工具。文档解析第一版不进 Chat：Chat 没有文件工具，要另做发送时解析。
  7. 附件入口：本机 Agent / Plan 的「+」现在只收图片。要不要放开到 PDF、Word、PPT（第 4 节的输入框）；不放开也能用，只是只能读工作区里已有的文件。
  8. 大文档：按页计费，124 页约 ¥0.19。要不要设一个页数上限，超过先问。
和现行规范的出入
  • 工具预览规范要新增两节：Deep Search 行和文档的 Read 行。Web Search 一节不动。
  • 现在 Web Search 展开后是输出原文的前 2000 个字符（等宽）。深度搜索展开后改成整理过的搜索词和来源列表，是新样式。
  • 来源只写标题和站点，都来自 DeepSeek 的返回，原样显示。聊天区不加载远程图片，所以没有站点图标；发布日期实测有明显错的（一条是 2004 年），不显示；个别标题也不准（tauri.app/blog 返回的是「On this page」）。
  • B 行尾的当前动作走现有的进度消息，不用改协议；它属于工具执行状态，按文案规范用英文。C 要新增结构化进度，子行的缩进也和中间消息区规范的「过程行共用同一左边缘、没有子分组」冲突。
  • 聊天输入框规范里「本机 Agent / Plan 的 + 面板显示图片」要改；设置页规范第 6、7 节要加行。
对标
  • DeepSeek 官方 chat-demo：思考和工具步骤排成一条可折叠的时间线，标题随阶段变（正在思考、正在搜索、正在浏览网页），步骤写「搜索到 N 个网页」「浏览 N 个页面」，点开是搜索结果面板；正文里的引用带悬浮卡片和站点图标。
  • ChatGPT、Claude 这类对话产品：运行时一行当前动作，结束后收成一行，展开是来源列表；句末跟来源标记。
  • 取：一行加当前动作；展开看搜索词和来源；回复里用普通链接。
  • 不取：站点图标、来源卡片和侧栏面板、常驻的步骤时间线。ActSpace 的过程行是安静的单行，回复结束后整体收进 Worked for。
