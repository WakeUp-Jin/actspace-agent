左侧会话栏 · 改版 Demo

骨架照 DSH，微交互借 Cursor。左边是可以直接点的侧栏。

  1. 搜索收成一个图标DSH点「工作区」右边的 🔍：输入框在标题行原地展开，结果替换整个列表；Esc 或 ✕ 收起。试试搜「审批」「DSH」。
  2. 分区标题可以整个收起Cursor鼠标放到「已置顶」「工作区」上，标签旁出现 ∨，点一下整区收起。刷新页面后状态还在。
  3. 文件夹 ↔ 箭头交叉淡入并旋转Cursor悬停工作区行，文件夹换成箭头，展开时转到朝下；当前会话所在的文件夹染成强调色（右下角换个强调色看更明显）。
  4. 视图选项DSH + 按时间点 🔍 右边的滑杆：分组（按工作区 / 单列表 / 按时间）、排序（手动 / 最近更新）、筛选归档。改过之后按钮带强调色小点。
  5. 拖拽 = 手动排序DSH会话只能在本组内拖（置顶区自己一组），工作区行可以整组拖，单列表整个列表一个顺序。拖一下就自动切到「手动排序」。已归档、空白会话、「未分组」不能拖；按时间分组时不能拖。
  6. 按时间分组 + 需要处理Codex需要处理（待审批 / 失败 / 完成未读）→ 今天 → 昨天 → 7 天内按星期 → 本月更早 → 按月。处理完（点开）就回到原来的时间组。每组标题可以收起。
  7. 每组 5 条 + 展开其余 N 个DSH运行中、待审批的会话不占名额；全部展开后变「收起」。
  8. 会话状态DSH转圈 = 运行中；琥珀点 + 「待审批」替换时间；绿点 = 完成未读（点开即消失）；红点 = 失败；空闲不显示。时间改中文「3小时」「2个月」。
  9. 悬停操作会话行悬停时，时间让位给 ⋯ / 归档 / 置顶；工作区行悬停出现 ⋯ 和 +（在这个工作区新建会话）。
