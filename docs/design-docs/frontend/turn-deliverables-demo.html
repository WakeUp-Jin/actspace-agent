数据从哪来

  • 改动摘要：本轮已完成的 write_file / edit_file 结果，按路径合并为净变化；删除的文件移出列表。数据随会话持久化，重开历史会话卡片仍在。
  • 交付：新增 present 工具，Agent 声明 files: [{ path, description? }]；后端校验文件存在后写入 deliverables/presented 事件。只取最终回复之前的声明，同路径取最后一次说明。
  • 两类卡片互相独立：同一文件可以同时出现在两处，数量也不必一致。

改动摘要卡

  • 单文件只显示标题「修改了 xx」；多文件显示列表，超过 4 行折叠。
  • 悬停标题时，统计换成「查看本轮改动」；文件行停 500ms 弹出单栏 diff，宽度为卡片宽 − 48px，高度最多 420px，下方放不下就放上方。
  • 移到浮层上会保持打开；移出 200ms 后关闭；Esc、滚动、点击都会关闭。
  • 点标题打开第一项，点行打开对应项；同一轮只占一个 Review 标签页。

交付卡

  • 高 60px，图标框 40px；默认双列，卡片容器 ≤ 620px 时单列（container query）；超过 4 张折叠。
  • 悬停时说明换成「在侧边栏预览」；打开中、已打开、失败等状态不会被悬停覆盖，成功状态 5 秒后淡出。
  • 右侧按钮用默认应用打开，下拉菜单列出关联应用，最后一项是「在 Finder 中显示」。
