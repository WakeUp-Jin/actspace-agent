① 列表边框

现状的问题：整行贴满卡片，分隔线两头直接顶到圆角边框，悬停底色把边框和圆角盖住，边和线挤在一起。下面四种处理方式，列表内容相同，鼠标移上去看悬停。

② 运行中的停止按钮

不要常驻停止按钮：运行中默认只有转圈，鼠标移到那一行（或键盘聚焦）才出现停止。点击行的其他地方仍是打开详情。下面是四种放法，移到「运行中」的行上看效果。

③ 子智能体返回时，主会话的样子

场景：主 Agent 并行派出 4 个子智能体后循环「等待 → 一个返回 → 再等待」。现状每次返回都是一条全宽分隔线，「等待子智能体」后面还跟着一句 wait_agent completed Input arrived.，看起来像调试输出。点开每个变体里的「已完成」，可以看到结论展开。

正文是现有主会话样式，这次不动；只改子智能体返回那一块。
