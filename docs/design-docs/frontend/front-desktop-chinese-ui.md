## 范围

侧栏、输入框普通操作、工作区控件、右侧文件/变更审查/上下文/终端/子 Agent 列表，以及现有设置页面使用简体中文。按钮、占位符、空态、菜单、Tooltip 和无障碍名称保持一致。

轨迹详情、消息中的工具执行卡片、独立扩展页面、开发诊断、系统原生菜单、官网与 CLI 不属于本轮覆盖范围。

## 保留英文

- Chat、Plan、Thinking、Effort 及 Auto、Minimal、Low、Medium、High、Extra High、Max、Ultra 档位保持原样。
- 工具执行名称、执行状态、执行行及其生成逻辑保持原样，设置与工具清单也不重命名工具。
- Agent、Skills、Token、Git、API、SSH、模型/服务商/外部应用/协议名称保持原样。
- 用户内容、模型回复、Skill 原始描述、代码、路径、分支名、终端输出、外部错误详情保持原样。
- 已保存的会话名和工作区名属于数据，即使是 New chat 或 Default workspace，也不按字符串批量翻译。

## 展示边界

- 不新增语言设置、语言包、国际化框架或自动翻译。以后完整支持切换和持久化时，再加入“界面语言”；与回复语言、英语学习功能分别管理。
- 上下文分类在桌面层按稳定 key 映射为系统提示词、工具、规则、Skills、会话摘要、会话内容，未知 key 原样展示。共享注册表、顺序和颜色不变。
- 宿主默认终端标题 Terminal N 在桌面层显示为“终端 N”，创建、恢复与重启一致；自定义标题原样展示，不修改宿主数据。
- 斜杠菜单保留原命令，说明使用中文；中文搜索与原英文关键词同时可用，命令前缀排序不变。
- 显示状态与机器状态分离，例如终端状态显示“已退出”但属性值仍为 exited。时间和数值展示明确采用简体中文格式，时区与金额单位不变。
