规则

  • 手动和自动触发完全一样：同一个组件、同一套文案，都是对话流里独立的一行，不贴进上一条回复。
  • 进行中只显示已用时间，后端没有真实进度就用不确定进度条，不编造百分比。
  • 压缩中不能发送、不能停止，停止按钮置灰，提示「压缩完成后可继续」。压缩期间排队发送由独立的消息队列功能负责。
  • 完成后留一条分隔线，点开能看到模型拿到的摘要。上面的旧消息不置灰，照常可读。
  • 失败时显示红色分隔线，附原因和「重试」。无需压缩只弹一次提示，不在对话里留记录。
  • 不加图标、卡片和 pill，状态靠文案、位置和进度条表达。
