胶囊什么时候出现 照 DSH 分支

  • 统计胶囊：steps === 0 → 整个不渲染。简洁模式只留速度，速度算不出来也整个不渲染。
  • 统计胶囊不可点时：模型用时 ≤ 0 && 工具用时 ≤ 0 && TTFT 步数 ≤ 0 && 速度为空 → 渲染成只读文字，不变成按钮、点了也不弹面板。
  • 用量胶囊：投影为空 ‖ (计费输入 = 0 && 输出 = 0) → 整个不渲染。计费输入 = 未缓存 + 缓存读取 + 缓存写入。
  • 简洁模式下用量胶囊只留缓存命中，命中率算不出来就不渲染。

切换上面的「场景」按钮，可以直接看这四种情况。

两个数字各自回答什么

  • N 轮 M 步 · 输出速度 —— 这次会话跑了多长、多快。
  • 总量 tok · 缓存命中 —— 这次会话一共用了多少、省了多少。
  • context 占用环 —— 现在这一发请求离上限还有多远。

前两个是全 Session 累计，第三个是当前压力。放同一行读成一句话，但数字天生不会相等。

展开面板里各是什么

照 DSH 实现 面板标题栏：左边图标 + 标题，右边标题值（只有用量面板有）。

  • 会话统计（无标题值）：模型用时 / 工具调用用时 / 首 token 平均（TTFT）/ 输出速度（TPS），有值才出行。
  • Token 用量（标题值 = 总 token）：缓存命中 / 未缓存输入 / 缓存读取 / 输出；缓存写入只有非 0 才出行。

关闭方式照 stat-dialog.ts：Esc、点击面板外、或再次点自己。面板向上弹出、离触发点 8px，并夹在视口内（边距 12px）。

数字口径

  • 模型用时 = Σ assistant/message − step/start。
  • 工具用时 = Σ 每次 tool/result − tool/call；并行时会大于墙钟。
  • 首 token 平均 = Σ TTFT ÷ 有计时的步数。
  • 输出速度 = 总输出 token ÷ 总解码时长，不是各次速度的平均。
  • 时长：不足 60 秒 → 45.2秒；否则 → 2分42秒。
  • 速度：≥ 10 取整，< 10 保留一位小数。
  • 缓存命中：非全命中但四舍五入会变成 100% 时，自动加小数位。

待你拍板 开放

  • 「运行中」那个脉动小圆点是 ActSpace 加的，DSH 没有——留不留。
  • 这三个东西放同一行会不会太挤；要不要把 context 环收进 Context 面板、dock 只留两个胶囊。
