消息队列与运行中插入

Agent 运行时继续输入：Enter 进入输入框上方的队列，运行结束后依次发出；「↳ 插入」把一条送进正在运行的回合。点场景自动播放，播放中和「自己试试」里都可以直接操作托盘。

规则

  • 发送按钮只有两种样子：输入框有内容时是 ↑ 发送（运行中点它或按 Enter 就是加入队列），运行中且输入框为空时是 ■ 停止。压缩中也能排队，只是停止按钮置灰。
  • 一条排队消息就是一个新回合，不合并。当前运行正常结束后发出队首一条，结束后再发下一条。
  • 「↳ 插入」把消息送进正在运行的回合，Agent 开始下一步时读到。它在对话里就是一条普通用户消息，出现在被读到的位置。
  • Agent 正在写最后的回复时插入，回合不结束，多跑一步处理这条消息。
  • 读到之前可以撤回，撤回后回到队列。停止时还没读到的插入回到队列顶部，不丢。
  • 停止或失败后队列暂停，不自动发出。点「继续发送」或直接发一条新消息后恢复。
  • /compact 可以排队，不能插入。压缩进行中或等待审批时，「插入」不可用。
  • 「···」里是编辑（输入框为空时把这条拿回输入框）和上移。删除直接生效，不二次确认。
  • 队列只在本次打开应用期间保留，和草稿一样；每个会话一份，切到别的会话后照常在后台发出。
