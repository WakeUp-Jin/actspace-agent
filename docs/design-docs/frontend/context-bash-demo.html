只有两样东西

  • 3 个数：调用次数、失败次数、合计耗时。
  • 程序分布：每个程序被用了几次、占比、失败几次。git / pnpm / npm / yarn / cargo / go / gh / docker 可以点开看子命令。默认显示前 8 个。

计数口径

  • cd src && pnpm test | tail -20 记为 pnpm test 1 次、tail 1 次；cd 前缀、FOO=1、sudo/timeout/env/nohup/time 都跳过。
  • 出现一次就记 1 次：cat a && cat b 记 cat ×2。这次调用失败，里面每个程序各记 1 次失败。

没有的（对照 DSH 砍掉）

  • 「最慢的命令」「重复命令」这类要展示命令原文的提示。
  • 按程序拆耗时（复合命令的耗时拆不开）。
  • 失败占比、后台次数。
