主题

边框已定 B（卡片去边框，横线分隔），Bash 卡片已定「一行总览」。下面只比较两处，都可以点。
路径：「1」把现在应用里的路径卡片原样搬到 B 风格里：两格统计兼作切换，列表按目录分组，每行带标签、读取次数和上次读取时间。「2」把两格改成标签页，展开后直接列出前几条，不用再多点一次。
Bash 交互：「1」点程序（如 git、pnpm）展开子命令，带次数、条形和失败数。「2」在 1 的基础上，再点子命令能看到具体跑过哪些命令和各跑了几次；鼠标移到命令上出现「轨迹 ↗」，点了跳到轨迹里那次调用。「值得注意」里的命令两种方案都能点着跳轨迹。
右边是同一块面板的完整样子，左右两栏只是两种状态：左边是刚打开时，右边是点开以后。
