Codex Codex App 现在的做法推荐 我的建议

固定规则（不用选）

  • 同一个编辑器：预览和源码是同一个 CM6 实例，只开关装饰；撤销历史、光标、未保存内容两边共享。
  • 失焦 = 纯阅读：编辑器没焦点时所有标记都隐藏，看起来就是排好版的文档。
  • 标题：H1–H4 四档字号，H5/H6 同 H4；# 跟着 D1 露出。
  • 粗体 / 斜体 / 删除线 / 行内代码 / 链接：标记跟着 D1 露出。
  • 引用：第一层 > 隐藏，左侧竖线；嵌套引用保留 >（Codex）。
  • 分割线：整行画成细线，光标在这一行时还原 ---。
  • 原始 HTML：按源码淡色显示，不渲染、不执行（沿用现有安全约束）。
  • 未闭合的代码块：只加代码背景和左侧黄线，不隐藏围栏。
  • 源码模式：等宽字体、Markdown 语法高亮、⌘F 查找；没有任何装饰。
