## 页面结构

```text
使用统计                              标准设置标题
查看模型调用、Token 用量与费用。

[24 小时] [7 天] [30 天] [全部]       刷新统计图标

请求数       Token 用量       已知费用       缓存命中率
数值         数值            USD / CNY      百分比

请求日志 · 数量   服务商统计 · 数量   模型统计 · 数量   工具统计 · 数量
------------- 当前分类下划线 -----------------
搜索当前分类   状态筛选（请求）        详细记录开关   共 N 条记录

紧凑表格 / 空状态 / 可重试错误
行数范围                                 上一页 下一页
```

- 导航及标题统一改为“使用统计”；Provider、Model、Default workspace 分别使用“服务商”“模型”“默认工作区”，真实品牌、模型 ID、Token、USD/CNY 保持原名。不新增语言切换系统。
- 复用 `SettingsPrimitives.PageShell` 的标题与间距，使用已有 880px 宽度选项容纳八列表格；普通设置页默认宽度不变。标题保持共用原语的 22px 半粗样式。
- 页面只有一个纵向滚动容器。四项指标单层展示，数字 22–24px、tabular-nums；弱背景、无外层套卡、无额外阴影。窗口不足 800px 时两列、不足 400px 时一列。
- 时间范围沿用现有协议 day/week/month/total，文案明确为滚动 24 小时、7 天、30 天、全部，不将 day 错写为“今天”。切换范围重置明细分页。
- 分类使用中性下划线标签；请求详情用现有 Switch。翡翠绿只承担开启、成功等状态；普通筛选和选中 tab 不滥用成功色。
- 图标刷新具有 Tooltip、可访问名称与忙碌状态。所有文字、线条、背景使用现有主题 token，浅色、深色及跟随系统均验收。

## 分类、查询与数据一致性

新页面统一消费 activity 投影的完整时间窗统计与分类聚合；先过滤、后聚合、最后分页。服务商按真实连接身份保留可区分标签；模型按请求中的实际模型分组，不使用某次 Run 的主模型替代全部调用。

| 分类 | 默认列 | 详情 |
| --- | --- | --- |
| 请求日志 | 时间、类型、对象、会话、Token、费用、延迟、状态 | 同时展示模型与工具；模型单价和 Token 分解通过 Hover Card 查看；费用只显示金额 |
| 服务商 | 服务商/连接、请求数、Token、费用 | 各币种金额、未知费用请求数 |
| 模型 | 模型、服务商、请求数、Token、费用 | 实际 API ID、各币种金额、来源覆盖情况 |
| 工具 | 工具、调用数、失败数、耗时 | 不展示虚构模型费用 |

请求搜索与状态过滤传给主进程，作用于完整匹配集；分页时保留 range、search、status，筛选变化重置页码。请求分类内摘要及结果数量跟随查询；分类标签数量统计整个时间窗，不受日志筛选影响。请求日志包含工具调用，顶部请求数仍仅统计模型调用。其他分类不继承请求专属 status，搜索按当前分类生效。移除价目页签与更新按钮；旧设置 activeTab=pricing 自动回到请求日志。页面不读取目录，模型单价来自请求保存的价格快照。

请求表格最小宽度 800px，薄边框、圆角、约 36px 行高。长模型名和会话标题省略，hover/focus 可查看完整值；删除逐行展开的灰色详情块。“详细记录”控制整张日志表的显示，关闭后保留概览与分类。窄窗口允许表格局部横向滚动，不允许拖宽整个设置页面。

## 金额、状态与文案

- 全部请求可计价时标签“费用”；部分未知时为“已知费用”，附“另有 N 次请求缺少费用依据”；全部未知显示“费用未知”。USD 和 CNY 分别展示，不跨币种相加。
- 有效零价显示 `$0` 或 `¥0`；缺失值显示“—”并可查看原因。小额金额显示至最多六位小数，非零且低于最小精度时显示阈值提示。
- 费用列只显示金额，没有悬浮卡片或提示虚线；费用来源仍保存在数据中。当前价目变化不改变历史金额。`tool-calls` 结束的模型请求表示成功返回工具调用，显示“成功”；费用缺失与请求状态分别处理。
- 未加载时显示局部读取状态；刷新保留已有结果。加载失败提供“重试”，不得把失败伪装成“没有数据”，也不能悄悄回退另一种统计口径。
- 无记录：“所选时间范围内暂无使用记录”；筛选无结果：“没有符合筛选条件的记录”。无 Token 依据时缓存命中率显示“—”。
- 主页面移除 Journal、projection、watermark 等开发术语；模型与 Token 浮层只展示名称和数值，不显示标题、单位说明、来源、时间、推理说明或计算式。单价仍按每百万 Token 保存，货币符号保留。刷新统计按钮不触发价格网络请求。

先用 renderer fixture 验证空、全未知、部分已知、免费、USD/CNY 混合、微小金额、超长模型名、加载失败和多页筛选。随后按 [前端验证规范](../../FRONTEND_VERIFICATION.md)验证真实 Electron IPC、重启、主题、滚动与焦点。

截图覆盖 1440、1280、800 和 600px 窗口；比较对象为同一版本、同一主题下的普通设置页面。通过条件：标题起点与字号一致、无重复卡片边界、默认明细可读、窄窗口不撑破布局、所有控件可用键盘操作。

本轮不新增热力图、趋势图、账户账单、导出、自定义日期或预算告警。它们不影响本次核心问题的解决。

当前页面只消费 activity 聚合，未再回退旧统计；页面内私有 Metric / AggregateTable 复用结构，未另建组件目录。浮层宽度 208px，复用 Radix Hover Card 与主题 token，支持悬浮、键盘聚焦、点击与 Escape。Token 卡片保留合计分隔线，缓存写入为 0 时隐藏；单价卡片仅在有缓存写入单价时显示该行；没有价格快照显示“暂无单价”。实际验收和剩余宿主门禁见[执行摘要](../../exec-runs/20260906-actspace-usage-statistics/execution-summary.md)。
