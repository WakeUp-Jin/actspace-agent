# 官网视觉方向 Demo

> 2026-09-19：网站视觉与交互现行规范见 [apps/site/DESIGN.md](../../apps/site/DESIGN.md)。本页早期视觉探索不覆盖新规范。

状态：2026-09-09 历史候选。2026-09-19 已选择新的[黑白直角双主题方向](website-xai-preview.md)，后续评审使用[新样稿](website-xai-preview.html)。本 A/B/C 原型不再等待选择，保留供历史对照；没有修改 `apps/site`。

打开 [HTML Demo](website-style-demo.html)，顶部切换 A / B / C，网站导航切换首页、博客和更新日志。博客卡片可进入文章。HTML 内嵌素材，可直接离线打开。

## 1. 视觉主题

- A 纸面编辑：暖纸色、宋体标题、舒展的图文左右布局。以内容和阅读为中心。
- B 精密工作台：中性灰、黑体、直角分区、紧凑的信息栏。产品界面主导首屏。
- C 空间画廊：森林色与纸色、云景横幅、错位构图、大幅章节编号。强化品牌氛围。

三版复用内容，区别来自布局、字体、密度和动效节奏。参考 Claude 的 [博客列表](https://claude.com/blog) 与 [commerce agents 文章](https://claude.com/blog/claude-for-commerce-agents)：适度圆角、背景色层级而非阴影、暖中性色。保留现有博客的窄阅读列及更新页的连续时间轴。

## 2. 色板与职责

使用原生 CSS 变量作为唯一样式策略。A：纸色 `#f5f2eb`、墨色 `#282820`、陶土色 `#9b4b34`；B：灰白 `#f1f3f0`、墨色 `#202922`、绿色 `#286b44`；C：米白 `#eeeee5`、墨绿 `#23382e`、苔绿 `#4b6147`。颜色字面量仅在 token 定义中出现，按钮使用主题反色，状态与装饰分离。三版均提供深浅主题。

## 3. 字体

英文优先 Georgia / Avenir Next，中文分别使用 Songti SC / PingFang SC。A 标题 52px，B 48px，C 60px，移动端 34px。文章正文 18px / 1.85，阅读列 680px；标题和正文左边缘对齐。中文不使用负字距。

## 4. 组件

导航为文字链接；按钮按下缩放，键盘操作无动画。A 博客采用柔和背景卡片，B 为图文列表，C 为首篇重点展示和下方双列。搜索、分类过滤、产品标签切换均可体验。更新页日期可跳转，滚动同步活动日期。

## 5. 布局

首页顺序：产品定位与真实界面、Context / Review / Usage 体验、精选文章、上手入口。通用间距以 8px 为基准，版心 1160px；A 更舒展，B 更紧凑，C 以大图和不对称布局组织章节。

## 6. 层级与动效

以背景色和细分隔线建立层级，无玻璃面板和装饰阴影。首次进入区块淡入并上移；日期活动点平移；产品标签切换短淡入。仅动画 transform / opacity，支持系统减少动态效果。

## 7. 内容与边界

- 博客标题、日期和封面来自现有公开内容；Context 文章全文，其余为明确标注的节选。
- 更新记录取自公开 release 文档中的 2026-08 历史记录，不伪造版本号与发布状态。
- 产品图来自官网已有素材，属于历史界面，图片旁明确标注；正式更新必须另换当前版本截图。
- 首页文案为待评审提案，不代表新增能力。
- 不包含文档、路线图的完整改版，不接入下载、订阅、分析统计或正式发布流程。
- 不改变 Astro 源码、依赖、内容源与部署配置。

## 8. 响应式与验收

760px 以下采用单列，导航和方向切换保留可见；更新日期变为横向导航，文章元信息收至两列。交互目标至少 40px。验收覆盖桌面 1280px、手机 375px 与 320px，三版深浅主题、博客筛选与文章返回、日期跳转及产品标签切换。实际验收结果记录于任务 history。

## 9. 后续改版提示

- 选择 A 时：延续纸色、宋体 52px / 1.25、0 字距、8px 按钮圆角；博客卡片圆角 18px，无阴影。
- 选择 B 时：使用黑体 48px / 1.2、600 字重、0 字距、4px 按钮圆角；博客按图文行呈现。
- 选择 C 时：使用宋体 60px / 1.2、0 字距、胶囊按钮和云景横幅；阅读正文仍保留 680px 窄列。
- 可以组合首页方向与博客方向。用户选择后再制定 `apps/site` 的正式实施范围。
