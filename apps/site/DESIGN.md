# ActSpace Site 设计规范

状态：V4，阶段 A 及 T9/H1 精修已合入 main。2026-10-17 确认的 D6 方向已演进为当前桌面插件舞台；执行计划见 `docs/exec-plans/completed/20261017-site-v4-redesign.md`。早期 HTML 已本地备份迁出，见 [原型迁出清单](../../docs/design-docs/retired-html-demos.md)；正式实现和本文是当前视觉依据。

## 产品与风格

会自我进化的 Agent 运行空间。信念「唯变所适，每一个问题，都有它的空间」，来源是 `docs/design-docs/ActSpace产品概念思路初稿.md`。运行空间是主角，Actor 精灵不是主角：全首页精灵最多出现一处小面积（首屏窗口侧栏「Actor 名册」前的 15px 图标）。

全站只提供浅色纸本风格：暖纸画布 `--site-canvas`（#f2f1ed）、纸面 `--site-paper`（#fbfaf7）用于卡片和产品窗口、墨色正文 `--site-ink`，细线 `--site-line` 建立层级。品牌紫 `--site-accent`（#6d4fc2，取自 Logo）是全站唯一强调色，用于导航当前项、插件点亮、链接下划线、卡片悬停边框和焦点框。路线图状态色只用在状态胶囊上：已上线 `--site-live`（墨绿）、进行中 `--site-wip`（赭）。

舞台（`.stage`）是全站唯一的大面积色块：圆角 28px（手机 22px），多层径向渐变加内联 SVG 噪点纹理（opacity .2，multiply）。色场三套：桃 + 灰蓝（`.stage-peach`，首屏、Harness、结尾）、薄荷 + 柠檬（`.stage-mint`，上下文）、灰蓝为主（`.stage-slate`，Space）。**每屏大面积色块不超过两处。**颜色集中在 `src/styles/tokens.css`（单个 `:root`），组件只用语义变量；`--canvas`、`--ink` 等短别名为旧代码保留，新代码直接用 `--site-*`。

正文用系统无衬线（SF + 苹方，Windows 回落微软雅黑）。标题用系统衬线 `--site-font-display`（Charter + Songti SC，回落 Noto Serif SC / Georgia），字重 500，与博客 `--blog-serif` 是同一个变量；不加载 Web 字体，因为中文 Web 字体在国内加载不稳。等宽字体用于日期、文件路径、插件名和眉题（首页首屏不用眉题）。不对中文施加负字距。

## 全站骨架

- 页头 64px，固定顶部，背景画布半透明 + 模糊；Logo 后紧跟产品、文档、博客和更新日志，右侧依次为 GitHub 图标、分隔线与快速开始按钮。页头、文档侧栏和目录的吸顶位置共享 `--site-header-height`。
- 页面宽度 `--site-page`：最大 1360px，两侧留白 16–40px 随屏宽变化。
- 主按钮黑底白字、圆角胶囊，悬停转品牌紫，按下缩到 .97；辅助操作为带细下划线的文字链接。箭头悬停右移 3px。键盘焦点为品牌紫 2px 描边。
- 箭头规则：站内链接用 `→`，只有外部链接（GitHub 等）才用 `↗`。
- 导航当前项：文字加深、字重 500，底部 2px 圆角紫条。
- 小屏使用可展开导航，Escape 收起；页头保留 Logo、快速开始和菜单。站点链接经过 `sitePath()`，兼容 GitHub Pages 子路径。
- 页脚：左 Logo，右侧文档、博客、更新日志、开发计划、GitHub ↗；下方等宽小字 `© 年份 ActSpace · 唯变所适 · 会自我进化的 Agent 运行空间`。文档阅读区不追加营销页脚。
- Logo 使用带透明通道的 `src/assets/brand/actspace-mark.png`。2026-10-17 由 `actspace-logo.png` 改名：dev 图片接口缓存一年且 URL 不含内容哈希，改名才能让浏览器丢掉旧的白底版本。`public/brand/` 下的 favicon（透明底）、apple-touch-icon 与 OG 图（画布色 `#f2f1ed`）都由它生成。

## 首页

首页只有首屏和 Harness 块是 HTML/CSS 重绘的演示；其余功能块都用真实产品界面截图（桌面端渲染进程的浏览器 mock，示例数据），角标写「产品界面 · 示例数据」，Space 写「开发中演示 · 示例数据」，不叫「实拍」。2026-10-17 用户否决了单独的「实拍」截图区（RealShots），截图要放进对应功能块里。顺序：首屏 → 现状（能力卡）→ 改动与交付 → 执行轨迹 → 审批 → 方向条 → 上下文管理引擎 → Harness 自进化 → Actor 与 Space → 结尾。组件在 `src/components/home/`，样式在 `src/styles/home.css`，文案与聚焦区域在 `src/lib/home-features.ts`。

- **首屏**（`Hero.astro` + `scripts/home-stage.ts`）：h1「会自我进化的 / Agent 运行空间」46px（不加眉题），右侧说明与「快速开始 →」「阅读产品理念 →」。下方桃色舞台占满首屏剩余高度（首屏高 `100vh − 页头`，760–920px；矮屏笔记本上宁可舞台底边略出首屏，也要给窗口留够高度）。舞台中央是按桌面端真实界面重画的窗口（2026-10-18 用户确认 H1 demo `docs/design-docs/site-v4/demos/H1-hero-desktop-stage.html`）：侧栏、标题栏、白色圆角用户气泡、纯文本工具行（`Read` / `Edit +n -m` / `Ran`）、子 Agent 卡片、审批卡片（「本会话允许 pnpm」）、测试输出、「上下文已压缩」分隔线、收尾塌缩成「Worked for Xs」、改动卡片与用量行、输入框（Review / •••、deepseek-flash、本机 / 权限 / 上下文圆环）、右侧上下文面板（用量条、分类、上下文事件）。任务「把登录页的表单校验补完，跑一下测试」。四周是 10 个插件：工具（读取文件 / 编辑 / 终端 / Browser Use）、行为（Skills / 审批策略 / 子 Agent）、上下文（渐进披露 / 压缩 / 上下文面板），用折线连到窗口；用到的插件点亮为紫色并让连线流动，用完转为淡紫。**每个用到的插件在窗口里都有一处看得见的变化**；点击开关后按新配置重跑（关「子 Agent」检索结果进主会话、关「压缩」上下文涨到 97% 并提示、关「渐进披露」一次性载入整个 src、关「审批策略」不出审批卡且权限显示「完全权限」、关「编辑」测试失败且没有改动卡片、关「上下文面板」面板不展开）。Browser Use 只列在工具里，这个任务用不到，不在窗口里演示，开关也不重跑。悬停或键盘聚焦显示说明（关掉的加「已关闭」）。左下角计数「本任务启用 n / 10 个插件」。
- **插件化只在首屏讲。**下面的功能块只讲各自的效果，不画插件模块和连线；Harness 块例外，因为「插件派生新版本」就是它的内容。
- **现状**：h2「基础功能」（不加口号和说明）+ 8 张纯文字能力卡（纸面底、圆角 16px），四列 → 两列（1180px）→ 一列（600px），每张链到对应文档。
- **方向**：h2「接下来，它会长成你的 Actor。」+ 三列状态条（序号、状态胶囊、名称、一句话），锚点跳到对应功能块。状态以用户确认为准：上下文管理引擎「已上线」，Harness 自进化与 Actor 与 Space「进行中」。
- **功能块**：左文（5fr）右舞台（7fr），逐块交替左右。文字区：状态胶囊 + 名称、h2 40px、说明、三条编号要点、文字链。
  - **真实界面聚焦块**（`FeatureShot.astro` + `scripts/home-focus.ts`）：舞台里是一扇纸面窗口，窗口里放截图；进入视口先看全貌 1.6s，再依次把截图平移放大到每个要点对应的区域（每处 3.6s，最大 1.7 倍，且不超过截图本身分辨率能撑住的倍数），紫色描边框标出区域、框外压暗，框上方贴「0n 要点名」标签。框和标签在截图画布里、按缩放倍数反向抵消线宽与字号。要点按钮下有进度线；悬停或键盘聚焦停在那一处，点按（触屏）切换固定。减少动态效果时只显示全貌。右下角「查看原图」打开 MediaViewer 看 PNG 原图。窗口默认 5:4；竖长截图用 `portrait`（3:4，最宽 440px），很扁的截图用 `natural`（按原图比例）。区域 `rect` 是相对整张图的 `[左, 上, 宽, 高]`，换图后必须重新量。画布按最大倍数排版、平时缩小显示，放大时是缩回原尺寸，避免浏览器拉伸低分辨率栅格导致发糊；不要给画布加 `will-change: transform`。功能块标题不加句号，说明一句话，要点一行内说完。
  - 改动与交付（薄荷）：轮尾改动卡、交付文件、用量胶囊。执行轨迹（灰蓝）：时间线、调用与结果、失败与停止。审批（桃色，`natural`）：审批卡、本会话放行命令前缀、权限模式菜单。上下文管理引擎（薄荷，`portrait`）：上下文面板的明细、趋势（压缩）、事件（渐进披露）。Actor 与 Space（灰蓝）：Space 演示的名册、协调 Agent 分派、留下 Actor。
  - Harness 自进化（桃色）仍是 HTML 演示：插件「编辑」v1 → 派生 v2 → 沙箱评估 → 接受 v2，角标「示意 · 尚未上线」。说明里写清 V1（会话内新增或修改工具）已经能用，链到 `/docs/harness-tools/`。
- **更新条**：纸面底链接卡片，紫色胶囊「产品更新」+ 等宽日期 + 标题 + 「查看更新 →」。
- **结尾**：桃色舞台条「给下一个问题，/ 一个空间。」+「快速开始 →」+「在 GitHub 查看 ↗」。不放角色插画。

动效规则：所有演示只在进入视口（IntersectionObserver，阈值 .25）且页面可见时播放，离开视口或切到后台就停表，回来从头播；`prefers-reduced-motion` 直接显示终态。Harness 与 Space 两块用 `data-loop` + `scripts/home-loop.ts` 按步骤切换 `data-p`，样式按 `data-p` 定义各步状态。

响应式：1400px 以下收起窗口侧栏，红绿灯移到标题栏；1180px 以下首屏改为纵向（窗口在上、固定 470px 高，插件收成可换行的标签行，不画连线和悬停说明）；640px 以下不展开上下文面板（输入框下的圆环照常变化）；900px 以下功能块单栏，h1 34px、h2 30px。所有宽度不出现横向滚动。

## 文档

Cursor 式阅读结构：左侧目录（`--site-canvas-soft` 底）、中央正文、右侧页内目录与复制页面。左栏展示所有分组；当前项用纸面底 + 字重 500 + 左侧 2px 紫色内边线，悬浮用浅灰圆角背景，不用下划线。标题与首页统一：h1 衬线 36px/500，正文 h2 衬线 26px/500，h3 无衬线 600。代码块纸面底加细边，行内代码 canvas-soft 底。正文链接下划线用 `--site-accent-line`，悬停变 `--site-accent`。没有搜索框、分组标签横条或独立页头。

1200px 以下隐藏右侧目录，复制页面移到正文右上方；760px 以下目录成为可折叠区。正文、代码块、表格与内容图片不溢出视口。

左侧目录滚动条采用透明轨道、浅灰圆角滑块；悬浮侧栏或键盘焦点进入时加深，直接悬浮滑块进一步增强。Chromium / Safari 使用 8px 轨道和两侧各 2px 留白，其他浏览器使用原生 thin。预留稳定滚动槽避免文字跳动，小屏折叠目录不额外占槽；高对比度模式保留系统滚动条颜色。

普通 Markdown 引用使用 `--site-quote-surface/border/ink`：极浅紫底、3px 左边线、深灰正文，内边距 16px 20px、圆角 6px，去除首尾段落多余外边距。截图占位独立使用中性细虚线边框、文件名与操作状态说明，不能伪装成普通引用或真实截图。

## 博客列表

布局与交互以用户提供的 Claude 博客列表为基准，保留 ActSpace 品牌、内容及自有角色插画；不恢复已明确删掉的博客副导航。

- 桌面筛选栏 216px，和内容间隔 46px。大屏三列，1280px 以下两列，600px 以下一列。760px 以下筛选置顶。
- 网格间隔 32px，卡片圆角 22px、细边框，文字区内边距约 30px。
- **封面固定 3:2 横向比例，不能由正方形源图片撑高。** 使用 `object-fit: cover` 中心裁切，不拉伸。确保角色主体在裁切安全区内。
- 列表封面由原始 PNG 母版构建为 quality 90 的响应式 WebP，输出 480/800/1254px 三档；母版不改写，文章正文图片不因此降质。
- 卡片纸面底（`--site-paper`），标题衬线 22px/500、行高 1.3；日期和分类 12px。文字区至少 226px，同一行卡片等高，分类靠底。网格不显示摘要，列表显示摘要。
- 筛选标题下先排序，再分类。分类采用原生 `details/summary` 折叠组与复选框，**不得退回单选下拉框**。方框 20px，文字 14px，整行可点、键盘可操作；选中为品牌紫。
- 卡片悬停保持底色，边框变 `--site-accent-line` 并上移 2px，与首页能力卡片一致。搜索框、视图切换、筛选勾选框和排序下拉同样用纸面底。
- 同组分类多选为 OR；不选等于全部；搜索与分类为 AND。排序只改变顺序，不清空条件。显示结果数与空结果提示。
- 搜索和网格/列表切换位于内容区顶部。视图切换保留筛选状态。
- 仅展示有内容支撑的筛选维度，当前不虚构产品、用途分类。
- 排序采用独立下拉面板：8px圆角、细边框与轻阴影，选项浅灰高亮并在右侧显示选中勾，颜色沿用站点语义变量。鼠标展开使用150ms淡入与轻微位移动画；键盘打开及减少动态效果模式直接显示。支持方向键、Home/End、Enter、Esc、Tab和点击外部关闭，无脚本时保留原生选择框。

## 博客详情

不放装饰性封面。面包屑、标题及摘要、右侧分类/产品/日期/预计阅读/复制链接、正文、前往博客/文档。

桌面 12 列网格、列间距 32px；标题摘要占第 4–9 列，侧栏占第 11–12 列并靠下。正文宽度为容器减去 32px 后的一半；1152px 以下正文最大 640px。991px 以下标题通栏，元信息下移。标题 35–52px 流体字号，行高 1.25；摘要 19–23px，行高 1.65；正文 18px，行高 1.85。

**引言结束必须有全宽细分割线。** 桌面引言底部空白和正文顶部空白各 104px，991px 以下各 80px，600px 以下各 48px。不让正文紧贴摘要，也不让侧栏和正文互相覆盖。文章中的实质性图片保留，文章内容来自 Markdown。

## 更新日志

只显示“更新日志”标题（衬线）；不添加标题说明或“公开发布记录 / 截至日期”。桌面日期左、内容右，小屏纵向，条目之间用细线分隔、不加卡片；日期用等宽数字，下方是紫色 `.site-tag`“产品更新”，条目标题衬线。从首页更新条跳转到的锚点条目（`:target`）短暂显示浅紫底后淡出，reduced-motion 下不做动画。发布记录由现有 release parser 读取，保留原有图文与视频内容。

## 资源与验收

文档截图通过 `Screenshot.astro` 在构建时生成 quality 85 的 WebP 和多宽度 `srcset`，调用方用 `sizes` 描述实际显示宽度；首屏可见的 eager/high，其余 lazy。首页功能块截图直接用 `astro:assets` 生成同样的 WebP srcset 与放大原图。所有截图与正文插图共用纸面相框：圆角 12px、1px `--line` 描边、柔和下投影，阴影画在外框（`.screenshot-link` / `.prose-image-frame`）上，外框裁圆角；文档、博客、更新日志与首页一致。点击放大使用显式生成的全尺寸 PNG，不让缩略图替代细节原图。页头/页脚 Logo 使用带透明通道的 `src/assets/brand/actspace-mark.png`，构建输出 50/100/150px WebP（保留 alpha），保持现有显示尺寸。Astro 使用 Sharp 图像服务，不使用跳过处理的 passthrough 服务。

Netlify 对 `/_astro/*` 的内容哈希资源设置一年 immutable 缓存；HTML 和没有内容哈希的 public 文件不使用该规则。验收同时检查产物字节数、移动端图片选择、桌面清晰度及点击放大，不能只看构建成功。

角色封面位于 `src/assets/blog/covers/`，展示分类映射位于 `src/lib/blog-presentation.ts`。正式文章继续使用 Astro content collections，避免把原型中的整篇 HTML 写死到路由。

开发：`pnpm --filter @actspace/site dev`，默认端口 8765（`http://127.0.0.1:8765/actspace-agent/`）。首页改动需在 1440×900、1100×800、390×844 截图，并对首屏和上下文面板做分时单帧截图（检查任一帧无大片空白）；交互验收覆盖插件悬停、点击开关和 `scrollWidth <= innerWidth`。执行一次 `check`、`test`、`build`；视觉验收检查手机、两列桌面、三列桌面和文章断点。逐次审美微调不反复跑整套验证。功能验收覆盖分类多选/取消、折叠、搜索、排序、无结果、视图切换、移动导航与复制。

不得仅根据尺寸接近宣称完成 Claude 像素级 1:1；中文字体与自有插画存在内容差异，最终以同视口截图人工对照为准。

### 图片预览与文档操作控件

图片预览以原图为主体，关闭按钮置于右上角，使用44px圆形点击区域与线性图标；按钮不能遮挡图片内容。弹窗锁定背景滚动，支持Esc关闭并恢复到触发图片的焦点。颜色使用站点语义变量。

博客封面和正文图片在加载前使用各自固有比例预留空间，并显示站点中性色的轻量骨架。缓存命中时直接结束加载状态；加载失败时停止动画并显示明确提示。减少动态效果时禁用骨架动画，无 JavaScript 时保持原生图片显示。

移动文档目录带展开箭头，当前文章使用中性底色，条目点击高度至少44px。复制页面保留图标并在独立文字区域反馈结果；代码块为复制按钮与语言标签保留顶部空间，避免覆盖代码。
