# ActSpace Site 设计规范

状态：2026-09-19 用户确认的视觉方向；2026-09-26 首页按 `docs/design-docs/website-redesign-demo.html` 改版，并统一全站强调色与字体。正式实现位于本目录，两个原型只作对照，不作为内容源。

## 产品与风格

给模型一个真正能行动的空间。首页强调本地工作区、可见的上下文、工具执行与交付审阅。以真实产品截图表达能力，不用无关装饰填充。

全站只提供浅色。近白画布、黑色正文和胶囊主按钮。品牌紫 `--site-accent`（#6d4fc2，取自 Logo）是全站唯一强调色，用于导航当前项、功能标签、进度条、正文链接下划线、卡片悬停边框和焦点框；配套 `--site-accent-soft`（浅紫底）、`--site-accent-line`（紫色细线）和 `--site-peach`（与博客角色插画同色的桃色底）。**每屏大面积用色不超过两处**（首页首图底板、结尾 CTA 桃色卡片），其余只用线、点、字。Markdown 引用继续使用 `--site-quote-*`。

暂不提供主题切换，不读取历史主题设置。颜色集中在 `src/styles/tokens.css`（单个 `:root`），组件只使用语义变量；`--canvas`、`--ink` 等短别名为旧代码保留，新代码直接用 `--site-*`。此规则适用于 site，桌面应用仍遵循其独立主题规范。

界面和正文使用系统字体栈：SF（`-apple-system`）+ 苹方，Windows 回落到微软雅黑，观感与 Mac 不同属可接受差异；不用 Avenir 等只有西文的字体打头，避免中英混排粗细不一。标题字重 600，博客标题用 Charter / Songti SC 衬线字体。不对中文施加负字距。细分割线和空白建立层级，不使用大阴影或渐变卡片；页头允许轻微半透明模糊。

## 全站骨架

- 桌面页头 68px，窄屏（760px 以下）64px，固定顶部；Logo 后紧跟产品、文档、博客和更新日志，右侧依次为 GitHub 图标、分隔线与快速开始按钮。切换文档不改变页头结构。页头、文档侧栏和目录的吸顶位置共享 `--site-header-height`；博客筛选栏保留页头下方 32px 间距。
- 页面最大宽度 1600px，左右内边距随屏宽变化，手机至少 24px。
- 主按钮黑底白字、圆角胶囊，字重 500，图标间距 10px，悬停加深、按下缩到 .97；辅助操作为文字链接。按钮和链接里的箭头悬停右移 3px。键盘焦点为品牌紫 2px 描边。
- 箭头规则：站内链接用 `→`，只有外部链接（GitHub 等）才用 `↗`。
- 导航当前项：文字加深、字重 500，底部 2px 圆角紫条，不用下划线。页头背景 88% 画布色 + 背景模糊。
- 小屏使用可展开导航，Escape 收起；页头保留 Logo、快速开始和菜单，GitHub 入口随站内导航进入菜单。360px 以下隐藏品牌文字以避免操作区拥挤。站点链接经过 `sitePath()`，兼容 GitHub Pages 子路径。
- 页脚一行：左 Logo，右侧文档、更新日志、开发计划、GitHub ↗；下方一行 `© 年份 ActSpace · 给模型一个真正能行动的空间`。文档阅读区不追加营销页脚。
- Logo 使用带透明通道的 `src/assets/brand/actspace-logo.png`（原白底图保留为 `actspace-logo-source.png`），任何底色上都不露白框。

## 首页

标题为“给模型一个 / 真正能行动的空间”，“空间”两字不换行并着品牌紫。顺序：首屏、任务到结果的介绍、上下文／工具执行／Review／Skills／子 Agent／轨迹六组图文、八项补充能力、更新条、结尾 CTA。不添加 WORKSPACE 等媒体标题、数字索引条、Hero 英文眉题。

- **首屏**：两栏 `1.25fr / 1fr` 底部对齐，左 h1（`clamp(38px, 5.6vw, 80px)`，600），右说明与按钮；860px 以下单栏。首图用真实任务截图 `review-workspace.png`，放在浅紫圆角底板上，截图顶部圆角、底部贴边出血；760px 以下截图放大到 170% 只露聊天区。
- **介绍段**：h2 `clamp(32px, 4.2vw, 56px)` / 600，与右侧说明底部对齐。
- **补充能力**：白底细边卡片，圆角 14px，四列 → 两列（1099px）→ 一列（600px）；悬停边框变 `--site-accent-line`、上移 2px、箭头变紫右移。
- **更新条**：整条是链接卡片，紫色胶囊“产品更新”（共享 `.site-tag`）+ 等宽日期 + 标题 + 右侧“查看更新 →”。
- **结尾 CTA**：`--site-peach` 圆角 24px 卡片，左侧“给下一项工作，/ 一个空间。”与按钮，右侧博客角色插画 `character-01`（WebP 420/840，lazy）；860px 以下上下排列，插画 3:2。

桌面宽 1100px 且高 700px 起，六组图文采用左侧分段说明（40fr）与右侧 sticky 图片（60fr）：每张图放进 16:10 浅灰底板（内边距 5.5%，按截图比例完整居中），底板下方 6 段紫色进度条标出已看过和当前一项。每段至少 58vh；非当前段只淡化正文（.4）和标签（.5），标题改为 muted 色，不整段半透明。图片 300ms 渐变、位移 10px。窄屏、矮屏和无 JavaScript 使用普通图文顺序流（图片同样放在 16:10 底板里），reduced-motion 关闭过渡。没有真实图片时显示清楚的文件名与拍摄要求，不使用虚构产品画面。具体文案与接图清单见 [SHOWCASE_PLAN.md](SHOWCASE_PLAN.md)、[SCREENSHOTS.md](SCREENSHOTS.md)。

## 文档

Cursor 式阅读结构：左侧浅灰目录、中央正文、右侧页内目录与复制页面。左栏展示所有分组；当前项用中性底色 + 字重 500 + 左侧 2px 紫色内边线，悬浮用浅灰圆角背景，不用下划线。正文链接下划线用 `--site-accent-line`，悬停变 `--site-accent`；正文 h2/h3 字重 600。没有搜索框、分组标签横条或独立页头。

1200px 以下隐藏右侧目录，复制页面移到正文右上方；760px 以下目录成为可折叠区。正文、代码块、表格与内容图片不溢出视口。

左侧目录滚动条采用透明轨道、浅灰圆角滑块；悬浮侧栏或键盘焦点进入时加深，直接悬浮滑块进一步增强。Chromium / Safari 使用 8px 轨道和两侧各 2px 留白，其他浏览器使用原生 thin。预留稳定滚动槽避免文字跳动，小屏折叠目录不额外占槽；高对比度模式保留系统滚动条颜色。

普通 Markdown 引用使用 `--site-quote-surface/border/ink`：极浅紫底、3px 左边线、深灰正文，内边距 16px 20px、圆角 6px，去除首尾段落多余外边距。截图占位独立使用中性细虚线边框、文件名与操作状态说明，不能伪装成普通引用或真实截图。

## 博客列表

布局与交互以用户提供的 Claude 博客列表为基准，保留 ActSpace 品牌、内容及自有角色插画；不恢复已明确删掉的博客副导航。

- 桌面筛选栏 216px，和内容间隔 46px。大屏三列，1280px 以下两列，600px 以下一列。760px 以下筛选置顶。
- 网格间隔 32px，卡片圆角 22px、细边框，文字区内边距约 30px。
- **封面固定 3:2 横向比例，不能由正方形源图片撑高。** 使用 `object-fit: cover` 中心裁切，不拉伸。确保角色主体在裁切安全区内。
- 列表封面由原始 PNG 母版构建为 quality 90 的响应式 WebP，输出 480/800/1254px 三档；母版不改写，文章正文图片不因此降质。
- 卡片标题衬线 22px、行高 1.3；日期和分类 12px。文字区至少 226px，同一行卡片等高，分类靠底。网格不显示摘要，列表显示摘要。
- 筛选标题下先排序，再分类。分类采用原生 `details/summary` 折叠组与复选框，**不得退回单选下拉框**。方框 20px，文字 14px，整行可点、键盘可操作；选中为品牌紫。
- 卡片悬停保持底色，边框变 `--site-accent-line` 并上移 2px，与首页能力卡片一致。
- 同组分类多选为 OR；不选等于全部；搜索与分类为 AND。排序只改变顺序，不清空条件。显示结果数与空结果提示。
- 搜索和网格/列表切换位于内容区顶部。视图切换保留筛选状态。
- 仅展示有内容支撑的筛选维度，当前不虚构产品、用途分类。
- 排序采用独立下拉面板：8px圆角、细边框与轻阴影，选项浅灰高亮并在右侧显示选中勾，颜色沿用站点语义变量。鼠标展开使用150ms淡入与轻微位移动画；键盘打开及减少动态效果模式直接显示。支持方向键、Home/End、Enter、Esc、Tab和点击外部关闭，无脚本时保留原生选择框。

## 博客详情

不放装饰性封面。面包屑、标题及摘要、右侧分类/产品/日期/预计阅读/复制链接、正文、前往博客/文档。

桌面 12 列网格、列间距 32px；标题摘要占第 4–9 列，侧栏占第 11–12 列并靠下。正文宽度为容器减去 32px 后的一半；1152px 以下正文最大 640px。991px 以下标题通栏，元信息下移。标题 35–52px 流体字号，行高 1.25；摘要 19–23px，行高 1.65；正文 18px，行高 1.85。

**引言结束必须有全宽细分割线。** 桌面引言底部空白和正文顶部空白各 104px，991px 以下各 80px，600px 以下各 48px。不让正文紧贴摘要，也不让侧栏和正文互相覆盖。文章中的实质性图片保留，文章内容来自 Markdown。

## 更新日志

只显示“更新日志”标题；不添加标题说明或“公开发布记录 / 截至日期”。桌面日期左、内容右，小屏纵向；日期下方是紫色 `.site-tag`“产品更新”，条目标题字重 600。从首页更新条跳转到的锚点条目（`:target`）短暂显示浅紫底后淡出，reduced-motion 下不做动画。发布记录由现有 release parser 读取，保留原有图文与视频内容。

## 资源与验收

截图通过 `Screenshot.astro` 在构建时生成 quality 85 的 WebP 和多宽度 `srcset`，调用方用 `sizes` 描述实际显示宽度；首图 eager/high，其余 lazy。点击放大使用显式生成的全尺寸 PNG，不让缩略图替代细节原图。页头/页脚 Logo 使用带透明通道的 `src/assets/brand/actspace-logo.png`，构建输出 50/100/150px WebP（保留 alpha），保持现有显示尺寸。Astro 使用 Sharp 图像服务，不使用跳过处理的 passthrough 服务。

Netlify 对 `/_astro/*` 的内容哈希资源设置一年 immutable 缓存；HTML 和没有内容哈希的 public 文件不使用该规则。验收同时检查产物字节数、移动端图片选择、桌面清晰度及点击放大，不能只看构建成功。

角色封面位于 `src/assets/blog/covers/`，展示分类映射位于 `src/lib/blog-presentation.ts`。正式文章继续使用 Astro content collections，避免把原型中的整篇 HTML 写死到路由。

开发：`pnpm --filter @actspace/site dev`，默认端口 8765（`http://127.0.0.1:8765/actspace-agent/`）。首页改动需在 1440、1100、760、390 四个宽度截图，与改版 demo 同宽对照。执行一次 `check`、`test`、`build`；视觉验收检查手机、两列桌面、三列桌面和文章断点。逐次审美微调不反复跑整套验证。功能验收覆盖分类多选/取消、折叠、搜索、排序、无结果、视图切换、移动导航与复制。

不得仅根据尺寸接近宣称完成 Claude 像素级 1:1；中文字体与自有插画存在内容差异，最终以同视口截图人工对照为准。


## 内容与截图维护

功能文档按开始使用、工作区与会话、模型与上下文、工具与执行、工作台、扩展、设置与开发分组。事实来源与博客迁移记录见 [CONTENT_SOURCES.md](CONTENT_SOURCES.md)，待补截图见 [SCREENSHOTS.md](SCREENSHOTS.md)。截图暂缺时用可读说明标注实际页面和状态，不显示破图。博客正文插图与列表封面分开管理，原文不因官网排版而改写。

### 图片预览与文档操作控件

图片预览以原图为主体，关闭按钮置于右上角，使用44px圆形点击区域与线性图标；按钮不能遮挡图片内容。弹窗锁定背景滚动，支持Esc关闭并恢复到触发图片的焦点。颜色使用站点语义变量。

首页截图、博客封面和正文图片在加载前使用各自固有比例预留空间，并显示站点中性色的轻量骨架。缓存命中时直接结束加载状态；加载失败时停止动画并显示明确提示。减少动态效果时禁用骨架动画，无 JavaScript 时保持原生图片显示。

移动文档目录带展开箭头，当前文章使用中性底色，条目点击高度至少44px。复制页面保留图标并在独立文字区域反馈结果；代码块为复制按钮与语言标签保留顶部空间，避免覆盖代码。
