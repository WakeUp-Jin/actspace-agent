## 滚动展示

建议桌面 >=1100px 使用左侧分段文字、右侧 sticky 图片；文字约 42%、图片约 58%。图片停留在页头下方，随当前段落切换。每段占约 60–75vh，不使用滚轮劫持或整屏吸附。

当前段落正常不透明，前后段落适度降低至约 0.35；图片使用 220–300ms 淡入淡出与不超过 12px 位移。键盘聚焦某段链接时恢复该段可读性。正文不以永久隐藏或等待动画的方式加载。

1100px 以下按普通图文顺序流展示，避免窄图片无法读清；移动端每段说明后跟一张图。尊重 prefers-reduced-motion，关闭位移与渐变过渡；无 JavaScript 时完整内容依然可读。截图点击可放大，保留替代文本。

图片未到位时显示对应文件名与简短拍摄要求的静态占位。用户提供素材后替换；不制造模拟产品画面，不让同一张旧截图重复代表六种功能。

## 文档与引用

配图紧跟“打开哪个入口 → 做什么 → 看到什么”的段落；首页全景在文档中按需要裁切为局部，正文可点击看大图。关键操作保留文本说明，图片不是唯一的信息来源。运行中／完成后只在有比较价值的地方分别放图。

普通 Markdown 引用统一采用极浅薰衣草底、较清楚的 3px 左边线、正文深灰，内边距约 16px 20px、圆角 6px；去掉首尾子段落额外外边距。建议在 site tokens 中定义 quote-surface、quote-border、quote-ink，组件只引用语义变量。官网按此前决定保持浅色，黑色按钮保持既定品牌方向。

同一引用规则覆盖文档和博客的 Markdown blockquote，不改引用文字，也不把所有段落变成提示卡。截图占位使用独立的“待补截图”说明样式，避免与示例提示词混淆。颜色方向已批准，按本规范实现并目视校验。
