# 官网与文档截图清单

共 **35 张独立截图**：首批 8 张，第二批 27 张。首页与文档共用同名素材，不重复计数。

## 首批必拍：01–08（8 张）

由用户手动截取真实 ActSpace，本轮 Agent 不代拍产品素材。先用同一个示例项目、同一浅色主题拍下表，足以制作首页首屏和六组重点展示。原始 PNG 可以直接放在一个文件夹交给 Agent，不用自己裁切、压缩或写路径。命名按下表即可。

建议将窗口固定在约 1440 × 900 逻辑像素，使用系统原始分辨率截图；尺寸不是硬要求，文字清晰优先。首页优先完整窗口，文档可以从同一原图裁出重点控件。关闭无关浮层和系统通知，使用示例会话及项目名称；密钥保持遮罩。没有达到描述中的实际状态时先跳过，不拼造界面。

首页展示的是能力，不要求六张图来自六个不同任务；同一次真实任务的上下文、执行、Review、轨迹可以连续截图。

## 交付方式

按表中的文件名保存，全部放在同一个文件夹即可，例如 `actspace-screenshots/`。完成首批后就可以先提供该文件夹路径，不需要等 35 张全部齐备。暂时无法截取的编号告诉 Agent 即可。原始图不要预先拼接、缩放或加水印；如果需要强调位置，可另附一张标注副本。

Agent 接收后核对编号、画面状态与现有实现，保留原始图，分别生成首页展示和文档局部版本；再处理格式、尺寸、替代文本、图注与页面引用。缺图保持明确占位，不用旧截图冒充新状态。

## 当前接入状态

35 个文件名均已对应到页面占位，截图共用不需要重复拍摄。首页首屏和六组展示使用 `Screenshot.astro`；图片归档到 `src/assets/screenshots/` 并保留表中名称后，构建时自动选择真实图片。文档以 `data-screenshot="文件名.png"` 标记各占位，收到图片后由 Agent 统一替换为本地资源引用，并决定是否裁切局部。不要手动删除普通引用段落。

`src/lib/screenshots.json` 保存首批接入时的拍摄说明，修改清单文件名时需同步它和页面引用。当前尚无任何本轮真实产品图片，网页中的占位不能作为功能实际运行的证据。
