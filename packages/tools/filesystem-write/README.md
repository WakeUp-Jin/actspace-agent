# filesystem-write

`@actspace/tools-filesystem-write` 拥有 edit_file、write_file、delete_file 的工具定义、注册和 lifecycle。

公开入口：`.`、`./manifest`、`./plugin`。

Host port 为 `actspace.host.tools.filesystem-write`；factory 只创建本包资源。

详细契约见 [Tool 插件边界](../../../docs/design-docs/agent-plugin-runtime/agent-tool-plugin-boundaries.md)。
